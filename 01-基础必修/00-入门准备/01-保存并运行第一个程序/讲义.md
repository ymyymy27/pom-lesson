# 保存并运行第一个程序

课程编号：B01 · 建议投入：1.5 小时（含练习与复盘） · 状态：可试学

## 本课任务

把编辑器里的文字变成电脑实际执行的指令。

## 先修检查

不需要编程经验。先完成根目录《开始学习》的 Python 与编辑器安装。

## 理解过程

源代码是文本文件；解释器是运行它的程序；终端用于输入运行命令。这三个东西各有职责。先保存再运行，修改后必须重新运行才能看到新结果。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/00-入门准备/01-保存并运行第一个程序/示例/示例.py"
```

```python
print("你好，大学！")
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

跟做：运行示例并解释每个输出来自哪条语句，修改一项数据后重新预测结果。

独立任务：在练习文件中分两行输出“我的第一门编程课”和“今天完成一次运行”。不要直接在终端输入这两句话。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

文件不能命名为“示例.py.txt”。开启资源管理器的文件扩展名显示；找不到文件时先检查当前目录。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
