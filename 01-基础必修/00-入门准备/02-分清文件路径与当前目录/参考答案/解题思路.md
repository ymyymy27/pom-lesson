# 解题思路

先明确任务：从仓库根目录和课时目录分别运行同一练习，练习只输出自身文件名；记录两次输出及运行命令。

相对路径从当前目录开始；绝对路径从盘符或根目录开始。路径不是程序内容。先定位工作目录，再运行文件；带空格的路径需要引号。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。终端用 Get-Location 查看当前目录。 __file__ 表示当前脚本的路径，Path(...).name 取文件名。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：不要把 PS C:\...> 这样的提示符复制成命令。终端里的命令与 Python 代码放在不同位置。
