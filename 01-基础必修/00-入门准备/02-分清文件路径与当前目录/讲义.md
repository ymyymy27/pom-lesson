# 分清文件路径与当前目录

课程编号：B02 · 建议投入：1.5 小时（含练习与复盘） · 状态：可试学

## 本课任务

解决程序找不到文件的最常见原因。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

相对路径从当前目录开始；绝对路径从盘符或根目录开始。路径不是程序内容。先定位工作目录，再运行文件；带空格的路径需要引号。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/00-入门准备/02-分清文件路径与当前目录/示例/示例.py"
```

```python
from pathlib import Path
print(Path(__file__).name)
print(Path(__file__).parent.name)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

不要把 PS C:\...> 这样的提示符复制成命令。终端里的命令与 Python 代码放在不同位置。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
