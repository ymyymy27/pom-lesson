# 用输入处理输出描述问题

课程编号：B03 · 建议投入：1.5 小时（含练习与复盘） · 状态：可试学

## 本课任务

在写代码之前明确程序究竟要完成什么。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

程序可以看成输入、处理、输出的组合。输入可以先用固定数据代替键盘输入，便于重复检查。计算结果与输出格式是两件事。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/01-程序与计算思维/01-用输入处理输出描述问题/示例/示例.py"
```

```python
price = 8
count = 3
total = price * count
print(f"总价：{total}元")
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

跟做：运行示例并解释每个输出来自哪条语句，修改一项数据后重新预测结果。

独立任务：校园打印店每页 0.2 元，打印 15 页，输出“费用：3.0元”；先在讲义旁写出输入、处理和输出。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

输出字符串中的单位不参与运算。不能用“0.2元”这样的字符串直接乘出金额。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
