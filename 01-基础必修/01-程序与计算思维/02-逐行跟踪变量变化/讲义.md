# 逐行跟踪变量变化

课程编号：B04 · 建议投入：1.5 小时（含练习与复盘） · 状态：可试学

## 本课任务

理解赋值后变量保存的值如何改变。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

等号表示把右边表达式算出来并绑定到左边的名字，不是数学中的恒等式。按执行顺序记录变量，每执行一行更新一次。变量名应表达用途。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/01-程序与计算思维/02-逐行跟踪变量变化/示例/示例.py"
```

```python
remaining = 10
remaining = remaining - 3
remaining = remaining + 2
print(remaining)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

独立任务：任务数从 4 开始，新增 3 项，完成 2 项，输出剩余任务数。画出每一步的变量值。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

变量必须先赋值再读取。NameError 通常意味着拼写不一致或执行顺序错误。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
