# 解题思路

先明确任务：把字符串“18”和“7”转换为整数并计算总和；分别说明直接拼接和转换后相加的区别。

整数用于计数，浮点数用于近似小数，字符串用于文本。键盘 input 的结果是字符串，需要 int 或 float 转换后才能计算。先预测类型再运算。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。用 int("18") 得到整数。 扩展：把“18”改为“十八”，观察报错，记录原因。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：ValueError 表示内容无法按指定格式转换；TypeError 常来自对不匹配的类型执行运算。
