# 数字字符串与类型转换

课程编号：B05 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

避免把文字拼接误认为数字相加。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

整数用于计数，浮点数用于近似小数，字符串用于文本。键盘 input 的结果是字符串，需要 int 或 float 转换后才能计算。先预测类型再运算。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/02-Python编程基础/01-数字字符串与类型转换/示例/示例.py"
```

```python
raw = "12"
print(raw + "3")
print(int(raw) + 3)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

ValueError 表示内容无法按指定格式转换；TypeError 常来自对不匹配的类型执行运算。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
