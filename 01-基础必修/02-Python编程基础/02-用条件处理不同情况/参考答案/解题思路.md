# 解题思路

先明确任务：给分数 59、60、100 分别输出补练、通过、通过。再增加范围检查：小于 0 或大于 100 输出“输入无效”。

比较运算得到 True 或 False；if 根据结果决定是否执行缩进的代码。elif 从上往下匹配，命中后不再检查后续分支。边界值能暴露大于与大于等于的区别。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。先各运行一次固定分数；学过循环后再批量检查。 范围检查应放在判断是否通过之前。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：缩进是语法的一部分；不要混用 Tab 和空格。判断相等使用 ==，赋值使用 =。
