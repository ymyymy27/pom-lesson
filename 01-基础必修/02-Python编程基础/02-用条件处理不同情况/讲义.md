# 用条件处理不同情况

课程编号：B06 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

让程序根据成绩做出不同反馈。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

比较运算得到 True 或 False；if 根据结果决定是否执行缩进的代码。elif 从上往下匹配，命中后不再检查后续分支。边界值能暴露大于与大于等于的区别。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/02-Python编程基础/02-用条件处理不同情况/示例/示例.py"
```

```python
score = 60
if score >= 60:
    print("通过")
else:
    print("补练")
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

跟做：运行示例并解释每个输出来自哪条语句，修改一项数据后重新预测结果。

独立任务：给分数 59、60、100 分别输出补练、通过、通过。再增加范围检查：小于 0 或大于 100 输出“输入无效”。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

缩进是语法的一部分；不要混用 Tab 和空格。判断相等使用 ==，赋值使用 =。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
