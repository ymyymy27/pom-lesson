# 解题思路

先明确任务：建立包含数学、英语的列表，追加编程，输出任务数量和最后一个任务。再测试空列表时能否读取最后一项。

列表保持元素顺序，索引从 0 开始。append 在末尾添加，遍历用于逐项处理。先区分位置与内容，再决定按索引访问还是遍历。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。len 返回元素数量。 空列表要先判断是否有元素，再索引。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：IndexError 表示索引超出范围。长度是 3 时，非负索引只有 0、1、2。
