# 用列表保存任务

课程编号：B08 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

处理数量变化的一组数据。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

列表保持元素顺序，索引从 0 开始。append 在末尾添加，遍历用于逐项处理。先区分位置与内容，再决定按索引访问还是遍历。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/02-Python编程基础/04-用列表保存任务/示例/示例.py"
```

```python
tasks = ["预习", "实验"]
tasks.append("复盘")
for task in tasks:
    print(task)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

IndexError 表示索引超出范围。长度是 3 时，非负索引只有 0、1、2。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
