# 解题思路

先明确任务：保存一本书，包含 title 和 borrowed 字段，把 borrowed 从 False 改为 True，输出书名和状态。

字典用键定位值，适合表达有名称的字段；列表适合保存多条记录。字典保持插入顺序，但不自动按键排序。先约定字段，避免每条记录写法不同。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。字段名写在引号里。 访问缺失字段时比较 [] 与 get 的行为。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：KeyError 表示键不存在；注意 title 和 Title 是不同键。
