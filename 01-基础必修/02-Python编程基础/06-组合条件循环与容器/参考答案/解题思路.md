# 解题思路

先明确任务：对完成状态为 True、False、False 的三条任务统计未完成数量；再用空列表运行，结果应为 0。

先写出数据结构，再拆出遍历和条件判断。统计器只在满足条件时增加。不要在统计过程中意外修改原始数据。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。先只输出每条任务的 done，确认数据读取正确。 在循环前设 count = 0。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：不要把字符串 "False" 当布尔值 False。非空字符串在条件判断中为真。
