## 理解过程

先写出数据结构，再拆出遍历和条件判断。统计器只在满足条件时增加。不要在统计过程中意外修改原始数据。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/02-Python编程基础/06-组合条件循环与容器/示例/示例.py"
```

```python
tasks = [{"title": "预习", "done": True}, {"title": "实验", "done": False}]
count = 0
for task in tasks:
    if not task["done"]:
        count += 1
print(count)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

不要把字符串 "False" 当布尔值 False。非空字符串在条件判断中为真。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
