# 解题思路

先明确任务：定义 to_seconds(minutes)，把 3 分钟转换为 180 秒；检查 0 分钟。

定义函数不会立即执行函数体；调用时才执行。参数让相同过程接收不同数据；return 把结果交给调用者；print 只是显示。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。函数内部 return 计算结果。 把 print 放在调用处，便于后面测试返回值。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：返回 None 常因为忘了 return。写了函数名但不加括号不会调用函数。
