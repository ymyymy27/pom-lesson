## 理解过程

函数应负责一件能描述清楚的事。先确定输入和输出，再让调用者组合它们。避免依赖函数外部不断变化的全局变量。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/03-函数与程序组织/02-把一个问题拆成小函数/示例/示例.py"
```

```python
def count_unfinished(tasks):
    count = 0
    for task in tasks:
        if not task["done"]:
            count += 1
    return count

print(count_unfinished([{"done": True}, {"done": False}]))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

函数内部临时变量应在每次调用时初始化，避免两次调用互相影响。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
