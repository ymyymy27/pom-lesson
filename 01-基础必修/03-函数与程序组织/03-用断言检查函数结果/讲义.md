# 用断言检查函数结果

课程编号：B13 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

让程序在结果错误时明确失败。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

测试用例由输入和预期结果组成。正常值、边界值、异常值各有用途。assert 条件不成立时停止执行，提醒实际结果不符合约定。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/03-函数与程序组织/03-用断言检查函数结果/示例/示例.py"
```

```python
def passed(score):
    return score >= 60

assert passed(59) is False
assert passed(60) is True
print("2项检查通过")
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

独立任务：为 is_even(number) 写检查，覆盖 0、3、4，全部通过后输出“3项检查通过”。故意改错一次观察失败位置。

## 常见错误与排查

AssertionError 是测试失败，不是测试工具坏了。先核对输入和预期，再检查实现。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
