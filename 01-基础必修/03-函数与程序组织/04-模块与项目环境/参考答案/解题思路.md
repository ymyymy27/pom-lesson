# 解题思路

先明确任务：使用标准库 statistics 计算 [60,80,100] 的平均值；另建 tools.py，放入前课函数并在 main.py 导入运行。提交两文件和运行命令。

一个 Python 文件可以提供函数供另一个文件导入。标准库随 Python 提供，第三方包需另行安装。虚拟环境让项目依赖相互隔离；安装与运行要使用同一解释器。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。先完成单文件标准库导入；再做双文件练习。 两个文件放在同一目录，不要把文件命名为 statistics.py。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：ModuleNotFoundError 先检查名字、文件位置和解释器，不要反复安装到不同环境。
