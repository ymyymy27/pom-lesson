## 本课任务

理解导入与依赖，并隔离项目使用的包。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

一个 Python 文件可以提供函数供另一个文件导入。标准库随 Python 提供，第三方包需另行安装。虚拟环境让项目依赖相互隔离；安装与运行要使用同一解释器。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/03-函数与程序组织/04-模块与项目环境/示例/示例.py"
```

```python
from statistics import mean
print(mean([2, 4, 6]))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

ModuleNotFoundError 先检查名字、文件位置和解释器，不要反复安装到不同环境。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
