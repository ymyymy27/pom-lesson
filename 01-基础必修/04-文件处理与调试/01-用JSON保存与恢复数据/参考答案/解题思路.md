# 解题思路

先明确任务：把包含 title 为“复习”、done 为 True 的列表转换为 JSON 再恢复，输出恢复后的字段。随后用 Path.write_text/read_text 保存到自己的临时文件并验证。

内存数据随进程结束消失；文件保存字节。JSON 是常见的数据交换格式，支持列表、对象、数字、布尔等。序列化与反序列化必须保持字段约定。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。保存文本显式指定 encoding="utf-8"。 先在内存中验证往返转换，再加入文件步骤。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：JSON 的 true/false 与 Python 的 True/False 写法不同；交给 json 模块转换，不手工拼接。
