# 用JSON保存与恢复数据：独立练习

## 任务与提交物

把包含 title 为“复习”、done 为 True 的列表转换为 JSON 再恢复，输出恢复后的字段。随后用 Path.write_text/read_text 保存到自己的临时文件并验证。

提交自己的练习代码、执行命令、实际输出，以及 3–5 句解题说明。Git 与项目课还必须提交任务中要求的操作记录，不能只提交参考脚本输出。

## 起点

从[练习.py](练习.py)开始。需要多文件时在自己的作业目录建立；不要修改课程中的参考答案。
