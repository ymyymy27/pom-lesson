## 理解过程

内存数据随进程结束消失；文件保存字节。JSON 是常见的数据交换格式，支持列表、对象、数字、布尔等。序列化与反序列化必须保持字段约定。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/04-文件处理与调试/01-用JSON保存与恢复数据/示例/示例.py"
```

```python
import json
tasks = [{"title": "实验", "done": False}]
text = json.dumps(tasks, ensure_ascii=False)
restored = json.loads(text)
print(restored[0]["title"])
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

JSON 的 true/false 与 Python 的 True/False 写法不同；交给 json 模块转换，不手工拼接。
