# 区分文件不存在与格式错误

课程编号：B16 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

让失败有明确反馈，同时保留用户的数据。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

异常表达处理过程失败。只捕获能够解释或处理的异常；文件不存在与内容损坏不能一律当作空数据。损坏的数据应报告并保留，避免覆盖。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/04-文件处理与调试/02-区分文件不存在与格式错误/示例/示例.py"
```

```python
import json
try:
    json.loads("{bad}")
except json.JSONDecodeError:
    print("数据格式错误，请检查文件")
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

捕获 Exception 后直接返回空列表会隐藏编程错误，也可能导致覆盖原有数据。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
