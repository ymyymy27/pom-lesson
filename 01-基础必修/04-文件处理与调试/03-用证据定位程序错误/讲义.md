# 用证据定位程序错误

课程编号：B17 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

形成可重复的调试过程。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

调试依次做复现、缩小范围、观察状态、提出假设和验证修改。语法错误、运行错误、逻辑错误的表现不同。一次只改一个假设相关的地方。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/04-文件处理与调试/03-用证据定位程序错误/示例/示例.py"
```

```python
numbers = [2, 4, 6]
total = 0
for number in numbers:
    total += number
    print("当前累计", total)
print("平均", total / len(numbers))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

跟做：运行示例并解释每个输出来自哪条语句，修改一项数据后重新预测结果。

独立任务：修复平均值程序：错误版本用 len(numbers)-1 作分母。使用 [2,4,6] 证明应输出 4.0；记录一个断点位置和观察到的变量值。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

修复后至少重跑原失败输入与一个新输入。不要只删除报错行。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
