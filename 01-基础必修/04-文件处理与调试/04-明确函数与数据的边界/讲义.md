# 明确函数与数据的边界

课程编号：B18 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

在任务项目里增加输入检查，保持已有功能可靠。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

入口把外部数据转换为内部约定，核心函数处理已知结构。错误提示应包含可以修正的原因。空白字符串、重复任务和不存在的编号要有明确行为。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/04-文件处理与调试/04-明确函数与数据的边界/示例/示例.py"
```

```python
def clean_title(title):
    result = title.strip()
    if not result:
        raise ValueError("任务名称不能为空")
    return result

print(clean_title("  实验  "))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

独立任务：实现 clean_title，去掉首尾空白；输入全空格时抛出 ValueError。对“  阅读  ”和全空格检查，输出“阅读”和“已拒绝空任务”。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

不要把“用户输入不合法”与“程序运行环境损坏”统一显示成“未知错误”。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
