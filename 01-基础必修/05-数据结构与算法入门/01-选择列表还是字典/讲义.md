## 理解过程

列表适合有序遍历，字典适合通过唯一键查找。用编号建立索引可以避免每次从头扫描；代价是维护额外数据结构。先考虑需要执行的操作。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/05-数据结构与算法入门/01-选择列表还是字典/示例/示例.py"
```

```python
tasks = [{"id": 1, "title": "阅读"}, {"id": 2, "title": "实验"}]
by_id = {task["id"]: task for task in tasks}
print(by_id[2]["title"])
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

列表的位置不是业务编号；删除元素会改变位置，但不应改变任务自身编号。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
