## 理解过程

栈是后进先出，适合撤销；队列是先进先出，适合排队处理。它们是行为规则，不只是某个库名。通过两次添加、两次取出检查顺序。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```python
from collections import deque
queue = deque(["同学甲", "同学乙"])
print(queue.popleft())
stack = ["修改一", "修改二"]
print(stack.pop())
```

## 常见错误与排查

不要将列表头部删除的开销与 deque 的队首操作混为一谈。
