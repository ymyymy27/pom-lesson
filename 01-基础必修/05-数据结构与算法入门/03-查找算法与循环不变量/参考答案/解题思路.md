# 解题思路

先明确任务：实现线性查找，检查首项、中间项、缺失目标和空列表。分别得到 0、1、-1、-1。

线性查找逐项比较，找到后返回；没找到应有明确结果。循环过程中，已经检查过的部分都不符合目标。这个事实帮助我们推理程序正确性。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。找不到时的 return 应放在循环结束之后。 统计长度为 n 且目标缺失时的比较次数。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：不要在第一次不匹配时就返回 -1；后面还可能有匹配项。
