## 理解过程

线性查找逐项比较，找到后返回；没找到应有明确结果。循环过程中，已经检查过的部分都不符合目标。这个事实帮助我们推理程序正确性。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/05-数据结构与算法入门/03-查找算法与循环不变量/示例/示例.py"
```

```python
def find_index(items, target):
    for index, value in enumerate(items):
        if value == target:
            return index
    return -1

print(find_index([4, 8, 12], 8))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。
