# 排序与复杂度实验

课程编号：B22 · 建议投入：3 小时（含练习与复盘） · 状态：可试学

## 本课任务

区分算法行为、运行时间和输入规模。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

排序把元素按规则重新组织。复杂度描述规模增长趋势，不是某台电脑的固定秒数。先用比较次数做可重复实验，再讨论时间波动。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/05-数据结构与算法入门/04-排序与复杂度实验/示例/示例.py"
```

```python
items = [3, 1, 2]
print(sorted(items))
print(items)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

一次计时很短不能证明复杂度更低。用多种规模、重复实验和操作计数交叉判断。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
