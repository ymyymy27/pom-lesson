# 二进制字符与文件

课程编号：B23 · 建议投入：4 小时（含练习与复盘） · 状态：可试学

## 本课任务

理解文件保存的是字节，而屏幕显示的是字符。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

数字可用不同进制表示，字符需要编码映射为字节。同一字符串的字符数量与 UTF-8 字节数量可能不同。读写双方使用相同编码才能正确解释内容。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/06-计算机系统与网络入门/01-二进制字符与文件/示例/示例.py"
```

```python
print(bin(10))
text = "大学"
print(len(text))
print(len(text.encode("utf-8")))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

出现乱码时先检查读写编码；不要反复转换未知编码覆盖原文件。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
