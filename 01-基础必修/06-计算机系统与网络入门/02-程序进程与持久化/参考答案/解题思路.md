# 解题思路

先明确任务：启动子进程输出 8+9，父进程读取结果并输出 17；画出程序文件、两个进程和输出之间的关系。

程序文件是保存的指令，进程是正在运行的实例。多个进程有各自的内存；文件可跨进程保存。程序退出不等于磁盘文件删除。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。使用 sys.executable 让子进程使用当前解释器。 本课只运行提供的固定命令，不拼接外部输入。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：启动另一个 Python 程序后，不能假定它看得到当前进程里的变量。
