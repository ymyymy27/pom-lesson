## 本课任务

解释为什么关闭程序后内存中的任务消失。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

程序文件是保存的指令，进程是正在运行的实例。多个进程有各自的内存；文件可跨进程保存。程序退出不等于磁盘文件删除。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/06-计算机系统与网络入门/02-程序进程与持久化/示例/示例.py"
```

```python
import subprocess, sys
result = subprocess.run([sys.executable, "-c", "print(6 * 7)"], capture_output=True, text=True, check=True)
print(result.stdout.strip())
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

启动另一个 Python 程序后，不能假定它看得到当前进程里的变量。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
