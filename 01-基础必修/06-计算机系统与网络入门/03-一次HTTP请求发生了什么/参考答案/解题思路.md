# 解题思路

先明确任务：解析 http://localhost:8080/health，分别输出主机、端口和路径；随后启动 TaskFlow 网页版，记录 /health 和不存在路径的状态码。

URL 包含协议、主机、端口和路径；客户端发出请求，服务端返回状态码、响应头和正文。200 通常表示成功，404 表示资源不存在。网络失败与业务失败需要区分。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。urlparse 只拆解地址，不会发起网络请求。 localhost 表示本机；端口用于区分服务入口。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：浏览器打不开时，先确认服务进程已启动和端口正确，再检查路径。
