## 理解过程

URL 包含协议、主机、端口和路径；客户端发出请求，服务端返回状态码、响应头和正文。200 通常表示成功，404 表示资源不存在。网络失败与业务失败需要区分。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/06-计算机系统与网络入门/03-一次HTTP请求发生了什么/示例/示例.py"
```

```python
from urllib.parse import urlparse
url = urlparse("http://127.0.0.1:8000/tasks")
print(url.hostname, url.port, url.path)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

浏览器打不开时，先确认服务进程已启动和端口正确，再检查路径。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
