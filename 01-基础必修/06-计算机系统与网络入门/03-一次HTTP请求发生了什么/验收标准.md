# 一次HTTP请求发生了什么：验收标准

- [ ] 完成独立任务：解析 http://localhost:8080/health，分别输出主机、端口和路径；随后启动 TaskFlow 网页版，记录 /health 和不存在路径的状态码。
- [ ] 固定示例结果与练习说明一致；记录至少一个自己设计的输入与预期。
- [ ] 能解释关键语句和本课概念，回答“改变输入后哪里会变化”。
- [ ] 发生错误时，能指出原因和修复步骤；需要实际操作证据的任务已附记录。
- [ ] 没有直接覆盖教师示例或参考答案。

反馈：功能未通过时先缩小到失败输入；能运行但无法解释时，回到讲义逐行跟踪。达到以上要求再进入下一课。
