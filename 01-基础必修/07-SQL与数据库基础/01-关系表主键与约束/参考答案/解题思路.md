# 解题思路

先明确任务：创建 courses 表，包含主键 id 与非空 name，插入“程序设计”并查询输出。说明表、行、列、主键分别对应什么。

表由行和列组成，主键标识一行。约束限制可接受的数据，帮助在多个入口写入时维持规则。SQLite 数据库可保存在一个本地文件中。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。使用 :memory: 可以做不生成文件的实验。 只有一个参数的元组也需要尾部逗号。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：表不存在通常是连接了另一个数据库，或尚未执行建表操作。
