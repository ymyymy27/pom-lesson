把多条任务记录组织成有约束的数据。

## 理解过程

表由行和列组成，主键标识一行。约束限制可接受的数据，帮助在多个入口写入时维持规则。SQLite 数据库可保存在一个本地文件中。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/07-SQL与数据库基础/01-关系表主键与约束/示例/示例.py"
```

```python
import sqlite3
with sqlite3.connect(":memory:") as db:
    db.execute("CREATE TABLE tasks(id INTEGER PRIMARY KEY, title TEXT NOT NULL)")
    db.execute("INSERT INTO tasks(title) VALUES (?)", ("阅读",))
    print(db.execute("SELECT title FROM tasks").fetchone()[0])
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。
