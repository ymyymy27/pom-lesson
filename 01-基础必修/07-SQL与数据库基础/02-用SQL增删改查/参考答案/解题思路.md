# 解题思路

先明确任务：插入编号 1 和 2 两条记录，仅删除编号 1，再查询剩余编号，输出 2。所有实验使用内存数据库。

INSERT 添加行，SELECT 查询，UPDATE 修改，DELETE 删除。WHERE 决定作用范围；写操作前先用 SELECT 核实匹配记录。参数与 SQL 结构分开传递。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。删除前先查询 WHERE id=1 的记录。 不用 f-string 把用户输入直接放进 SQL。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：遗漏 WHERE 会影响所有行。课程中的删除实验只能在自己的练习数据库中执行。
