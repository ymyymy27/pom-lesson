# 用SQL增删改查：独立练习

## 任务与提交物

插入编号 1 和 2 两条记录，仅删除编号 1，再查询剩余编号，输出 2。所有实验使用内存数据库。

提交自己的练习代码、执行命令、实际输出，以及 3–5 句解题说明。Git 与项目课还必须提交任务中要求的操作记录，不能只提交参考脚本输出。

## 起点

从[练习.py](练习.py)开始。需要多文件时在自己的作业目录建立；不要修改课程中的参考答案。

## 分层提示

1. 删除前先查询 WHERE id=1 的记录。
2. 不用 f-string 把用户输入直接放进 SQL。
