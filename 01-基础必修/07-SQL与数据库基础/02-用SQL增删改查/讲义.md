## 理解过程

INSERT 添加行，SELECT 查询，UPDATE 修改，DELETE 删除。WHERE 决定作用范围；写操作前先用 SELECT 核实匹配记录。参数与 SQL 结构分开传递。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/07-SQL与数据库基础/02-用SQL增删改查/示例/示例.py"
```

```python
import sqlite3
with sqlite3.connect(":memory:") as db:
    db.execute("CREATE TABLE tasks(id INTEGER PRIMARY KEY, done INTEGER)")
    db.execute("INSERT INTO tasks VALUES (1,0)")
    db.execute("UPDATE tasks SET done=? WHERE id=?", (1,1))
    print(db.execute("SELECT done FROM tasks WHERE id=1").fetchone()[0])
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。
