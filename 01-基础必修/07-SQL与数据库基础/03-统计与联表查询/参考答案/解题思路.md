# 解题思路

先明确任务：建立课程表和任务表，Python 课程有两条任务；用 JOIN 与 COUNT 得到 Python 的任务数 2。

一张表保存一个主题的数据，用外键表达关联。JOIN 根据条件组合行；GROUP BY 将行分组后计算统计量。先画出两张表的关系再写查询。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。先只写 JOIN 查询观察组合结果。 挑战：新增没有任务的课程，比较 JOIN 和 LEFT JOIN。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：联表遗漏关联条件可能得到笛卡尔积，导致统计数量异常。
