## 理解过程

一张表保存一个主题的数据，用外键表达关联。JOIN 根据条件组合行；GROUP BY 将行分组后计算统计量。先画出两张表的关系再写查询。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/07-SQL与数据库基础/03-统计与联表查询/示例/示例.py"
```

```python
import sqlite3
with sqlite3.connect(":memory:") as db:
    db.executescript("CREATE TABLE tasks(course TEXT, done INTEGER); INSERT INTO tasks VALUES ('Python',1),('Python',0),('SQL',1);")
    print(db.execute("SELECT course, COUNT(*) FROM tasks GROUP BY course ORDER BY course").fetchall())
```

## 常见错误与排查

联表遗漏关联条件可能得到笛卡尔积，导致统计数量异常。
