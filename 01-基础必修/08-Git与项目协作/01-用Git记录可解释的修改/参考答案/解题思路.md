# 解题思路

先明确任务：在自己新建的练习目录初始化 Git，创建说明.md 并提交；修改一行，保存 git diff 和 git log 的输出。不要在课程仓库里覆盖教师文件。

工作区是正在编辑的文件；暂存区选择本次提交内容；提交保存一个快照。diff 展示变化，status 展示当前状态。提交信息解释修改目的。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。如果 Git 要求身份信息，只在练习仓库配置 user.name 和 user.email。 练习的答案是实际提交记录，参考脚本只列核对步骤。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：不要把虚拟环境、密钥和运行产生的数据加入提交；先查看暂存差异。
