# 用Git记录可解释的修改

课程编号：B30 · 建议投入：4 小时（含练习与复盘） · 状态：可试学

## 本课任务

让每次修改能够被查看、说明和恢复。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

工作区是正在编辑的文件；暂存区选择本次提交内容；提交保存一个快照。diff 展示变化，status 展示当前状态。提交信息解释修改目的。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/08-Git与项目协作/01-用Git记录可解释的修改/示例/示例.py"
```

```python
steps = ["git init", "git status", "git add 说明.md", "git commit -m 首次记录"]
for step in steps:
    print(step)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

不要把虚拟环境、密钥和运行产生的数据加入提交；先查看暂存差异。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
