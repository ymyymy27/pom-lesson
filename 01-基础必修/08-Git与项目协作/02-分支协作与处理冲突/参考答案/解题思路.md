# 解题思路

先明确任务：在练习仓库创建两个分支，分别修改说明.md 同一行，制造并解决冲突；记录选择最终内容的理由，展示没有冲突标记的文件。

分支是独立推进修改的名字。合并时 Git 能处理部分互不冲突的编辑；同一处不同修改需要人决定。解决冲突后必须再次验证程序行为。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。合并前先确保已有修改已提交。 冲突标记含 <<<<<<<、=======、>>>>>>>；不能只删标记而不理解内容。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：参考脚本不替代真实 Git 操作。验收必须检查分支历史与合并后的文件。
