# 分支协作与处理冲突

课程编号：B31 · 建议投入：4 小时（含练习与复盘） · 状态：可试学

## 本课任务

理解并行修改如何合并到同一个结果。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

分支是独立推进修改的名字。合并时 Git 能处理部分互不冲突的编辑；同一处不同修改需要人决定。解决冲突后必须再次验证程序行为。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/08-Git与项目协作/02-分支协作与处理冲突/示例/示例.py"
```

```python
for action in ["创建分支", "修改并提交", "合并", "验证结果"]:
    print(action)
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 常见错误与排查

参考脚本不替代真实 Git 操作。验收必须检查分支历史与合并后的文件。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
