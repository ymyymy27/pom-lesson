# 解题思路

先明确任务：完成 TaskFlow 数据库版，按新增、列出、完成、重启、再次列出的顺序演示；交付运行说明、三条测试证据和一段调试复盘。

交付包含代码、数据、运行说明、验证证据和已知限制。展示一条完整用户流程，再展示失败输入如何处理。复盘应基于具体问题而非笼统评价。

推荐检查顺序：先核对输入和数据结构，再跟踪处理步骤，最后检查输出与边界情况。请同学只看你的说明运行一次，记录他需要询问的步骤。 现场增加一个简单筛选条件，解释修改位置。

实现见[参考答案.py](参考答案.py)。从课时目录执行 `python "参考答案/参考答案.py"`。

参考实现只展示一种方法。Git 操作、双文件导入、磁盘读写和项目交付部分还需要按练习要求实际完成并保留证据。

常见误区：测试通过不代表已覆盖所有需求。说明没有实现的功能，避免把规划写成已交付。
