# 演示项目与复盘

课程编号：B32 · 建议投入：4 小时（含练习与复盘） · 状态：可试学

## 本课任务

向另一位同学交付可以独立运行的作品。

## 先修检查

完成上一课，能独立运行其示例并用自己的话解释结果。若尚不能，先回到上一课完成独立练习。

## 理解过程

交付包含代码、数据、运行说明、验证证据和已知限制。展示一条完整用户流程，再展示失败输入如何处理。复盘应基于具体问题而非笼统评价。

先在纸上预测示例的输出，再逐行跟踪执行。把“代码做什么”和“为什么要这样做”分别说清楚。运行后若结果与预测不同，标记第一个出现差异的位置。

## 完整示例

文件：[示例.py](示例/示例.py)。从仓库根目录在 PowerShell 执行：

```powershell
python "01-基础必修/08-Git与项目协作/03-演示项目与复盘/示例/示例.py"
```

```python
items = {"可运行": True, "有说明": True, "能解释": True}
print(all(items.values()))
```

代码中的数据可直接修改。跟做时每次只改变一个输入，记录修改前的预测与修改后的输出。恢复原始输入再次运行，确认结果可重复。

## 跟做与独立练习

跟做：运行示例并解释每个输出来自哪条语句，修改一项数据后重新预测结果。

独立任务：完成 TaskFlow 数据库版，按新增、列出、完成、重启、再次列出的顺序演示；交付运行说明、三条测试证据和一段调试复盘。

打开[练习说明](练习/练习说明.md)，在自己的作业副本中完成；尝试后再阅读[解题思路](参考答案/解题思路.md)。

## 常见错误与排查

测试通过不代表已覆盖所有需求。说明没有实现的功能，避免把规划写成已交付。

遇到问题先记录执行命令、完整错误和最小输入，再定位到对应行。只描述“不能运行”不足以复现问题。
