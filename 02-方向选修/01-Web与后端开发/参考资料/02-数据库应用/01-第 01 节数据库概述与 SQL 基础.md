# 第 01 节：数据库概述与 SQL 基础

## 一、什么是数据库？

数据库是 **有组织地存储和管理数据** 的系统。Web 应用中几乎所有数据（用户信息、文章、订单等）都存储在数据库中。

### 1.1 数据库分类

| 类型 | 代表 | 数据结构 | 适用场景 |
|------|------|---------|---------|
| **关系型（RDBMS）** | PostgreSQL, MySQL, SQLite | 表（行+列） | 结构化数据、需要事务 |
| **文档型** | MongoDB | JSON 文档 | 灵活 schema、快速迭代 |
| **键值型** | Redis | Key-Value | 缓存、会话、排行榜 |
| **搜索引擎** | Elasticsearch | 倒排索引 | 全文搜索 |

本课程重点学习 **PostgreSQL（关系型）** + **Redis（键值型）**。

### 1.2 关系型数据库核心概念

```
数据库 (Database)
└── 表 (Table) — 类比 Excel 的工作表
    ├── 列 (Column / Field) — 字段，定义数据类型
    ├── 行 (Row / Record) — 一条数据记录
    ├── 主键 (Primary Key) — 唯一标识每一行
    └── 外键 (Foreign Key) — 关联其他表
```

**示例：用户表 (users)**

| id (主键) | name | email | age | is_active |
|-----------|------|-------|-----|-----------|
| 1 | 张三 | zs@example.com | 25 | true |
| 2 | 李四 | ls@example.com | 30 | true |
| 3 | 王五 | ww@example.com | 28 | false |

## 二、SQL 语言

SQL（Structured Query Language）是操作关系型数据库的标准语言。

### 2.1 SQL 语句分类

| 类型 | 全称 | 操作 | 关键语句 |
|------|------|------|---------|
| **DDL** | 数据定义语言 | 定义表结构 | CREATE, ALTER, DROP |
| **DML** | 数据操作语言 | 操作数据 | INSERT, UPDATE, DELETE |
| **DQL** | 数据查询语言 | 查询数据 | SELECT |
| **DCL** | 数据控制语言 | 权限控制 | GRANT, REVOKE |

## 三、DDL — 创建和管理表

### 3.1 创建表

```sql
-- 创建用户表
CREATE TABLE users (
    id          SERIAL PRIMARY KEY,        -- 自增主键
    name        VARCHAR(100) NOT NULL,      -- 可变长字符串，不为空
    email       VARCHAR(255) UNIQUE NOT NULL, -- 唯一且不为空
    age         INTEGER DEFAULT 0,          -- 整数，默认值 0
    bio         TEXT,                        -- 长文本，可为空
    is_active   BOOLEAN DEFAULT TRUE,       -- 布尔值
    created_at  TIMESTAMP DEFAULT NOW(),    -- 时间戳，默认当前时间
    updated_at  TIMESTAMP DEFAULT NOW()
);

-- 创建任务表（包含外键）
CREATE TABLE tasks (
    id          SERIAL PRIMARY KEY,
    title       VARCHAR(200) NOT NULL,
    description TEXT,
    status      VARCHAR(20) DEFAULT 'pending',  -- pending / in_progress / completed
    priority    INTEGER DEFAULT 0 CHECK (priority >= 0 AND priority <= 10),
    assignee_id INTEGER REFERENCES users(id) ON DELETE SET NULL,  -- 外键关联 users
    created_at  TIMESTAMP DEFAULT NOW(),
    due_date    DATE
);
```

### 3.2 常用数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `SERIAL` | 自增整数（PostgreSQL 专用） | 主键 |
| `INTEGER` | 整数 | 年龄、数量 |
| `BIGINT` | 大整数 | 大范围 ID |
| `NUMERIC(10,2)` | 精确小数 | 金额 |
| `VARCHAR(n)` | 可变长字符串（最大 n 个字符） | 姓名、邮箱 |
| `TEXT` | 不限长度的文本 | 文章内容 |
| `BOOLEAN` | 布尔值 | 状态标志 |
| `DATE` | 日期 | 2025-01-01 |
| `TIMESTAMP` | 日期时间 | 2025-01-01 12:30:00 |
| `JSON` / `JSONB` | JSON 数据 | 扩展字段 |

### 3.3 修改和删除表

```sql
-- 添加列
ALTER TABLE users ADD COLUMN phone VARCHAR(20);

-- 修改列类型
ALTER TABLE users ALTER COLUMN phone TYPE VARCHAR(30);

-- 删除列
ALTER TABLE users DROP COLUMN phone;

-- 重命名列
ALTER TABLE users RENAME COLUMN name TO username;

-- 删除表（谨慎！）
DROP TABLE IF EXISTS tasks;

-- 清空表数据（保留表结构）
TRUNCATE TABLE tasks;
```

## 四、DML — 增删改数据

### 4.1 INSERT — 插入数据

```sql
-- 插入单条
INSERT INTO users (name, email, age)
VALUES ('张三', 'zhangsan@example.com', 25);

-- 插入多条
INSERT INTO users (name, email, age) VALUES
    ('李四', 'lisi@example.com', 30),
    ('王五', 'wangwu@example.com', 28),
    ('赵六', 'zhaoliu@example.com', 22);

-- 插入并返回新记录（PostgreSQL 特性）
INSERT INTO users (name, email, age)
VALUES ('钱七', 'qianqi@example.com', 35)
RETURNING id, name, email;
```

### 4.2 UPDATE — 更新数据

```sql
-- 更新单条
UPDATE users
SET age = 26, updated_at = NOW()
WHERE id = 1;

-- 更新多条
UPDATE users
SET is_active = FALSE
WHERE age < 20;

-- 注意：没有 WHERE 条件会更新所有行！（非常危险）
-- UPDATE users SET is_active = FALSE;  -- 所有用户被停用！
```

### 4.3 DELETE — 删除数据

```sql
-- 删除单条
DELETE FROM users WHERE id = 3;

-- 删除多条
DELETE FROM users WHERE is_active = FALSE;

-- 注意：没有 WHERE 条件会删除所有数据！（非常危险）
-- DELETE FROM users;  -- 所有数据被删除！
```

## 五、DQL — 查询数据

### 5.1 基础查询

```sql
-- 查询所有列
SELECT * FROM users;

-- 查询指定列
SELECT name, email, age FROM users;

-- 使用别名
SELECT name AS 姓名, email AS 邮箱, age AS 年龄 FROM users;

-- 去重
SELECT DISTINCT status FROM tasks;
```

### 5.2 WHERE 条件过滤

```sql
-- 比较运算符
SELECT * FROM users WHERE age > 25;
SELECT * FROM users WHERE age >= 25 AND age <= 35;
SELECT * FROM users WHERE age BETWEEN 25 AND 35;  -- 等价

-- 等于 / 不等于
SELECT * FROM users WHERE is_active = TRUE;
SELECT * FROM users WHERE status != 'completed';
SELECT * FROM users WHERE status <> 'completed';   -- 另一种写法

-- IN — 在列表中
SELECT * FROM users WHERE age IN (25, 28, 30);
SELECT * FROM tasks WHERE status IN ('pending', 'in_progress');

-- LIKE — 模糊匹配
SELECT * FROM users WHERE name LIKE '张%';     -- 以"张"开头
SELECT * FROM users WHERE email LIKE '%@gmail.com'; -- 以 @gmail.com 结尾
SELECT * FROM users WHERE name LIKE '%三%';    -- 包含"三"

-- IS NULL / IS NOT NULL
SELECT * FROM tasks WHERE assignee_id IS NULL;     -- 未分配的任务
SELECT * FROM tasks WHERE due_date IS NOT NULL;     -- 有截止日期的任务

-- AND / OR / NOT
SELECT * FROM users
WHERE age >= 25 AND is_active = TRUE;

SELECT * FROM tasks
WHERE status = 'pending' OR priority >= 8;

SELECT * FROM users
WHERE NOT is_active;
```

### 5.3 排序和限制

```sql
-- ORDER BY 排序
SELECT * FROM users ORDER BY age ASC;          -- 升序（默认）
SELECT * FROM users ORDER BY age DESC;         -- 降序
SELECT * FROM tasks ORDER BY priority DESC, created_at ASC;  -- 多列排序

-- LIMIT / OFFSET 分页
SELECT * FROM tasks ORDER BY created_at DESC LIMIT 10;           -- 前 10 条
SELECT * FROM tasks ORDER BY created_at DESC LIMIT 10 OFFSET 20; -- 第 3 页（跳过前 20 条）
```

### 5.4 聚合函数

```sql
-- COUNT — 计数
SELECT COUNT(*) FROM users;                          -- 用户总数
SELECT COUNT(*) FROM users WHERE is_active = TRUE;   -- 活跃用户数

-- SUM / AVG / MAX / MIN
SELECT SUM(priority) FROM tasks;
SELECT AVG(age) FROM users;
SELECT MAX(age) FROM users;
SELECT MIN(created_at) FROM tasks;
```

### 5.5 GROUP BY 分组

```sql
-- 按状态统计任务数
SELECT status, COUNT(*) AS task_count
FROM tasks
GROUP BY status;
-- 结果：
-- status      | task_count
-- pending     | 5
-- in_progress | 3
-- completed   | 8

-- HAVING — 对分组结果过滤（WHERE 是对行过滤）
SELECT status, COUNT(*) AS task_count
FROM tasks
GROUP BY status
HAVING COUNT(*) > 3;

-- 按用户统计任务数并排序
SELECT assignee_id, COUNT(*) AS task_count
FROM tasks
WHERE status != 'completed'
GROUP BY assignee_id
ORDER BY task_count DESC;
```

## 六、SQL 执行顺序

一条 SELECT 语句的 **逻辑执行顺序**（不是书写顺序）：

```
FROM       → 确定数据源（表）
WHERE      → 行级过滤
GROUP BY   → 分组
HAVING     → 组级过滤
SELECT     → 选择列
DISTINCT   → 去重
ORDER BY   → 排序
LIMIT      → 限制行数
```

理解这个顺序有助于写出正确的 SQL：
- `WHERE` 中不能用 `SELECT` 中的别名（因为 WHERE 先于 SELECT 执行）
- `HAVING` 可以用聚合函数（因为 HAVING 在 GROUP BY 之后执行）
