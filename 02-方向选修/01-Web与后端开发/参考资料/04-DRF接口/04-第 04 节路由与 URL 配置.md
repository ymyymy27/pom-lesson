# 第 04 节：路由与 URL 配置

## 一、DRF Router

Router 自动为 ViewSet 生成 URL 路由，不需要手动写 `path()`。

### 1.1 DefaultRouter

```python
# apps/tasks/urls.py
from django.urls import path, include
from rest_framework.routers import DefaultRouter
from . import views

router = DefaultRouter()
router.register('tasks', views.TaskViewSet, basename='task')
router.register('tags', views.TagViewSet, basename='tag')

urlpatterns = [
    path('', include(router.urls)),
]
```

**自动生成的 URL：**

```
GET/POST        /tasks/                  → TaskViewSet.list / .create
GET/PUT/PATCH/DELETE  /tasks/{pk}/       → TaskViewSet.retrieve / .update / .partial_update / .destroy
POST            /tasks/{pk}/complete/    → TaskViewSet.complete  (@action)
GET             /tasks/my_tasks/         → TaskViewSet.my_tasks  (@action)
GET             /tasks/statistics/       → TaskViewSet.statistics (@action)

GET/POST        /tags/                   → TagViewSet.list / .create
GET/PUT/PATCH/DELETE  /tags/{pk}/        → TagViewSet.retrieve / .update / .partial_update / .destroy

GET             /                        → API Root（所有端点列表）
```

### 1.2 SimpleRouter vs DefaultRouter

| 特性 | SimpleRouter | DefaultRouter |
|------|-------------|---------------|
| 标准 CRUD 路由 | ✅ | ✅ |
| API Root 页面 | ❌ | ✅（`GET /`） |
| `.json` 后缀 | ❌ | ✅ |
| 使用场景 | 生产环境 | 开发环境 |

```python
from rest_framework.routers import SimpleRouter, DefaultRouter

# 开发
router = DefaultRouter()

# 生产
router = SimpleRouter()
```

### 1.3 basename 参数

```python
# 有 queryset 时可以省略 basename（自动从 model 推导）
router.register('tags', views.TagViewSet)  # basename 自动为 'tag'

# 重写了 get_queryset() 时必须指定 basename
router.register('tasks', views.TaskViewSet, basename='task')

# basename 影响 URL name：
# basename='task' →
#   task-list        GET /tasks/
#   task-detail      GET /tasks/{pk}/
#   task-complete    POST /tasks/{pk}/complete/  (@action)
```

## 二、嵌套路由

### 2.1 手动嵌套

```python
# 项目下的任务：/api/v1/projects/{project_pk}/tasks/
# apps/projects/urls.py
from django.urls import path, include
from rest_framework.routers import DefaultRouter
from . import views
from apps.tasks.views import TaskViewSet

router = DefaultRouter()
router.register('projects', views.ProjectViewSet, basename='project')

# 嵌套路由
project_tasks_list = TaskViewSet.as_view({
    'get': 'list',
    'post': 'create',
})
project_tasks_detail = TaskViewSet.as_view({
    'get': 'retrieve',
    'put': 'update',
    'patch': 'partial_update',
    'delete': 'destroy',
})

urlpatterns = [
    path('', include(router.urls)),
    path('projects/<int:project_pk>/tasks/', project_tasks_list, name='project-task-list'),
    path('projects/<int:project_pk>/tasks/<int:pk>/', project_tasks_detail, name='project-task-detail'),
]
```

```python
# apps/tasks/views.py
class TaskViewSet(viewsets.ModelViewSet):
    serializer_class = TaskWriteSerializer
    
    def get_queryset(self):
        qs = Task.objects.select_related('assignee', 'project').prefetch_related('tags')
        # 嵌套路由时，按项目过滤
        project_pk = self.kwargs.get('project_pk')
        if project_pk:
            qs = qs.filter(project_id=project_pk)
        return qs
    
    def perform_create(self, serializer):
        # 嵌套路由时，自动设置 project
        project_pk = self.kwargs.get('project_pk')
        kwargs = {'creator': self.request.user}
        if project_pk:
            kwargs['project_id'] = project_pk
        serializer.save(**kwargs)
```

### 2.2 使用 drf-nested-routers（推荐）

```bash
pip install drf-nested-routers
```

```python
from rest_framework_nested import routers

# 一级路由
router = routers.DefaultRouter()
router.register('projects', ProjectViewSet, basename='project')
router.register('tasks', TaskViewSet, basename='task')
router.register('tags', TagViewSet, basename='tag')

# 二级嵌套路由：/projects/{project_pk}/tasks/
projects_router = routers.NestedDefaultRouter(router, 'projects', lookup='project')
projects_router.register('tasks', TaskViewSet, basename='project-tasks')
projects_router.register('members', ProjectMemberViewSet, basename='project-members')

# 二级嵌套路由：/tasks/{task_pk}/comments/
tasks_router = routers.NestedDefaultRouter(router, 'tasks', lookup='task')
tasks_router.register('comments', CommentViewSet, basename='task-comments')

urlpatterns = [
    path('', include(router.urls)),
    path('', include(projects_router.urls)),
    path('', include(tasks_router.urls)),
]

# 生成的 URL：
# /projects/                          项目列表
# /projects/{pk}/                     项目详情
# /projects/{project_pk}/tasks/       项目下的任务列表
# /projects/{project_pk}/tasks/{pk}/  项目下的任务详情
# /projects/{project_pk}/members/     项目成员
# /tasks/                             所有任务
# /tasks/{pk}/                        任务详情
# /tasks/{task_pk}/comments/          任务评论
# /tasks/{task_pk}/comments/{pk}/     评论详情
# /tags/                              标签
```

## 三、URL 整合

### 3.1 项目 URL 结构

```python
# config/urls.py
from django.contrib import admin
from django.urls import path, include
from drf_spectacular.views import SpectacularAPIView, SpectacularSwaggerView

urlpatterns = [
    # Admin
    path('admin/', admin.site.urls),
    
    # API v1
    path('api/v1/', include('apps.tasks.urls')),
    path('api/v1/', include('apps.projects.urls')),
    path('api/v1/', include('apps.users.urls')),
    
    # API 文档
    path('api/schema/', SpectacularAPIView.as_view(), name='schema'),
    path('api/docs/', SpectacularSwaggerView.as_view(url_name='schema'), name='swagger-ui'),
    
    # DRF 可浏览 API 登录
    path('api-auth/', include('rest_framework.urls')),
]
```

### 3.2 版本管理

```python
# 方式1：URL 路径版本（推荐）
path('api/v1/', include('apps.tasks.urls')),
path('api/v2/', include('apps.tasks.urls_v2')),

# 方式2：DRF 版本类
# settings.py
REST_FRAMEWORK = {
    'DEFAULT_VERSIONING_CLASS': 'rest_framework.versioning.URLPathVersioning',
    'ALLOWED_VERSIONS': ['v1', 'v2'],
    'DEFAULT_VERSION': 'v1',
}

# urls.py
path('api/<version>/', include('apps.tasks.urls')),

# views.py
class TaskViewSet(viewsets.ModelViewSet):
    def get_serializer_class(self):
        if self.request.version == 'v2':
            return TaskV2Serializer
        return TaskSerializer
```
