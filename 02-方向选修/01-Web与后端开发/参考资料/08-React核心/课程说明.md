# 第 08 阶段：React 核心（组件/状态/路由/Hooks）

## 学习目标

完成本阶段后，你将能够：
- 理解 React 组件化开发思想和 JSX 语法
- 使用函数组件和 Hooks 管理状态
- 掌握常用 Hooks（useState、useEffect、useRef、useMemo、useCallback）
- 使用 React Router 实现前端路由
- 编写自定义 Hooks 封装逻辑
- 理解组件生命周期和渲染优化
