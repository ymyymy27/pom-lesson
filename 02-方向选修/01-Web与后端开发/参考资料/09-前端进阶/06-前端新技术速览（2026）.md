## 2. React Compiler 1.0（2025.10 稳定）

### 它做什么？

**自动分析组件依赖，插入 memoization** —— 替代手写的 `useMemo`、`useCallback`、`React.memo`。

```tsx
// 以前：手动优化
const MemoizedList = React.memo(function List({ items, onSelect }) {
  const sorted = useMemo(() => items.sort(), [items]);
  const handleClick = useCallback((id) => onSelect(id), [onSelect]);
  return sorted.map(item => <Item key={item.id} onClick={handleClick} />);
});

// React Compiler 启用后：写普通代码，编译器自动优化
function List({ items, onSelect }) {
  const sorted = items.sort();
  return sorted.map(item => (
    <Item key={item.id} onClick={() => onSelect(item.id)} />
  ));
}
```

### 如何在 Vite 项目中启用

```js
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [
    react({
      babel: {
        plugins: [['babel-plugin-react-compiler', {}]],
      },
    }),
  ],
});
```

### Next.js 中启用

```js
// next.config.js
module.exports = {
  experimental: {
    reactCompiler: true,
  },
};
```

> Next.js 16.4+ Rust 版 Compiler 构建提速 40%+（需 Turbopack）。

## 3. React Server Components（RSC）

### 核心思想

```
Server Component（默认）→ 在服务端渲染，零客户端 JS
Client Component（'use client'）→ 需要交互的部分
```

```tsx
// app/tasks/page.tsx — Server Component
async function TaskPage() {
  const tasks = await db.tasks.findMany(); // 直接访问数据库
  return <TaskList tasks={tasks} />;
}

// components/TaskList.tsx — Client Component
'use client';
import { useState } from 'react';

export function TaskList({ tasks }) {
  const [filter, setFilter] = useState('all');
  // 交互逻辑...
}
```

### 与 TaskFlow（CSR SPA）的对比

| 维度 | TaskFlow（React + Vite SPA） | Next.js App Router |
|------|------------------------------|-------------------|
| 首屏加载 | 需下载全部 JS | Server 直出 HTML |
| SEO | 需 SSR 配置 | 内置 |
| 后端耦合 | DRF API 独立 | 可 API Route 一体 |
| 复杂度 | 较低 | 较高 |
| 适用 | 内部工具、B2B SaaS | 内容站、SEO 敏感 |

**结论：** TaskFlow 选 SPA 合理；若需 SEO 或首屏极致性能，可评估迁移 Next.js。

## 4. TanStack 生态（2026 逻辑层标准）

| 库 | 替代 | 用途 |
|----|------|------|
| TanStack Query | 手写 fetch + useEffect | 服务端状态、缓存、重试 |
| TanStack Router | React Router | 类型安全路由 |
| TanStack Form | Formik / 手写 | 表单状态 |
| TanStack Table | 手写 table | 复杂表格 |

TaskFlow stage-09 已引入 TanStack Query —— 这是 2026 最佳实践。

```tsx
// TanStack Query 示例（TaskFlow 已在用）
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

function useTasks(projectId: string) {
  return useQuery({
    queryKey: ['tasks', projectId],
    queryFn: () => api.getTasks(projectId),
    staleTime: 30_000,
  });
}
```

## 7. 何时考虑 Next.js 迁移？

```
✅ 考虑迁移：
  - 需要 SEO（公开页面、博客、Landing）
  - 首屏性能是关键指标
  - 团队熟悉 App Router

❌ 保持 SPA：
  - 纯 B2B 内部工具（TaskFlow 类）
  - 后端已是 Django/DRF 独立服务
  - 团队规模小，避免额外复杂度
```
