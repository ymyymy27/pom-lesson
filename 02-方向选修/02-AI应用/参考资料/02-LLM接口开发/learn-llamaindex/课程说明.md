## 1. LlamaIndex vs LangChain

| 维度 | LlamaIndex | LangChain |
|------|------------|-----------|
| 定位 | **数据索引 + RAG 专精** | 通用 LLM 应用框架 |
| 强项 | 文档加载、索引、查询引擎 | Chain、Agent、Tool |
| RAG | 原生、多种 Index 类型 | 通过 Retriever 集成 |
| Agent | 支持（较轻） | LangGraph 深度集成 |
| 学习曲线 | RAG 场景更低 | 更广但更杂 |

**选型建议：**
- 纯 RAG 知识库 → **LlamaIndex**
- Agent + 复杂工作流 → **LangChain + LangGraph**
- 可组合使用：LlamaIndex 做索引，LangChain 做 Agent

---

## 2. 核心概念

```
Documents → Nodes → Index → Query Engine → Response

Document：原始文档（PDF/Markdown/API）
Node：文档块（chunk）
Index：向量/树/关键词等索引结构
Query Engine：检索 + 合成回答
```

---

## 3. 最小 RAG 示例

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader, Settings
from llama_index.embeddings.openai import OpenAIEmbedding
from llama_index.llms.openai import OpenAI

Settings.llm = OpenAI(model="gpt-4o-mini")
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")

# 加载文档
documents = SimpleDirectoryReader("./data/docs").load_data()

# 建索引
index = VectorStoreIndex.from_documents(documents)

# 查询
query_engine = index.as_query_engine(similarity_top_k=3)
response = query_engine.query("TaskFlow 的权限模型是什么？")
print(response)
```

---

## 4. 索引类型

| 索引 | 适用 |
|------|------|
| VectorStoreIndex | 语义检索（默认） |
| SummaryIndex | 全文摘要 |
| TreeIndex | 层级文档 |
| KnowledgeGraphIndex | 实体关系（Graph RAG） |
| Composability | 多索引组合 |
