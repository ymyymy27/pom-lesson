# Scikit-learn 机器学习实战

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_ml_overview.py` | 机器学习概述、sklearn 生态、数据集加载与划分 |
| 第2课 | `02_linear_regression.py` | 线性回归、梯度下降、多项式回归、正则化 |
| 第3课 | `03_classification.py` | 逻辑回归、决策树、随机森林、SVM、KNN |
| 第4课 | `04_evaluation_metrics.py` | 评估指标（准确率/召回率/F1/AUC/混淆矩阵/ROC） |
| 第5课 | `05_feature_engineering.py` | 特征工程（缩放/编码/选择/降维） |
| 第6课 | `06_model_tuning.py` | 模型调优（交叉验证/网格搜索/管道） |
| 第7课 | `07_ml_project.py` | 综合项目：从数据到模型的完整流程 |

## 依赖安装

```bash
pip install -r requirements.txt
```

## 学习方式

- 每个 .py 文件可直接运行：`python 01_ml_overview.py`
- 代码包含详细中文注释，边看边跑
- 按顺序学习，每课都有运行输出
