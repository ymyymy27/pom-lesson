# 第 03 节：函数式与集合操作

## 本节目标

- 掌握一等函数、闭包与高阶函数
- 熟练使用集合 API：`map` / `where` / `fold` / `sort`
- 会用扩展方法和级联操作写出简洁代码

## 一、函数是一等公民

```dart
// 箭头函数
int doubleIt(int x) => x * 2;

// 匿名函数 / 闭包
final add = (int x) => x + 1;

// 函数作为参数（回调）
void forEach(int n, void Function(int) action) {
  for (var i = 0; i < n; i++) action(i);
}

// 函数作为返回值（柯里化风格）
Function makeAdder(int base) => (int x) => base + x;
final addTen = makeAdder(10);
print(addTen(5)); // 15
```

与 TS 一样，闭包会捕获外层变量：

```dart
var counters = <int Function()>[];
for (var i = 0; i < 3; i++) {
  counters.add(() => i * 2);   // 捕获的是每次循环的 i
}
```

## 二、集合 API（对照 JS 数组方法）

```dart
final tasks = <Map<String, dynamic>>[
  {'title': '写 Dart', 'done': true},
  {'title': '配环境', 'done': false},
  {'title': '跑 App', 'done': false},
];

// map：转换（JS 的 .map）
final titles = tasks.map((t) => t['title']).toList();

// where：过滤（JS 的 .filter）
final undone = tasks.where((t) => t['done'] == false).toList();

// any / every：判断
final allDone = tasks.every((t) => t['done'] == true);
final hasUrgent = tasks.any((t) => t['priority'] == 1);

// fold：归约（JS 的 .reduce，但需要初始值）
final total = [1, 2, 3, 4].fold<int>(0, (sum, x) => sum + x);

// expand：一对多展开（JS 的 .flatMap）
final words = ['a b', 'c'].expand((s) => s.split(' ')).toList();

// sort：排序（直接修改原列表）
final nums = [3, 1, 2];
nums.sort((a, b) => a.compareTo(b));
```

> Dart 的集合方法默认返回**惰性 Iterable**，需要 `.toList()` 才变成 List；这一点和 Python 的 map 类似，和 JS 不同。

## 三、空安全相关的函数式写法

```dart
String? maybeName(String? raw) => raw?.trim();

// 链式处理可空值
final display = raw
    ?.trim()
    ?.toUpperCase()
    ?? '匿名';

// 列表里过滤 null
final list = <int?>[1, null, 3];
final nonNull = list.whereType<int>().toList();  // [1, 3]
```

## 四、扩展方法（Dart 特色，TS 没有）

给现有类型"加方法"，不修改原类：

```dart
extension StringX on String {
  bool get isBlank => trim().isEmpty;
  String toTitleCase() =>
      split(' ').map((w) => w.isEmpty ? w : '${w[0].toUpperCase()}${w.substring(1)}').join(' ');
}

extension TaskListX on List<Map<String, dynamic>> {
  int get doneCount => where((t) => t['done'] == true).length;
}
```

用途：把工具函数组织到类型旁边，IDE 自动提示，比写一堆全局函数优雅。

## 五、级联操作 `..`

连续调用同一对象的方法：

```dart
final list = <String>[]
  ..add('a')
  ..add('b')
  ..sort();

// 等价于：
// final list = <String>[];
// list.add('a'); list.add('b'); list.sort();
```

## 常见坑

- `map`/`where` 返回 Iterable，忘写 `.toList()` 会导致"类型对不上"
- 对 `List` 用 `==` 比较的是引用，不是内容；内容比较要 `listEquals`（Flutter 提供）
- 匿名函数类型写作 `void Function(int)`，不是 TS 的 `(x: number) => void`
