# 第 02 阶段：Flutter 环境与工程结构

## 学习目标

完成本阶段后，你将能够：
- 在 Windows 上完成 Flutter 环境搭建，通过 `flutter doctor` 检查
- 创建项目并在 Windows 桌面端 / Android 模拟器 / Chrome 上运行
- 看懂 Flutter 项目目录与 `pubspec.yaml`
- 理解 Widget 树、Element 树与热重载机制
- 使用 DevTools 调试第一个 App

## 前置要求

- 完成 Stage 01（Dart 基础）
- 已安装 VS Code 或 Android Studio

## 课程内容

| 节 | 课时文件 | 内容 |
|----|-------------|------|
| 1 | `01-第 01 节环境搭建与 flutter doctor.md` | SDK 安装、镜像源、编辑器、模拟器与真机准备 |
| 2 | `02-第 02 节工程结构与 Widget 树.md` | 目录结构、pubspec、main.dart、MaterialApp、Widget 树 |
| 3 | `03-第 03 节计数器 App 逐行解读与调试.md` | 官方模板逐行讲解、热重载、DevTools、断点与日志 |

## 练习与产出

- `exercises/`：环境诊断与最小改动练习
- `code/`：官方计数器 + 两个自改版本
- 在 Windows 桌面端跑通 App，并截图记录

## 预计时长：2 天

## 验收标准

- 能向他人解释 Flutter 项目里每个文件/目录的作用
- 能说出热重载与热重启的区别
- 不查资料能新建项目并运行到目标设备
