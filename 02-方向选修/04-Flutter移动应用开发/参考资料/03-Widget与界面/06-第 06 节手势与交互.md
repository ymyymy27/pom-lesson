# 第 06 节：手势与交互

## 本节目标

- 掌握点击、长按、双击等基础手势
- 理解手势竞技场与冲突处理
- 实现拖拽（Draggable / DragTarget）

## 一、基础手势：GestureDetector vs InkWell

```dart
// InkWell：带水波纹反馈，Material 风格首选
InkWell(
  onTap: () => openTask(task),
  onLongPress: () => showMenu(context),
  borderRadius: BorderRadius.circular(12),
  child: TaskCard(task: task),
)

// GestureDetector：更底层，可组合任意手势
GestureDetector(
  onTap: () => debugPrint('单击'),
  onDoubleTap: () => debugPrint('双击'),
  onLongPress: () => debugPrint('长按'),
  onPanUpdate: (d) => debugPrint('拖动偏移：${d.delta}'),
  child: container,
)
```

规则：

- 需要 Material 水波纹 → `InkWell` / `ListTile` / 按钮
- 需要任意手势组合 → `GestureDetector`
- 需要原始事件（鼠标悬停、触控点细节）→ `Listener`

## 二、手势竞技场（Gesture Arena）

多个手势同时竞争时，Flutter 有一个"竞技场"裁决：

```text
用户按下 → 多个手势候选进入竞技场
  ├─ 移动超过阈值 → 拖动获胜
  ├─ 快速抬起 → 点击获胜
  ├─ 按住超过 500ms → 长按获胜
  └─ 双击检测窗口内再次按下 → 双击获胜
```

常见冲突案例：

```dart
// 列表项要"点击进入 + 滑动列表"：
ListView.builder(
  itemBuilder: (_, i) => InkWell(
    onTap: () => open(i),
    child: TaskCard(...),          // 内部不要再套 GestureDetector 的 onPan
  ),
)
```

冲突解决思路：

1. 优先用组件内置手势（InkWell 的 tap 与 ListView 的 scroll 天然共存）
2. 在 `GestureDetector` 上设 `behavior: HitTestBehavior.opaque` 修正命中区域
3. 用 `RawGestureDetector` + 自定义手势识别器处理复杂冲突

## 三、拖拽：Draggable + DragTarget

```dart
// 可拖拽的任务卡片
Draggable<Task>(
  data: task,
  feedback: Material(
    elevation: 4,
    borderRadius: BorderRadius.circular(12),
    child: SizedBox(width: 200, child: TaskCard(task: task)),
  ),
  childWhenDragging: Opacity(opacity: 0.3, child: TaskCard(task: task)),
  child: TaskCard(task: task),
)

// 放置目标：比如"已完成"区域
DragTarget<Task>(
  onWillAcceptWithDetails: (details) => details.data.status != TaskStatus.done,
  onAcceptWithDetails: (details) => markDone(details.data),
  builder: (context, candidates, rejected) {
    return Container(
      height: 80,
      color: candidates.isNotEmpty ? Colors.green.withValues(alpha: 0.2) : Colors.grey[200],
      alignment: Alignment.center,
      child: const Text('拖到这里完成'),
    );
  },
)
```

## 四、点击外部关闭 / 弹层交互

```dart
// 点击遮罩关闭
GestureDetector(
  behavior: HitTestBehavior.opaque,
  onTap: () => Navigator.pop(context),
  child: Stack(...),
)
```

## 常见坑

- 在 InkWell 里再套 GestureDetector 的 tap 会导致双重触发
- `onPanUpdate` 与 `onTap` 同时存在时，拖动会"抢走"点击
- `Draggable` 的 feedback 必须是一个独立渲染的 Widget，否则拖拽时会看到原位置残影
