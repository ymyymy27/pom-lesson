# 第 03 阶段：Widget 与 UI 构建

## 学习目标

完成本阶段后，你将能够：
- 区分 StatelessWidget 与 StatefulWidget，理解生命周期
- 熟练使用布局、列表、表单、手势等核心组件
- 使用 Material 3 主题定制亮暗模式
- 编写自定义组件并封装复用
- 实现基础动画与交互动效

## 前置要求

- 完成 Stage 02
- 有 React 组件化经验（本阶段会大量对照）

## 课程内容

| 节 | 课时文件 | 内容 |
|----|-------------|------|
| 1 | `01-第 01 节Stateless 与 StatefulWidget.md` | 组件分类、生命周期、setState、key |
| 2 | `02-第 02 节布局系统.md` | Row/Column/Stack/Expanded/Flexible、约束与尺寸 |
| 3 | `03-第 03 节文本图片与 Material 3 主题.md` | Text/Image/Icon、Material 3、明暗主题 |
