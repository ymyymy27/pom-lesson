# 第 03 节：深链接与页面生命周期

## 本节目标

- 理解深链接（Deep Link）的配置与处理
- 掌握 App 前后台生命周期
- 实现"通知点击直达详情页"

## 一、深链接是什么

深链接 = 用 URL 直接打开 App 内的某个页面：

```text
taskflow://tasks/123        （App 自定义协议）
https://taskflow.app/tasks/123  （Universal Link / App Link）
```

Web 对应：`https://site.com/tasks/123` 直接进入详情页。

## 二、配置（以 Android 为例）

AndroidManifest.xml 的 MainActivity 里声明 intent-filter：

```xml
<intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="taskflow" android:host="tasks" />
</intent-filter>
```

这样 `taskflow://tasks/123` 能唤起 App。

## 三、接收深链接：app_links 包

```powershell
flutter pub add app_links
```

```dart
class DeepLinkService {
  Future<void> init() async {
    // 冷启动（App 被链接唤起）时的链接
    final initial = await getInitialLink();
    if (initial != null) _handle(initial);

    // 热启动（App 已在后台）时的链接流
    linkStream.listen(_handle);
  }

  void _handle(Uri uri) {
    // taskflow://tasks/123 → 提取 id → 导航
    if (uri.pathSegments.isNotEmpty && uri.pathSegments.first == 'tasks') {
      router.push('/tasks/${uri.pathSegments[1]}');
    }
  }
}
```

go_router 天然支持 URL 化路径，深链接解析后直接 `go` 即可。

## 四、页面生命周期：WidgetsBindingObserver

App 前后台切换（类似 Web 的 visibilitychange）：

```dart
class AppLifecycleObserver extends StatefulWidget {
  const AppLifecycleObserver({super.key, required this.child});
  final Widget child;

  @override
  State<AppLifecycleObserver> createState() => _AppLifecycleObserverState();
}

class _AppLifecycleObserverState extends State<AppLifecycleObserver>
    with WidgetsBindingObserver {
  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    super.dispose();
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        debugPrint('回到前台 → 刷新数据/重连 WebSocket');
      case AppLifecycleState.paused:
        debugPrint('进入后台 → 保存草稿/暂停任务');
      case AppLifecycleState.detached:
        debugPrint('即将销毁');
      default:
        break;
    }
  }

  @override
  Widget build(BuildContext context) => widget.child;
}
```

典型用途：

- 回到前台刷新任务列表
- 进入后台自动保存表单草稿
- 重连断开的 WebSocket

## 五、通知点击直达详情页

完整链路（Stage 09 会实现推送，这里先设计）：

```text
推送到达 → 用户点击 → 拿到 payload（任务ID）
  → DeepLinkService / 通知回调 → router.go('/tasks/123')
  → 登录守卫判定 → 详情页加载
```

关键点：**如果 App 没登录，先跳登录页，登录成功后再带"待跳转目标"继续导航**（把 pending location 存在 Provider 里）。
