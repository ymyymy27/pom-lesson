# 第 06 阶段：数据模型与本地存储

## 学习目标

完成本阶段后，你将能够：
- 使用 json_serializable / freezed 设计健壮的数据模型
- 使用 shared_preferences 与 flutter_secure_storage 管理偏好与敏感数据
- 使用 drift 设计表结构、DAO 与数据库迁移
- 管理文件读写与图片缓存策略

## 前置要求

- 完成 Stage 05
- 熟悉 SQL（`99-历史归档/旧版课程说明/工具旧导航/learn-sql`）

- `exercises/`：模型序列化与数据库 CRUD 练习

## 验收标准

- Task 模型支持 JSON 双向转换并有完整单测
- Token 存在安全存储中，重启 App 登录态可恢复
- 任务数据本地可增删改查，数据库迁移方案清晰
