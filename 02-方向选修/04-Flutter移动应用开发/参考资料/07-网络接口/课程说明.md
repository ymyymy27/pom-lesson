# 第 07 阶段：网络与 TaskFlow API 对接

## 学习目标

完成本阶段后，你将能够：
- 使用 dio 封装统一网络层（拦截器、日志、超时、重试）
- 对接现有 Django REST Framework API（列表/详情/分页/错误码）
- 实现 JWT 登录与 Access/Refresh 自动刷新
- 处理文件上传下载与进度展示
- 使用 WebSocket 实现实时通知，设计离线缓存策略

## 前置要求

- 完成 Stage 06
- 已学 `learn-fullstack` Stage 04/05（DRF + JWT）
- 能启动 TaskFlow 后端（`99-历史归档/旧版课程说明/项目原始骨架/TaskFlow/`）
