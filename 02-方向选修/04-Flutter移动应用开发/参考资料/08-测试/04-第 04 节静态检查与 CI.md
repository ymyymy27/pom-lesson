# 第 04 节：静态检查与 CI

## 本节目标

- 配置 lint 规则，让 analyze 无告警
- 在 GitHub Actions 上跑 analyze + test
- 与已有 CI/CD 知识衔接

## 一、flutter analyze 与 lint

`analysis_options.yaml` 是 lint 规则配置（对应 ESLint + Prettier）：

```yaml
include: package:flutter_lints/flutter.yaml

linter:
  rules:
    - avoid_print                    # 用 debugPrint 代替 print
    - prefer_const_constructors      # 能 const 就 const
    - use_key_in_widget_constructors # Widget 构造器要接收 key
    - sort_child_properties_last

analyzer:
  exclude:
    - "**/*.g.dart"                  # 生成代码不检查
    - "**/*.freezed.dart"
  errors:
    invalid_annotation_target: ignore
```

运行：

```powershell
flutter analyze          # 全项目检查
dart format .            # 统一格式
dart format --set-exit-if-changed .   # CI 里检查格式
```

## 二、GitHub Actions 流水线

`.github/workflows/flutter-ci.yml`：

```yaml
name: Flutter CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: subosito/flutter-action@v2
        with:
          channel: stable
          cache: true

      - name: 安装依赖
        run: flutter pub get

      - name: 静态检查
        run: flutter analyze

      - name: 单元测试
        run: flutter test --coverage

      - name: 上传覆盖率
        uses: codecov/codecov-action@v4
        with:
          token: ${{ secrets.CODECOV_TOKEN }}
```

与你的 learn-fullstack CI 对照：

| Web CI | Flutter CI |
|--------|-----------|
| `npm ci` / `pip install` | `flutter pub get` |
| `npm run lint` | `flutter analyze` |
| `npm test` | `flutter test` |
| `npm run build` | `flutter build apk --release` |
| 部署到服务器 | 上传构建产物 / 发布应用商店 |

## 四、常见 CI 坑

- CI 环境默认没有 Android SDK/Windows 桌面工具链：构建 APK 用 `ubuntu-latest` + `flutter-action`（自动带 Android SDK），跑 Windows 测试用 `windows-latest`
- `flutter pub get` 记得缓存：`subosito/flutter-action` 的 `cache: true`
- 国内网络下 CI 拉依赖慢：可在 CI 里配置镜像环境变量

## 动手练习

1. 配置 analysis_options，`flutter analyze` 到 0 告警
2. 在 GitHub 仓库加 Flutter CI（analyze + test）
3. 故意提交一个 lint 错误，观察 CI 变红并修复

## 验收标准

- 本地 analyze 0 告警、格式统一
- PR 自动跑 analyze + test
- 能说出 Flutter CI 与 Web CI 的步骤对应关系
