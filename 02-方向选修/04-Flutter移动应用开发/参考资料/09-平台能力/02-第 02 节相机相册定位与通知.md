## 二、定位：geolocator

```powershell
flutter pub add geolocator
```

```dart
Future<LatLng?> getCurrentLocation() async {
  final enabled = await Geolocator.isLocationServiceEnabled();
  if (!enabled) return null;

  final permission = await Geolocator.checkPermission();
  if (permission == LocationPermission.denied) {
    await Geolocator.requestPermission();
  }

  final pos = await Geolocator.getCurrentPosition(
    locationSettings: const LocationSettings(
      accuracy: LocationAccuracy.medium,
      timeLimit: Duration(seconds: 8),
    ),
  );
  return LatLng(pos.latitude, pos.longitude);
}
```

Web 对照：`navigator.geolocation.getCurrentPosition`，同样的"先申请后使用"。

## 三、本地通知：flutter_local_notifications

```powershell
flutter pub add flutter_local_notifications
```

```dart
final plugin = FlutterLocalNotificationsPlugin();

Future<void> init() async {
  const settings = InitializationSettings(
    android: AndroidInitializationSettings('@mipmap/ic_launcher'),
    iOS: DarwinInitializationSettings(),
  );
  await plugin.initialize(settings);
}

Future<void> showReminder(String title, String body) async {
  const details = NotificationDetails(
    android: AndroidNotificationDetails(
      'task_reminder',          // channel id
      '任务提醒',                 // channel 名
      importance: Importance.high,
      priority: Priority.high,
    ),
    iOS: DarwinNotificationDetails(),
  );
  await plugin.show(
    1001,
    title,
    body,
    details,
  );
}
```

适用场景：截止时间提醒、本地闹钟（不需要服务器）。

## 四、远程推送：Firebase Cloud Messaging

```powershell
flutter pub add firebase_core firebase_messaging
```

```dart
final messaging = FirebaseMessaging.instance;

// 申请通知权限
await messaging.requestPermission();

// 拿设备 Token（后端用来定向推送）
final token = await messaging.getToken();

// 前台收消息
FirebaseMessaging.onMessage.listen((message) {
  showLocalNotification(message.notification!);
});

// 后台点击进入 App
FirebaseMessaging.onMessageOpenedApp.listen((message) {
  final taskId = message.data['task_id'];
  router.push('/tasks/$taskId');
});
```

完整链路（与 Stage 05 深链接衔接）：

```text
后端创建任务 → FCM 推送 → 设备收到 → 通知栏显示
  → 用户点击 → 直达详情页 → 登录守卫 → 加载数据
```
