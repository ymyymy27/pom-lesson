# 第 04 节：响应式与多端适配

## 本节目标

- 让 UI 自适应手机/平板/桌面窗口
- 理解 kIsWeb 与平台差异
- 完成 Web 部署与桌面端适配

## 一、响应式三板斧

```dart
// 1. LayoutBuilder：按可用空间决策
LayoutBuilder(builder: (context, constraints) {
  final isWide = constraints.maxWidth >= 600;
  return isWide ? const WideLayout() : const NarrowLayout();
});

// 2. MediaQuery：屏幕信息
final size = MediaQuery.sizeOf(context);
final orientation = MediaQuery.orientationOf(context);

// 3. 断点常量
enum Breakpoint { compact, medium, expanded }

Breakpoint breakpointOf(double width) {
  if (width < 600) return Breakpoint.compact;   // 手机
  if (width < 840) return Breakpoint.medium;    // 折叠屏/小平板
  return Breakpoint.expanded;                   // 平板/桌面
}
```

对应 Web：CSS 媒体查询 `@media (min-width: 600px)`。

## 二、自适应导航

```dart
class AdaptiveScaffold extends StatelessWidget {
  const AdaptiveScaffold({super.key, required this.child});
  final Widget child;

  @override
  Widget build(BuildContext context) {
    final isWide = MediaQuery.sizeOf(context).width >= 840;
    return Scaffold(
      body: child,
      bottomNavigationBar: isWide
          ? null                                   // 宽屏不用底部栏
          : NavigationBar(...),
      drawer: isWide ? null : const AppDrawer(),
    );
  }
}
```

宽屏体验：

- 侧边 `NavigationRail` + 主内容区
- 列表 + 详情"主从布局"（选中任务在右侧显示详情）
- 表格数据用 `DataTable` 或宽 GridView

## 三、平台差异：kIsWeb 与 TargetPlatform

```dart
import 'package:flutter/foundation.dart';

if (kIsWeb) {
  // Web 行为
} else {
  // 移动/桌面
}

final platform = Theme.of(context).platform;   // android / iOS / windows ...
switch (platform) {
  case TargetPlatform.android:
  case TargetPlatform.iOS:
    // 移动
  case TargetPlatform.windows:
  case TargetPlatform.macOS:
  case TargetPlatform.linux:
    // 桌面
}
```

常见平台差异：

- 桌面：支持右键菜单、快捷键、多窗口尺寸
- Web：CORS、路由是 URL（go_router 天然支持）、无文件系统
- 移动：返回键/手势返回、键盘弹出

## 四、Web 部署

```powershell
flutter build web
# 产物在 build/web，可部署到任意静态服务器（Nginx/GitHub Pages）
```

注意：

- Web 端图片跨域要后端开 CORS
- 刷新深链接要服务器做 SPA fallback（未匹配路径返回 index.html）

## 五、桌面端

```powershell
flutter build windows
# 产物在 build/windows/x64/runner/Release/
```

发布前检查：

- 窗口最小尺寸（`windows/runner/main.cpp` 可调）
- 菜单栏与快捷键
- 多显示器/DPI 缩放

## 动手练习

1. TaskFlow 列表页在宽度 ≥840 时显示 NavigationRail + 主从布局
2. 用 `flutter run -d chrome` 验证 Web 行为（刷新深链接 + CORS）
3. 用 `flutter build windows` 生成桌面版并安装体验

## 验收标准

- 手机/平板/桌面三种宽度都有合理布局
- 能说出 Web 与桌面部署的产物与注意事项
