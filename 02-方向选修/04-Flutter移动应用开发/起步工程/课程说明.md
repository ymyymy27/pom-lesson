# Flutter起步工程

提供Dart对象、内存任务列表、输入校验与Widget测试。先安装学校统一的Flutter SDK，执行 `flutter --version`、`flutter doctor` 确认工具与目标平台可用。

从仓库根目录在PowerShell中运行：

```powershell
Set-Location "02-方向选修/04-Flutter移动应用开发/起步工程"
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

本工程包含Web入口。新增Android或Windows平台时，在个人项目副本中执行 `flutter create --platforms=android,windows .` 生成平台文件，再按平台要求配置工具。

预期：页面能添加任务、切换完成状态、删除任务；空名称显示反馈。内存版本重启清空数据。本地保存与真实API接入是后续独立任务。
