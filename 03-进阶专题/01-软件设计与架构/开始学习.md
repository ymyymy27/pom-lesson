## 每日学习节奏（90 分钟）

```
1. 阅读（30–45 min）
   打开当课 Markdown → 概念 + 类比 + 图示

2. 动手（30–45 min）
   - 设计模式：运行 practice/ 下 Python 示例
   - 架构/系统设计：画架构图、写 ADR
   - 开发方式：对照团队流程思考

3. 反思（10 min）
   - 完成课末自检清单
   - 用 3 句话向「假想同事」解释核心概念（费曼学习法）
   - 关联到自己当前项目
```

每课文档结构统一：

5. **自检清单** — 验证掌握

## 深度学习技巧

- **对比学习：** 每学一种架构/模式，列出「适用 / 不适用」各 3 条
- **项目映射：** 维护「我的项目 ↔ 课程概念」对照表
- **间隔复习：** 第 6、10、12 周回顾前阶段自检清单
- **Architecture Review：** 每完成一个模块，用该模块 Checklist 审查自己的项目
