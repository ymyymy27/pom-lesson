# 架构设计

从单体到分布式，系统学习软件架构的风格、权衡与决策方法。

## 学习路线（推荐顺序）

课程按 **「先风格、后决策、再集成、最后案例」** 组织。文件名编号保留历史顺序，**请按下列阶段学习**：

```
阶段 A · 基础认知
  00 架构全景（质量属性 + 四维基因 + 完整谱系）
  01 单体族（单体 / 分层 / 模块化 / 六边形 / 洋葱 / 整洁）

阶段 B · 分布式核心
  02 分布式族（SOA / 微服务 / 网关 / 发现 / 分布式挑战）
  03 事件与数据族（EDA / 消息驱动 / 事件溯源 / CQRS / CAP / 缓存分片）

阶段 C · 风格精讲（谱系补全）
  07 插件与管道族（微内核 / 管道-过滤器 / 批处理 ETL / 空间型）
  08 现代运行族（无服务器 / Lambda·Kappa 流式 / 服务网格）
  09 数据与前端族（数据网格 / MVC·MVP·MVVM / 微前端 / 集成总线 / P2P）
  10 AI 应用族（RAG / Agent 循环 / 编排器-工作者 / 多智能体 / LLM 网关）

阶段 D · 决策与集成
  04 架构决策与演进（ADR / ATAM / 扩展 / 安全 / 绞杀者）
  06 消息与集成（Kafka vs RabbitMQ / BFF / Saga 实战）

阶段 E · 综合
  05 架构案例实战
  projects/capstone_taskflow.md
```

## 学习目标

- 能根据业务阶段选择合适的架构风格
- 理解微服务、事件驱动等方案的收益与代价
- 会用 ADR 记录和沟通架构决策
- 能对照谱系表，说清任意一种「小架构」拆的是哪个维度
