## 完成标准

- [ ] 绘制限界上下文地图（domain-design）
- [ ] 设计 2 个以上聚合及不变量（domain-design）

- [ ] 设计 CI/CD 流水线概要（dev-methods）

## 建议顺序

```
1. 阅读 capstone_taskflow.md 需求
2. 完成 domain-design 练习（上下文 + 聚合）
3. 完成 architecture 设计（含 ADR）
4. 完成 system-design 估算
5. 对照参考答案，补充遗漏
```
