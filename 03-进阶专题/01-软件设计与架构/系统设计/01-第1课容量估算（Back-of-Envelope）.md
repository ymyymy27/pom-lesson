# 第1课：容量估算（Back-of-Envelope）

## 1. 为什么要估算？

```
面试官：「设计 Twitter」
你：「用 Kafka、Redis、微服务...」（没数字支撑）

vs

你：「1 亿 DAU，每人每天 10 条推文 = 10 亿写/天 ≈ 12,000 写 QPS 峰值...
     存储 5 年约 18 PB，需要分片...」
```

**估算展示：** 工程思维、数量级感觉、设计合理性。

---

## 2. 常用数量级

### 时间

| 单位 | 秒数 |
|------|------|
| 1 天 | 86400 ≈ **10⁵** |
| 1 月 | ≈ 2.5 × 10⁶ |
| 1 年 | ≈ 3 × 10⁷ |

### 数据大小

| 单位 | 大小 |
|------|------|
| 1 KB | 10³ bytes |
| 1 MB | 10⁶ bytes |
| 1 GB | 10⁹ bytes |
| 1 TB | 10¹² bytes |
| 1 PB | 10¹⁵ bytes |

### 延迟（心里有数）

| 操作 | 量级 |
|------|------|
| L1 缓存 | ~1 ns |
| 内存访问 | ~100 ns |
| SSD 随机读 | ~100 μs |
| 同机房网络 | ~0.5 ms |
| 跨洲网络 | ~100 ms |

## 3. QPS 估算模板

```
已知：DAU = 1000 万

假设：
- 每用户每天 20 次请求
- 读写比 100:1
- 峰值 = 平均 × 3

计算：
总请求/天 = 1000万 × 20 = 2 亿
平均 QPS = 2亿 / 86400 ≈ 2300
峰值 QPS = 2300 × 3 ≈ 7000

写 QPS（若 1% 是写）= 70
读 QPS = 6930
```

### 快速心算技巧

- 86400 ≈ 10⁵，2 亿 / 10⁵ = 2000 QPS
- 永远假设 **峰值 = 平均 × 2~5**

---

## 4. 存储估算模板

```
对象：Tweet
- tweet_id: 8 bytes
- user_id: 8 bytes
- text: 280 chars × 2 bytes = 560 bytes
- metadata: ~100 bytes
- 合计：~700 bytes/条

写入量：
- 1 亿 DAU × 2 条/天 = 2 亿条/天
- 存储/天 = 2亿 × 700B ≈ 140 GB/天
- 5 年 = 140 GB × 365 × 5 ≈ 250 TB（未计副本）

加 3 副本：~750 TB
```

### 存储决策

| 估算结果 | 决策 |
|---------|------|
| < 1 TB | 单库 PostgreSQL 够用 |
| 1–100 TB | 分片 + 对象存储 |
| > 100 TB | 必须分片、冷热分离 |

---

## 5. 带宽估算

```
读带宽 = 读 QPS × 平均响应大小
例：7000 QPS × 10 KB = 70 MB/s ≈ 560 Mbps

写带宽 = 写 QPS × 平均请求大小
```

**CDN 场景：** 静态资源流量远大于 API，单独估算。

---

## 6. 服务器数量粗算

```
单台 API 服务器处理能力：~1000 QPS（视逻辑复杂度）
需要台数 = 峰值 QPS / 单台 QPS × 冗余系数(1.5~2)

例：7000 / 1000 × 2 = 14 台 API 服务器
```

**注意：** 这是数量级，实际需压测；但面试中说明思路即可。

## 7. 经典案例速算

### URL 短链

```
1 亿链接/月，5 年保留
存储：1亿 × 12 × 5 = 60 亿条
每条约 100 bytes → 600 GB（单副本）

读：100:1 读写比，_redirect 为主
读 QPS 需单独估算（见第 2 课）
```

### 社交 Feed

```
1 亿用户，每人关注 200 人，30% 日活发帖
写：3000 万帖/天 ≈ 350 写 QPS
读：每用户刷 20 次/天 × 20 条 = 400 亿条/天读 ≈ 460 万读 QPS（需缓存！）
```

## 8. 估算中的假设艺术

**好的假设：**
```
「假设平均推文 200 字符，峰值流量是平均 3 倍，
 如果没有具体数字，我按 1000 万 DAU 估算...」
```

**坏的假设：**
```
沉默不语，或直接说「很大」
```

**原则：** 假设合理、声明假设、数量级正确即可（不必精确到个位）。

## 9. 动手练习

### 练习 1
图片分享 App，500 万 DAU，每人每天上传 2 张图（平均 2MB），浏览 50 张。估算写 QPS、读 QPS、5 年存储。

<details>
<summary>参考答案</summary>

- 上传/天：500万 × 2 = 1000 万张
- 写 QPS：1000万/86400 ≈ 115，峰值 ~350
- 浏览/天：500万 × 50 = 2.5 亿次（读 metadata，非全图）
- 存储/天：1000万 × 2MB = 20 TB/天
- 5 年：20TB × 365 × 5 ≈ 36 PB → 必须对象存储 + CDN

</details>
