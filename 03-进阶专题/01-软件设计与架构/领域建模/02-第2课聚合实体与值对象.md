# 第2课：聚合、实体与值对象

## 1. 战术设计核心概念

```
┌─────────────────────────────────────────────────┐
│                  聚合 Aggregate                   │
│  ┌─────────────┐    ┌──────────────┐            │
│  │ 实体 Entity  │    │ 值对象 VO     │            │
│  │  (有 ID)    │    │  (无 ID, 不可变)│            │
│  │  Order      │───▷│  Money, Address│            │
│  │  LineItem   │    │  OrderStatus   │            │
│  └─────────────┘    └──────────────┘            │
│         聚合根 Aggregate Root = Order              │
└─────────────────────────────────────────────────┘
```

## 2. 实体（Entity）

### 定义
有**唯一标识（ID）**，生命周期内属性可变，用 ID 区分而非属性值。

```python
class Order:
    def __init__(self, order_id: str):
        self.id = order_id  # 身份标识
        self.status = OrderStatus.DRAFT
        self.items: list[LineItem] = []

    def add_item(self, product_id: str, quantity: int, price: Money):
        if self.status != OrderStatus.DRAFT:
            raise DomainError("只能向草稿订单添加商品")
        self.items.append(LineItem(product_id, quantity, price))
```

**判断：** 两个 Order 即使所有属性相同，ID 不同就是不同对象。

## 3. 值对象（Value Object）

### 定义
无 ID，由**属性值**定义相等性，**不可变**，可自由替换。

```python
@dataclass(frozen=True)  # 不可变
class Money:
    amount: Decimal
    currency: str

    def add(self, other: "Money") -> "Money":
        if self.currency != other.currency:
            raise ValueError("货币不一致")
        return Money(self.amount + other.amount, self.currency)

@dataclass(frozen=True)
class Address:
    line1: str
    city: str
    postal_code: str
```

### 实体 vs 值对象

| | 实体 Entity | 值对象 Value Object |
|---|------------|-------------------|
| 标识 | 有 ID | 无 ID，值相等即相等 |
| 可变性 | 可变 | 不可变 |
| 生命周期 | 独立追踪 | 随实体创建/销毁 |
| 示例 | Order, User | Money, Address, Email |

### 何时用值对象

- 概念完整且不需独立追踪：`Money` 比 `amount: float + currency: str` 更安全
- 需要验证逻辑：`Email` 构造时校验格式
- 避免原始类型偏执（Primitive Obsession）

## 4. 聚合（Aggregate）

### 定义
一组相关对象的**一致性边界**，有一个**聚合根**作为唯一入口。

```
Order（聚合根）
├── LineItem（实体，属于 Order）
├── LineItem
├── ShippingAddress（值对象）
└── Money total（值对象）

❌ 不允许：直接从外部修改 LineItem.quantity
✅ 必须：order.change_item_quantity(item_id, new_qty)
```

### 设计原则

1. **小聚合** — 尽量只含 1 个实体 + 值对象；多实体时谨慎
2. **ID 引用** — 聚合间用 ID 关联，不直接持有对象引用
3. **单事务** — 一个事务只修改一个聚合
4. **最终一致** — 跨聚合用 Domain Event

### 聚合边界示例：订单 vs 库存

```
❌ 错误：Order 聚合包含 Inventory
   order.items[0].inventory.stock  # 跨聚合直接访问

✅ 正确：
   Order 聚合：Order + LineItem，只存 product_id
   Inventory 聚合：独立，存 stock
   跨聚合：OrderPlaced 事件 → Inventory 扣减
```

## 5. 不变量（Invariants）

聚合内**必须始终为真**的业务规则。

```python
class Order:
    MAX_ITEMS = 50

    def add_item(self, product_id: str, quantity: int, price: Money):
        # 不变量 1：只有草稿可编辑
        if self.status != OrderStatus.DRAFT:
            raise DomainError("订单已提交，不可修改")

        # 不变量 2：数量必须正数
        if quantity <= 0:
            raise DomainError("数量必须大于 0")

        # 不变量 3：不超过最大行数
        if len(self.items) >= self.MAX_ITEMS:
            raise DomainError(f"最多 {self.MAX_ITEMS} 个商品")

        # 不变量 4：同一商品合并行
        existing = self._find_item(product_id)
        if existing:
            existing.increase_quantity(quantity)
        else:
            self.items.append(LineItem(product_id, quantity, price))

        self._recalculate_total()  # 不变量 5：总额 = 各行之和
```

**所有修改聚合状态的方法都必须守护不变量。**

## 6. 聚合设计反模式

| 反模式 | 问题 | 解决 |
|--------|------|------|
| 大聚合 | Order 含 User、Product、Payment | 拆小，ID 引用 |
| 无聚合根 | 外部直接改 LineItem | 所有修改经 Order |
| 跨聚合事务 | 下单 + 扣库存同一事务 | Domain Event |
| 贫血模型 | Order 只有 getter/setter | 行为放进聚合 |
| 上帝聚合 | 一个 Root 管全部 | 按一致性边界拆分 |

## 7. 完整示例：Order 聚合

```python
from dataclasses import dataclass
from decimal import Decimal
from enum import Enum, auto


class OrderStatus(Enum):
    DRAFT = auto()
    PAID = auto()
    SHIPPED = auto()
    CANCELLED = auto()


@dataclass(frozen=True)
class Money:
    amount: Decimal
    currency: str = "CNY"


class LineItem:
    def __init__(self, product_id: str, quantity: int, unit_price: Money):
        if quantity <= 0:
            raise ValueError("quantity must be positive")
        self.product_id = product_id
        self.quantity = quantity
        self.unit_price = unit_price

    @property
    def subtotal(self) -> Money:
        return Money(self.unit_price.amount * self.quantity, self.unit_price.currency)


class Order:
    def __init__(self, order_id: str, customer_id: str):
        self.id = order_id
        self.customer_id = customer_id
        self.status = OrderStatus.DRAFT
        self._items: list[LineItem] = []
        self._events: list = []

    @property
    def items(self) -> tuple[LineItem, ...]:
        return tuple(self._items)

    @property
    def total(self) -> Money:
        if not self._items:
            return Money(Decimal("0"))
        total = self._items[0].subtotal
        for item in self._items[1:]:
            total = Money(total.amount + item.subtotal.amount)
        return total

    def add_item(self, product_id: str, quantity: int, price: Money):
        if self.status != OrderStatus.DRAFT:
            raise DomainError("Cannot modify non-draft order")
        self._items.append(LineItem(product_id, quantity, price))

    def submit(self):
        if not self._items:
            raise DomainError("Cannot submit empty order")
        if self.status != OrderStatus.DRAFT:
            raise DomainError("Order already submitted")
        self.status = OrderStatus.PAID
        self._events.append(OrderSubmitted(self.id, self.customer_id, self.total))

    def collect_events(self) -> list:
        events, self._events = self._events, []
        return events


class DomainError(Exception):
    pass


@dataclass
class OrderSubmitted:
    order_id: str
    customer_id: str
    total: Money
```

## 8. 动手练习

### 练习 1：识别实体与值对象

银行账户系统（Account、Transaction、Money、AccountNumber），分类并说明理由。

<details>
<summary>参考答案</summary>

- **实体：** Account（有 account_id）、Transaction（有 txn_id）
- **值对象：** Money（amount+currency）、AccountNumber（格式校验，不可变）

</details>

### 练习 2：设计 Task 聚合

TaskFlow 中「任务」聚合：包含标题、描述、状态（Todo/InProgress/Done）、指派人、截止日期。列出不变量和聚合根方法。

<details>
<summary>参考答案</summary>

**不变量：**
- 标题非空，长度 ≤ 200
- 状态转换合法：Todo→InProgress→Done，Done 不可回退（或需 Reopen 命令）
- 截止日期不能早于创建日

**方法：**
- `assign(user_id)`, `start()`, `complete()`, `update_title()`, `set_due_date()`

</details>
