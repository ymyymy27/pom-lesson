# 第 13 阶段：CI/CD & 云部署

## 学习目标

完成本阶段后，你将能够：
- 理解 CI/CD 概念和流程
- 使用 GitHub Actions 实现自动化测试和部署
- 将 TaskFlow 部署到云服务器（Linux VPS）
- 配置域名和 HTTPS（Let's Encrypt）
- 实现自动化部署流水线
