# 第5课：实战部署

## 1. 完整项目：Python Web + PostgreSQL + Redis + Nginx

### 项目架构

```
浏览器 → Nginx(:80) → Web App(:8000) → PostgreSQL(:5432)
                                      → Redis(:6379)

Nginx：反向代理、SSL、静态文件
Web：  Python FastAPI 应用
DB：   PostgreSQL 数据库
Redis：缓存和会话存储
```

### 项目结构

```
my-deploy/
├── app/
│   ├── main.py
│   ├── requirements.txt
│   └── Dockerfile
├── nginx/
│   └── nginx.conf
├── docker-compose.yml
├── .env
├── .env.example
└── .dockerignore
```

### app/main.py

```python
from fastapi import FastAPI
from datetime import datetime
import os

app = FastAPI(title="My App")

@app.get("/")
def root():
    return {
        "message": "Hello from Docker!",
        "time": datetime.now().isoformat(),
        "env": os.getenv("APP_ENV", "development"),
    }

@app.get("/health")
def health():
    return {"status": "healthy"}
```

### app/requirements.txt

```
fastapi==0.109.0
uvicorn==0.27.0
```

### app/Dockerfile

```dockerfile
FROM python:3.12-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### nginx/nginx.conf

```nginx
upstream web_backend {
    server web:8000;
}

server {
    listen 80;
    server_name localhost;

    # 代理 API 请求
    location / {
        proxy_pass http://web_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 流式输出支持
        proxy_buffering off;
        proxy_cache off;
    }

    # 静态文件
    location /static/ {
        alias /app/static/;
        expires 7d;
    }

    # 健康检查
    location /nginx-health {
        return 200 "ok";
        add_header Content-Type text/plain;
    }
}
```

### docker-compose.yml

```yaml
services:
  web:
    build: ./app
    environment:
      - APP_ENV=production
      - DATABASE_URL=postgresql://user:${DB_PASSWORD}@db:5432/mydb
      - REDIS_URL=redis://redis:6379
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_healthy
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 10s

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: user
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U user -d mydb"]
      interval: 5s
      timeout: 5s
      retries: 5
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 3
    restart: unless-stopped

  nginx:
    image: nginx:1.25-alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      web:
        condition: service_healthy
    restart: unless-stopped

volumes:
  postgres_data:
  redis_data:
```

### .env

```bash
DB_PASSWORD=my-secret-password-123
```

### 部署命令

```bash
# 1. 启动所有服务
docker compose up -d --build

# 2. 查看状态
docker compose ps

# 3. 测试
curl http://localhost/
curl http://localhost/health

# 4. 查看日志
docker compose logs -f

# 5. 更新部署
docker compose up -d --build web    # 只重建 web 服务

# 6. 停止
docker compose down
```

## 2. 多阶段构建优化

### 优化前 vs 优化后

```dockerfile
# === 优化前：~1GB ===
FROM python:3.12
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["uvicorn", "main:app", "--host", "0.0.0.0"]

# === 优化后：~150MB ===
FROM python:3.12-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --user --no-cache-dir -r requirements.txt

FROM python:3.12-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
ENV PATH=/root/.local/bin:$PATH
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0"]
```

### 镜像大小对比

```
python:3.12         ~1.0GB
python:3.12-slim    ~150MB    ← 推荐
python:3.12-alpine  ~50MB     ← 可能有兼容问题
```

### 减小镜像的技巧

```dockerfile
# 1. 用 slim 基础镜像
FROM python:3.12-slim

# 2. pip 不缓存
RUN pip install --no-cache-dir -r requirements.txt

# 3. 合并 RUN 命令
RUN apt-get update && \
    apt-get install -y --no-install-recommends curl && \
    rm -rf /var/lib/apt/lists/*

# 4. .dockerignore 排除无关文件
# 5. 多阶段构建
```

## 4. 生产部署清单

### 部署前检查

```
□ Dockerfile 使用 slim 镜像
□ .dockerignore 排除无关文件
□ 环境变量通过 .env 管理，不硬编码
□ .env 已加入 .gitignore
□ 数据库使用命名卷持久化
□ 内部服务不暴露端口到主机
□ 所有服务配置了 restart 策略
□ 关键服务配置了健康检查
□ Nginx 配置了反向代理
□ 日志配置了大小限制
```

### 安全清单

```
□ 使用非 root 用户运行应用
□ 数据库密码使用强密码
□ 只暴露必要端口（80/443）
□ 使用 HTTPS（Let's Encrypt）
□ 定期更新基础镜像
□ 不在镜像中包含密钥
```

### 非 root 用户

```dockerfile
FROM python:3.12-slim
WORKDIR /app

# 创建非 root 用户
RUN useradd -m appuser

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .

# 切换到非 root 用户
USER appuser

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

## 5. 常见问题与排查

### 容器启动失败

```bash
# 查看日志
docker compose logs web

# 查看退出码
docker inspect --format='{{.State.ExitCode}}' 容器名

# 常见退出码
# 0   正常退出
# 1   应用错误
# 137 被 OOM Kill（内存不足）
# 143 收到 SIGTERM（正常停止）
```

### 端口冲突

```bash
# 查看端口占用
# Windows
netstat -ano | findstr :8000

# Linux/Mac
lsof -i :8000

# 解决：改用其他端口
ports:
  - "8001:8000"
```

### 磁盘空间不足

```bash
# 查看 Docker 磁盘占用
docker system df

# 清理
docker system prune -a          # 清理所有未使用资源
docker volume prune             # 清理未使用的卷
docker builder prune            # 清理构建缓存
```

### 容器间网络不通

```bash
# 确认在同一网络
docker network inspect 网络名

# 测试连通性
docker exec web ping db
docker exec web curl http://db:5432
```
