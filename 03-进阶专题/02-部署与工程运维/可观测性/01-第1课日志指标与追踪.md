# 第1课：日志、指标与追踪

## 1. 结构化日志

```python
import structlog

logger = structlog.get_logger()

logger.info(
    "task_created",
    task_id="task_abc",
    user_id="user_42",
    project_id="proj_xyz",
    trace_id="trace_123",  # 关联追踪
)
# {"event": "task_created", "task_id": "task_abc", ...}
```

**原则：**
- 生产环境用 INFO 及以上，DEBUG 仅开发
- 不记录密码、Token、PII
- 每条日志带 `request_id` / `trace_id`

## 2. Prometheus 指标

### 四种类型

| 类型 | 用途 | 示例 |
|------|------|------|
| Counter | 只增计数 | 请求总数、错误数 |
| Gauge | 可增可减 | 内存使用、队列长度 |
| Histogram | 分布统计 | 延迟 P50/P95/P99 |
| Summary | 类似 Histogram | 客户端分位数 |

```python
from prometheus_client import Counter, Histogram

REQUEST_COUNT = Counter("http_requests_total", "Total requests", ["method", "endpoint"])
REQUEST_LATENCY = Histogram("http_request_duration_seconds", "Latency", ["endpoint"])

@REQUEST_LATENCY.labels(endpoint="/tasks").time()
def list_tasks():
    REQUEST_COUNT.labels(method="GET", endpoint="/tasks").inc()
    ...
```

## 3. OpenTelemetry 追踪

```python
from opentelemetry import trace
from opentelemetry.instrumentation.fastapi import FastAPIInstrumentor

tracer = trace.get_tracer(__name__)

@app.get("/tasks/{task_id}")
async def get_task(task_id: str):
    with tracer.start_as_current_span("get_task") as span:
        span.set_attribute("task.id", task_id)
        task = await db.fetch_task(task_id)
        return task

FastAPIInstrumentor.instrument_app(app)  # 自动 HTTP 追踪
```

Trace 结构：
```
HTTP GET /tasks/abc
  └── get_task
        └── db.fetch_task
```

## 4. 三支柱关联

```
同一 request_id / trace_id 串联：

Log:  {"trace_id": "abc", "msg": "task not found"}
Metric: http_requests_total{status="404"} 
Trace: span "get_task" status=NOT_FOUND
```
