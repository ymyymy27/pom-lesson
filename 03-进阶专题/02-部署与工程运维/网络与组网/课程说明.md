> 面向"组内成员在不同网段、不同地区合作开发"的实战课程。

## 为什么需要这门课

团队成员分布在不同的网段和地区时，会遇到这些典型问题：

- 家宽、公司内网、云服务器彼此之间"默认不通"；
- 想在本地调试微信/钉钉回调，对方却访问不到 `localhost`；
- 需要连公司内网的数据库，却不知道怎么安全地建立隧道；
- 两地环境变量、端口、地址不一致，联调时互相"甩锅"。

这门课从网络原理出发，逐步讲到 SSH 隧道、VPN、内网穿透和协作工作流，
最终让每个人都具备"自己打通网络"的能力。

## 学习顺序建议

```
01 网络基础 → 02 NAT 与网段 → 03 SSH 隧道 → 04 VPN/Mesh
        ↓
05 NAT 穿透 → 06 内网穿透工具 → 07 协作实战 → 08 安全与排查
```

- 第 1、2 课是"为什么连不通"的原理，必须掌握；
- 第 3、4、6 课是三种常用打通手段，按需选用；
- 第 5 课解释工具背后的原理，遇到直连失败时有用；
- 第 7 课是综合实战，建议和同事一起完成；
- 第 8 课的安全部分**不是可选项**，正式组网前必须过一遍。

## 前置要求

- 能打开终端（Windows PowerShell / macOS Terminal / Linux Shell）；
- 会基本命令：`cd`、`ls`、`ping`（可先学 `learn-cli` 或 `learn-shell`）；
- 准备至少两台设备：例如本机 + 一台云服务器，或本机 + 同事的电脑。
