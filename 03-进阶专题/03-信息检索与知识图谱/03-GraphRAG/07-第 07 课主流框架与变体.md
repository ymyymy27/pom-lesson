# 第 07 课：主流框架与变体

## 1. 核心问题

GraphRAG 已经不是一个算法，而是一个家族。这一课横向对比
Microsoft GraphRAG、LightRAG、HippoRAG、KAG、nano-graphrag 等，
帮你在选型时看清各自的取舍。

## 2. 逐个拆解

### 2.1 Microsoft GraphRAG

- 官网：github.com/microsoft/graphrag
- 定位：企业级、大规模、全局问答
- 核心：Leiden 社区 + 社区摘要 + Local/Global/DRIFT Search
- 优点：全局能力最强，社区生态成熟（ByoG、批量索引）
- 缺点：索引成本高，管道复杂，修改门槛高
- 适合：10 万+ token 语料、需要全局综述的企业知识库

### 2.2 LightRAG（EMNLP 2025 Findings）

- 核心：**双层次检索（Dual-level Retrieval）**
  - 低层（Low-level）：具体实体与关系
  - 高层（High-level）：主题与抽象概念
- 实现：图结构 + 向量表示融合，支持增量更新
- 优点：轻量、索引快、增量友好、支持本地模型
- 缺点：全局综述能力弱于 Microsoft GraphRAG
- 适合：中小规模、要快速上线、需要频繁更新文档的场景

### 2.3 HippoRAG（NeurIPS 2024）与 HippoRAG 2

- 核心：知识图谱 + **个性化 PageRank（PPR）**
- 思路：离线用 LLM 建 KG，在线把问题中的实体作为种子跑 PPR，
  一次性完成多跳检索，无需迭代
- 论文数据：2WikiMultiHopQA 上 Recall@5 达 89.5（+21.6 vs ColBERTv2）
- 优点：单步多跳、推理成本低、可解释（路径即证据）
- 缺点：依赖抽取质量；复杂开放问题效果有限
- HippoRAG 2（2025）：引入"页面片段"检索与跨文档交互，进一步提分

### 2.4 KAG（蚂蚁集团，ACM Web Conf 2025）

- 核心：**逻辑形式引导的生成**（Logical-form-guided）
- 底座：OpenSPG 语义图谱引擎
- 三个创新：
  1. 互索引（Mutual Indexing）：文档与图谱双向链接
  2. Schema 约束的知识构建：解决抽取质量
  3. 逻辑形式求解：把问题转成可执行的逻辑查询，支持数值/时序推理
- 适合：金融、医疗等**专业域、需要严谨逻辑**的场景
- 后续：KAG-Thinker（2025）把推理与知识检索进一步结合

### 2.5 nano-graphrag

- 定位：GraphRAG 的可读教学实现（约 1100 行，异步）
- 特点：轻量、可 hack、保留 Local/Global 检索思想
- 适合：学习源码、二次开发原型

### 2.6 LlamaIndex PropertyGraphIndex

- 把"属性图"作为索引的一等公民，支持自定义抽取与查询
- 适合：已经用 LlamaIndex 的团队快速集成

### 2.7 Neo4j GraphRAG / neo4j-genai

- 提供 Cypher 模板、向量+图混合检索、LangChain 集成
- 适合：已有 Neo4j 基础设施的团队

## 4. 2025~2026 趋势

1. **Agentic GraphRAG**：检索不再是单次调用，而是
   "计划 → 检索 → 验证 → 再检索"的循环，DRIFT 是代表。
2. **多 Agent + 图**：不同 Agent 分管建图、检索、验证；
   2026 年有工作把 GraphRAG + Multi-Agent 用于多模态/Text-to-SQL，
   多跳 QA 相对提升 30%~46%（不同论文口径，需谨慎引用）。
3. **上下文优化**：用图结构裁剪检索上下文，论文报告可减少 19%~53% token。
4. **内存化图**：HippoRAG 2 等把图当作 LLM 的"长期记忆"，
   与 Agent 记忆系统融合。
5. **专业域深耕**：KAG 模式（逻辑形式 + 图）在金融医疗加速落地。

## 5. 选型决策树

```
语料规模 < 100 文档？
  ├─ 是 → 关系复杂吗？
  │        ├─ 否 → 纯向量 RAG 就够
  │        └─ 是 → LightRAG / LlamaIndex PropertyGraph
  └─ 否 → 需要全局综述吗？
           ├─ 是 → Microsoft GraphRAG
           └─ 否 → 多跳事实问答？→ HippoRAG
                   专业域严谨推理？→ KAG
                   都要一点 → Hybrid：向量 + 图 + Rerank 自研
```
