# 星辰科技内部资料（虚构样例）

## 组织架构
李四（研发总监）管理研发部。张三（后端工程师）汇报给李四，王五（前端工程师）也汇报给李四。赵六（市场总监）管理市场部。

## 项目概览
研发部拥有两个项目：项目X（智云平台）和项目Y（星图分析）。市场部拥有项目Z（品牌官网）。

## 智云平台（项目X）
项目X使用 Python、FastAPI、PostgreSQL 和 Redis 构建。张三和王五都在项目X上工作。张三负责后端接口，王五负责前端页面。

## 星图分析（项目Y）
项目Y使用 Python、ClickHouse 和 React 构建。李四担任项目Y的负责人。

## 品牌官网（项目Z）
项目Z使用 Next.js 和 Vercel 部署。赵六负责项目Z的运营。

## 技术栈说明
公司后端主要使用 Python 与 FastAPI，前端使用 React 与 TypeScript，数据存储使用 PostgreSQL、Redis、ClickHouse。

## 考勤与年假制度
员工入职满一年可享受5天带薪年假，满三年10天，满五年15天。年假需提前3个工作日在 OA 系统申请。

## 报销制度
日常报销单笔不超过5000元由部门主管审批；超过5000元需要财务总监审批。
