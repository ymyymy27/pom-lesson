## 什么是 MCP？

MCP (Model Context Protocol) 是 Anthropic 提出的开放协议，目标是**标准化 LLM 与外部工具/数据源的连接方式**。

类比：USB 统一了设备连接标准，MCP 统一了 AI 工具连接标准。

- 无 MCP：每个 AI 应用都要单独适配每个工具（N×M 问题）
- 有 MCP：工具实现一次 MCP Server，所有 AI 应用都能用（N+M 方案）
