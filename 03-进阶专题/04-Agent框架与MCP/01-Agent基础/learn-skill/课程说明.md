## 什么是 Agent Skill？

Agent Skill（智能体技能）是上下文工程（Context Engineering）中的最新技术，
它将**专业知识 + 工作流规范 + 使用时机**打包成一个可复用的 Markdown 模块，
让 AI 工具（Claude、Copilot、Cursor、Windsurf 等）能按你定义的方式执行特定任务。

简单来说：**Skill = 可复用的、模块化的、按需加载的高级提示词系统**

## 前置知识

- 了解基本的 Markdown 语法
- 使用过至少一种 AI 编程助手（如 Claude、Copilot、Cursor、Windsurf）
- 不需要编程基础，但有的话会更好理解
