# 图像生成 从零开始深入学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_image_gen_overview.py` | 图像生成概述（发展/模型/原理） |
| 第2课 | `02_dalle_and_api.py` | DALL-E / API 方式生成图像 |
| 第3课 | `03_stable_diffusion.py` | Stable Diffusion 本地部署与使用 |
| 第4课 | `04_prompt_engineering.py` | 图像生成 Prompt 工程 |
| 第5课 | `05_controlnet.py` | ControlNet 精确控制生成 |
| 第6课 | `06_image_editing.py` | 图像编辑（Inpainting/Outpainting/风格迁移） |
| 第7课 | `07_image_gen_project.py` | 完整项目：AI 绘画工作站 |
