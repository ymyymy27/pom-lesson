## 1. 为什么需要量化？

| 精度 | 7B 权重大小 | 典型 GPU |
|------|------------|---------|
| FP16 | ~14 GB | RTX 4090 24GB |
| INT8 | ~7 GB | RTX 3090 24GB |
| INT4 (AWQ/GPTQ) | ~4.5 GB | RTX 3060 12GB |
| FP8 | ~7 GB | H100 / L40S |

量化 = **用更低精度存权重**，换取更小显存和更快速度，精度略有下降。

---

## 2. vLLM 支持的量化格式

| 格式 | 启动方式 | 说明 |
|------|---------|------|
| AWQ | `--quantization awq` | 激活感知，精度较好，**推荐** |
| GPTQ | `--quantization gptq` | 经典 4-bit，生态广 |
| FP8 | `--quantization fp8` | H100 等原生 FP8 硬件 |
| bitsandbytes | `--quantization bitsandbytes` | 动态量化 |
| 压缩 tensors | `--quantization compressed-tensors` | 新格式 |

```bash
# AWQ 量化模型（从 HuggingFace 下载预量化权重）
python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen2.5-7B-Instruct-AWQ \
    --quantization awq \
    --dtype float16 \
    --port 8000
```

**规则：** 模型权重格式必须与 `--quantization` 匹配，否则加载失败或输出异常。

---

## 3. 量化选型建议

```
显存够用（7B + 24GB）？
  ├─ 是 → FP16/BF16，精度最好
  └─ 否 → AWQ 4-bit

需要 70B 单节点？
  └─ AWQ/GPTQ 4-bit + TP=4/8

有 H100/L40S？
  └─ 优先 FP8（速度与精度平衡好）
```

---

## 4. 张量并行（Tensor Parallelism）

将**单层权重**切分到多 GPU，All-Reduce 通信：

```bash
# 2 卡跑 14B 或加速 7B
python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen2.5-14B-Instruct \
    --tensor-parallel-size 2 \
    --port 8000
```

```python
from vllm import LLM

llm = LLM(
    model="Qwen/Qwen2.5-72B-Instruct-AWQ",
    tensor_parallel_size=4,
    quantization="awq",
    max_model_len=8192,
)
```

| TP 大小 | 适用 |
|---------|------|
| 2 | 14B FP16、单卡放不下 |
| 4 | 32B–70B INT4 |
| 8 | 70B+ FP16 |

**注意：** TP 需要 GPU 间高速互联（NVLink 理想）；跨节点 TP 延迟高。

---

## 5. 流水线并行（Pipeline Parallelism）

将**不同层**分配到不同 GPU，适合超大模型：

```bash
python -m vllm.entrypoints.openai.api_server \
    --model meta-llama/Llama-3.1-405B-Instruct-FP8 \
    --tensor-parallel-size 8 \
    --pipeline-parallel-size 2 \
    --port 8000
```

TP × PP = 总 GPU 数（如 TP=4, PP=2 → 8 GPU）。

---

## 6. 专家并行（MoE 模型）

Mixtral、DeepSeek-MoE 等模型激活部分专家，vLLM 支持 Expert Parallelism：

```bash
python -m vllm.entrypoints.openai.api_server \
    --model mistralai/Mixtral-8x7B-Instruct-v0.1 \
    --tensor-parallel-size 2 \
    --enable-expert-parallel \
    --port 8000
```

---

## 7. 投机解码（Speculative Decoding）

用小模型（draft）快速生成候选 token，大模型（target）批量验证：

```bash
python -m vllm.entrypoints.openai.api_server \
    --model Qwen/Qwen2.5-7B-Instruct \
    --speculative-model Qwen/Qwen2.5-0.5B-Instruct \
    --num-speculative-tokens 5 \
    --port 8000
```

**效果：** Decode 阶段延迟降低 1.5–2.5x，几乎不损精度。

---

## 8. 多 GPU 配置决策

```
模型能放进 1 卡？
  └─ TP=1（最简单）

单卡放不下，有多卡 NVLink？
  └─ TP=2/4/8

超大模型（405B）？
  └─ TP + PP 组合

MoE 模型？
  └─ 加 --enable-expert-parallel
```
