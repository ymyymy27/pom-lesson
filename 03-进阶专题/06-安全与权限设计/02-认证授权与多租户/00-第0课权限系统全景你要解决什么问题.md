# 第0课：权限系统全景：你要解决什么问题

## 1. 一句话解释

权限系统是"一套系统里谁能看到什么、能做什么、能操作哪些数据"的总和；多租户是"一套系统如何安全地服务多个客户"的架构问题。两者叠加，构成了企业级 SaaS 的地基。

## 2. 类比

把系统想象成一栋大楼：

```
认证 = 刷卡确认你是谁
授权 = 你能进哪些房间（门禁）
数据权限 = 同一间办公室，不同级别能看不同的文件柜
多租户 = 同一栋楼里多家公司租用，互不串门
审计 = 每扇门的刷卡记录
```

多租户不是独立于权限之外的新系统，而是给所有权限判断加了一个"先确认属于哪个租户"的前置条件。

## 3. 权限系统的五大支柱

| 支柱 | 回答的问题 | 本课程对应 |
|------|-----------|-----------|
| 认证（Authentication） | 你是谁？ | 第1课 |
| 授权（Authorization） | 你能做什么操作？ | 第2课 |
| 组织模型（Org Model） | 组织里的人和岗位怎么组织？ | 第3课 |
| 数据权限（Data Permission） | 你能看到哪些行、哪些字段？ | 第4课 |
| 审计（Audit） | 出事了能不能追溯？ | 第7课 |

多租户横切所有支柱：认证要区分租户，授权要按租户分角色，数据权限要按租户隔离，审计要记录租户。

