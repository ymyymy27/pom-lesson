# 实战练习

本目录提供 3 个可运行的 Python 示例，覆盖本课程的核心机制。全部使用标准库，无需安装依赖。

```powershell
python rbac_demo.py
python data_scope_demo.py
python multitenant_demo.py
```

| 文件 | 主题 | 对应课程 |
|------|------|----------|
| `rbac_demo.py` | 用户-角色-权限 + 角色继承 | 第2课 |
| `data_scope_demo.py` | 数据范围（本人/部门/部门及下属/全部） | 第4课 |
| `multitenant_demo.py` | 租户上下文 + 共享表隔离 + IDOR 防护 | 第6课 |

建议先阅读对应课程，再运行示例，最后修改数据验证自己的理解。
