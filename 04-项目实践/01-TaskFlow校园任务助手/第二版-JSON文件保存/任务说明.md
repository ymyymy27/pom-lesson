# 第二版-JSON文件保存：里程碑任务

先完成本阶段对应的基础课或 Web 方向桥接课，再运行参考实现。参考实现的入口是 `任务助手.py`（命令行阶段）或 `manage.py`（Django阶段）。

## 从起步文件开始

复制[起步练习.py](起步练习.py)到个人作业目录，实现以下契约：去除首尾空白；空名称抛出ValueError。

## 独立扩展

在个人项目副本中加入“仅查看未完成任务”的功能。说明数据在哪里筛选，已有功能是否受影响，并为正常输入、空列表和不存在的编号准备检查。

## 验收

- 完整运行新增、列出、完成任务流程；文件与数据库版本重启后保留数据。
- 对空名称、不存在的编号给出可理解反馈。
- 附上运行命令、实际输出、一次失败记录与修复说明。
- 能解释起步函数与参考实现的关系，现场修改一个条件。
