# TaskFlow校园任务助手

一个项目逐步学习内存、文件、数据库和Web应用。前三版只需要 Python 标准库。建议在自己的项目副本中练习。

## 什么时候开始

| 版本 | 先修验收 | 所需知识 |
|---|---|---|
| 内存列表 | B01–B14通过 | 变量、条件、循环、容器、函数与模块 |
| JSON文件保存 | B01–B18通过 | 文件读写、JSON、异常与调试 |
| SQLite与协作 | B01–B29通过 | 关系表、SQL、约束与事务 |
| Django网页应用 | 基础必修B01–B32及Web方向W01–W05通过 | HTTP、路由、视图、ORM、接口联调、测试与基础安全 |

Django版在Web方向后期引入，W06组织交付与复盘。基础课先完成小程序练习，再逐步进入前三个版本。

## 第一版：内存列表

从仓库根目录执行：

```powershell
python "04-项目实践/01-TaskFlow校园任务助手/第一版-内存列表/任务助手.py" --demo
```

预期显示一条完成任务和一条待办任务。去掉 `--demo` 进入交互模式；支持 add、list、done、quit。退出后数据消失，这是这一版的设计。

## 第二版：JSON文件保存

```powershell
python "04-项目实践/01-TaskFlow校园任务助手/第二版-JSON文件保存/任务助手.py" --file "tmp/我的任务.json" add --title "完成实验"
python "04-项目实践/01-TaskFlow校园任务助手/第二版-JSON文件保存/任务助手.py" --file "tmp/我的任务.json" list
python "04-项目实践/01-TaskFlow校园任务助手/第二版-JSON文件保存/任务助手.py" --file "tmp/我的任务.json" done --id 1
```

新文件的首个编号为1；已有文件请使用 list 输出的真实编号。多次启动后任务仍保留。损坏的 JSON 会报告错误并保留原文件。此版供单人单进程练习。

## 第三版：SQLite与协作

```powershell
python "04-项目实践/01-TaskFlow校园任务助手/第三版-SQLite与协作/任务助手.py" --db "tmp/我的任务.sqlite3" add --title "复习SQL"
python "04-项目实践/01-TaskFlow校园任务助手/第三版-SQLite与协作/任务助手.py" --db "tmp/我的任务.sqlite3" list
```

同样支持 done、delete 和 `--id`。SQL 使用参数化查询，编号来自数据库。删除练习只使用自己创建的数据。

## 第四版：Django网页应用

本阶段是Web方向综合项目。达到上表先修条件后，先读[里程碑任务](第四版-Django网页应用/任务说明.md)，再按下面的命令核对参考实现。

在 PowerShell 中进入本版目录，然后创建独立环境：

```powershell
Set-Location "04-项目实践/01-TaskFlow校园任务助手/第四版-Django网页应用"
python -m venv .venv
& ".venv/Scripts/python.exe" -m pip install -r requirements.txt
& ".venv/Scripts/python.exe" manage.py migrate
& ".venv/Scripts/python.exe" manage.py test
& ".venv/Scripts/python.exe" manage.py runserver 127.0.0.1:8000
```

打开浏览器访问 `http://127.0.0.1:8000/`，添加、完成、恢复和删除任务。结束服务按 Ctrl+C。网页包含 CSRF 校验和输入验证，接口使用 `/tasks` 与 `/tasks/<编号>`，`/health` 返回健康状态。

这是本机单人教学应用，默认没有账号体系。权限、部署和多人隔离在进阶课程中学习。
