# RAG课程资料问答助手

这是不需要账号或模型下载的离线检索实验。输入问题，检索五段教学资料并显示来源；当前回答是资料摘录，不是真实LLM生成。

## 运行与比较

从仓库根目录执行：

```powershell
python "04-项目实践/02-RAG课程资料问答助手/问答助手.py" "Git提交前检查什么" --method keyword
python "04-项目实践/02-RAG课程资料问答助手/问答助手.py" "Git提交前检查什么" --method vector
python "04-项目实践/02-RAG课程资料问答助手/评估.py"
```

预期主要来源为“课文-02”。资料外的问题如“火星公转周期”应没有来源并说明缺少依据。

## 两种检索的区别

keyword 使用词项重叠数；vector 使用字符二元组和英文词的TF-IDF向量余弦相似度。它是词项向量实验，不具备预训练语义Embedding的能力。比较排名与失败案例，比单纯追求分数更重要。

## 独立任务与提示

复制项目到个人目录，先实现按关键词匹配的 `retrieve`，再加入归一化向量打分。新建至少4个问题，包括一个无答案问题。尝试同义词改写，说明两种检索的局限。

起点：[起步练习](起步练习.py)。参考：[问答助手](问答助手.py)。问题标注：[评估问题](评估问题.json)。提示：先检查分词结果，再检查是否取到了正确来源；没有来源时不要调用生成环节。

## 后续真实模型实验

完成离线验收后，可在教师提供的接口条件下实现 `generate(question, context)`，把检索命中的内容作为上下文。保留模拟实现作为测试替身，记录接口条件、耗时、失败处理与费用。该扩展不影响离线必做任务，不能把模拟结果当成真实模型效果。

## 验收

输出包含答案模式、来源编号和分数；无依据时拒绝回答；关键词与向量两种方法都有评估记录；新增资料后重新运行原问题，解释退化或改进。

资料为本仓库原创教学样例，可直接改写用于实验。
