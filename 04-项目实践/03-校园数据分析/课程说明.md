# 校园数据分析

数据为教学合成样例。目标是读取CSV、检查输入、分组统计并写出有边界的结论。

从仓库根目录运行：

```powershell
python "04-项目实践/03-校园数据分析/分析.py"
python "04-项目实践/03-校园数据分析/分析.py" --output "tmp/学习分析报告.md"
```

预期：Python共3条记录、100分钟、完成率66.7%；SQL共60分钟；Git共40分钟。报告表格可以直接用Markdown查看。

## 独立任务

从[起步练习](起步练习.py)实现平均学习时长，再在自己的CSV中加入一条记录并解释结果变化。随后测试空数据、错误列名、负数和非数字；程序应说明问题，不能悄悄忽略错误行。

提示：总时长除以记录数；空列表不能直接除以0。参考实现的 [summarize](分析.py) 负责数据验证与统计，report 负责展示。

## 验收

交付自己的CSV、报告、错误输入证据；解释完成率的分母；说明小样本与数据来源的限制。数据分析方向另完成[分类基线](分类基线.py)，比较训练集与测试集结果，不能用测试数据调阈值。
