## 学习方式

- Markdown 文档 + 终端动手练习
- Windows 用户建议用 Git Bash 或 WSL
- 每条命令都动手试一遍，看输出
- 按顺序学习，每课都有动手练习

## 环境说明

- **Windows**: Git Bash（安装 Git 自带）或 WSL
- **Mac/Linux**: 自带终端即可
- PowerShell 命令有差异，本课以 Bash 为主
