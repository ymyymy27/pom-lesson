# Lesson 1: Shell 基础概念

> 理解 Shell 是什么，它如何工作，以及为什么命令行如此强大

---

## 1.1 Shell 是什么？

**Shell（命令行解释器）** 是一种计算机程序，它在你（用户）和操作系统内核之间充当翻译官的角色。

```
图形界面（GUI）的工作方式：
┌─────────────────────────────────────────┐
│     你 ←→ 鼠标点击 ←→ 图形窗口 ←→ 系统   │
└─────────────────────────────────────────┘

命令行界面（CLI）的工作方式：
┌─────────────────────────────────────────┐
│     你 ←→ 文字命令 ←→ Shell ←→ 操作系统  │
└─────────────────────────────────────────┘
```

### Shell 的核心功能

1. **读取命令**：从你输入的文字中提取命令
2. **解析执行**：理解命令的含义
3. **调用系统**：将命令翻译成系统调用
4. **返回结果**：将输出显示给你

---

## 1.2 命令行 vs 图形界面

### GUI（图形用户界面）的特点

| 优点 | 缺点 |
|-----|------|
| 直观可视化 | 难以自动化 |
| 容易上手 | 操作速度慢 |
| 所见即所得 | 难以远程操作 |
| 适合简单任务 | 批量处理困难 |

### CLI（命令行界面）的特点

| 优点 | 缺点 |
|-----|------|
| 强大的自动化能力 | 学习曲线较陡 |
| 精确控制 | 不直观 |
| 可组合使用（管道） | 需要记忆命令 |
| 适合复杂任务 | 错误信息可能晦涩 |
| 远程操作友好 | |

**什么时候用命令行？**
- 批量处理文件（重命名 1000 个文件）
- 自动化重复任务（每天定时备份）
- 精确控制系统（Docker 容器管理）
- 远程服务器操作（SSH 连接）
- 开发工作流（Git, npm, pip）

---

## 1.3 Windows 上的 Shell 选项

### CMD（命令提示符）

Windows 最传统的命令行工具，历史可追溯到 MS-DOS 时代。

```
启动方式：
1. Win + R → 输入 cmd → 回车
2. 开始菜单 → Windows 系统 → 命令提示符
```

**特点**：
- 命令较为简单（如 `dir`, `copy`, `del`）
- 语法偏向 DOS
- 不支持管道对象的概念

### PowerShell

Windows 7 起引入的新一代 Shell，是 CMD 的超集和升级。

```
启动方式：
1. Win + R → 输入 powershell → 回车
2. 开始菜单 → Windows PowerShell
3. 右键开始菜单 → 终端（Windows 11）
```

**特点**：
- **面向对象**：命令返回的是 .NET 对象，不是纯文本
- **一致性**：Verb-Noun 命名规范
- **管道强大**：可以像编程一样组合命令
- **跨平台**：PowerShell Core (7+) 支持 macOS 和 Linux

### Windows Terminal（推荐）

微软现代化的终端应用，可以同时运行 CMD、PowerShell、Azure Cloud Shell 等多个 Shell。

```
获取方式：
- Microsoft Store 免费下载
- GitHub: microsoft/terminal
```

**推荐配置**：将 Windows Terminal 设为默认终端，配合 PowerShell 7 使用。

### Bash

Linux/macOS 默认的 Shell。Windows 上可以通过以下方式使用：

- **WSL (Windows Subsystem for Linux)**：在 Windows 中运行真正的 Linux
- **Git Bash**：随 Git 安装的轻量 Bash 环境
- **Cygwin**：模拟 Linux 环境的工具

## 1.4 PowerShell 的工作原理

```
当你输入命令：
    Get-ChildItem -Path C:\ -Filter *.txt -Recurse

PowerShell 的处理流程：
┌────────────────────────────────────────────────────────┐
│                                                        │
│  1. 解析                                               │
│     Get-ChildItem -Path C:\ -Filter *.txt -Recurse    │
│     ↓                                                  │
│  2. 查找命令                                           │
│     Get-ChildItem 是一个别名(alias)                   │
│     真实命令可能是 Microsoft.PowerShell.Management\    │
│       Get-ChildItem                                   │
│     ↓                                                  │
│  3. 执行                                               │
│     调用 .NET Framework 获取文件系统信息              │
│     返回 [System.IO.FileInfo] 和 [System.IO.DirectoryInfo] 对象
│     ↓                                                  │
│  4. 格式化输出                                         │
│     自动以表格形式显示对象的属性                       │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 关键概念：对象 vs 文本

CMD 中的命令返回的是**纯文本**：
```
CMD 输出：
    Volume Serial Number is XXXX-XXXX
    Directory of C:\
    01/01/2024  12:00 AM    <DIR>          Users
    01/01/2024  12:00 AM    <DIR>          Windows
```

PowerShell 中的命令返回的是**对象**：
```
PowerShell 输出：
    Directory: C:\
Mode                LastWriteTime         Length Name
----                -------------         ------ ----
d-----        1/1/2024   12:00 AM                Users
d-----        1/1/2024   12:00 AM                Windows
```

**对象的优势**：可以像访问对象属性一样访问文件信息（Size, LastWriteTime, Name），这使得后续的筛选、排序、分组变得极其方便。

## 1.5 命令的组成结构

### CMD 风格（动词直接对应操作）

```
命令 [参数] [目标]

dir /s /b C:\*.txt        # 列出 C 盘所有 txt 文件
copy file1.txt file2.txt  # 复制文件
del *.log                 # 删除所有 log 文件
```

### PowerShell 风格（Verb-Noun 规范）

```
Verb-Noun -ParameterName ParameterValue

Get-ChildItem -Path C:\ -Filter *.txt -Recurse
  |              |         |          |
  |              |         |          └─ 递归搜索
  |              |         └─ 过滤器（只选 txt）
  |              └─ 目标路径
  └─ 动作（获取子项）
```

### PowerShell 常用 Verb（动词）

| Verb | 含义 | 示例 |
|-----|------|------|
| **Get** | 获取/查询 | Get-Process, Get-Service |
| **Set** | 设置 | Set-Location, Set-Variable |
| **New** | 创建 | New-Item, New-Object |
| **Remove** | 删除 | Remove-Item, Remove-Variable |
| **Copy** | 复制 | Copy-Item |
| **Move** | 移动 | Move-Item |
| **Rename** | 重命名 | Rename-Item |
| **Start** | 启动 | Start-Process, Start-Service |
| **Stop** | 停止 | Stop-Process, Stop-Service |
| **Restart** | 重启 | Restart-Computer |
| **Test** | 测试 | Test-Path, Test-NetConnection |
| **Invoke** | 调用/执行 | Invoke-WebRequest, Invoke-Expression |
| **Format** | 格式化 | Format-Table, Format-List |
| **Out** | 输出到 | Out-File, Out-Host |

## 1.6 别名（Alias）

PowerShell 为常用命令提供了简短的别名，兼容 CMD 和 Bash 用户。

### 查看所有别名

```powershell
Get-Alias
```

### 常用别名对照

| PowerShell | CMD | Bash | 功能 |
|-----------|-----|------|------|
| `Get-ChildItem` | `dir` | `ls` | 列出目录内容 |
| `Set-Location` | `cd` | `cd` | 切换目录 |
| `Get-Location` | `cd` (无参数) | `pwd` | 显示当前目录 |
| `Copy-Item` | `copy` / `cp` | `cp` | 复制文件 |
| `Move-Item` | `move` / `mv` | `mv` | 移动/重命名 |
| `Remove-Item` | `del` / `rm` | `rm` | 删除 |
| `Get-Content` | `type` | `cat` | 查看文件内容 |
| `Set-Content` | - | `>` | 写入文件 |
| `Select-Object` | - | `head/tail` | 选择属性 |
| `Where-Object` | - | `grep` | 筛选 |
| `Sort-Object` | - | `sort` | 排序 |
| `Clear-Host` | `cls` | `clear` | 清屏 |

### 使用别名

```powershell
# 这些命令完全等价：
Get-ChildItem
ls
dir

# 查看别名的真实命令
Get-Alias ls
# 输出: ls -> Get-ChildItem
```

### 创建自定义别名

```powershell
# 为命令创建别名
Set-Alias -Name gh -Value Get-Help

# 创建带参数的别名（需要用函数）
function ll { Get-ChildItem -Path $args[0] -Force }
Set-Alias -Name ll -Value ll
```

## 1.7 输入输出重定向

### 输出重定向

```powershell
# 将输出保存到文件（覆盖）
命令 > 文件.txt

# 追加到文件
命令 >> 文件.txt

# 将错误信息保存到文件
命令 2> 错误.txt

# 同时保存输出和错误
命令 > 输出.txt 2>&1
```

### 输入重定向

```powershell
# 从文件读取输入
命令 < 文件.txt
```

### 管道输出

```powershell
# 将输出作为下一个命令的输入
命令A | 命令B

# tee：同时输出到屏幕和文件
命令 | Tee-Object -File 输出.txt

# Out-Null：丢弃输出
命令 | Out-Null
```

## 1.8 通配符与特殊字符

### 通配符

| 符号 | 含义 | 示例 |
|-----|------|------|
| `*` | 任意字符（0个或多个） | `*.txt` = 所有 txt 文件 |
| `?` | 单个任意字符 | `file?.txt` = file1.txt, fileA.txt |
| `[abc]` | 括号内任意字符 | `file[123].txt` = file1/2/3.txt |
| `[!abc]` | 不在括号内的字符 | `file[!1].txt` = 除 file1.txt 外 |

### 特殊变量

| 变量 | 含义 |
|-----|------|
| `$_` | 当前管道对象 |
| `$PSScriptRoot` | 当前脚本所在目录 |
| `$PWD` | 当前工作目录 |
| `$HOME` | 用户主目录 |
| `$env:VAR` | 环境变量 |

## 1.10 命令历史

### 基本历史

```powershell
# 查看历史记录
Get-History

# 运行指定 ID 的历史命令
Invoke-History 5

# 运行上一个命令
r  # 或
!!
```

### 搜索历史

```powershell
# 方法 1: Ctrl+R
# 按 Ctrl+R 后输入关键词，会反向搜索

# 方法 2: 查找包含关键词的命令
Get-History | Where-Object { $_.CommandLine -match "python" }
```

### 历史文件

PowerShell 的命令历史默认保存在：
```
C:\Users\<用户名>\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
```
