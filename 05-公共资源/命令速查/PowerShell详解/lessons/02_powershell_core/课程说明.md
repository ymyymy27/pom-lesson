## 2.1 cmdlets 命名规范

PowerShell 的命令遵循统一的 **Verb-Noun** 命名规范，这让命令非常容易记忆和预测。

### 命名规则

```
Verb-Noun
  │     └─ 单数名词，通常是复数形式（如 Items, Processes）
  └─ 从预定义的动词列表中选择
```

### 常用 Verb（动词）

**数据操作类**：
| Verb | 中文 | 示例 |
|-----|------|------|
| Get | 获取 | Get-Process, Get-Content |
| Set | 设置 | Set-Location, Set-ExecutionPolicy |
| New | 创建 | New-Item, New-Object |
| Remove | 删除 | Remove-Item, Remove-Variable |
| Copy | 复制 | Copy-Item |
| Move | 移动 | Move-Item |
| Rename | 重命名 | Rename-Item |

**执行类**：
| Verb | 中文 | 示例 |
|-----|------|------|
| Start | 启动 | Start-Process, Start-Service |
| Stop | 停止 | Stop-Process, Stop-Service |
| Restart | 重启 | Restart-Computer, Restart-Service |
| Invoke | 调用 | Invoke-WebRequest, Invoke-Command |

**输出类**：
| Verb | 中文 | 示例 |
|-----|------|------|
| Out | 输出到 | Out-File, Out-Null |
| Format | 格式化 | Format-Table, Format-List |
| Export | 导出 | Export-Csv, Export-Clixml |
| Import | 导入 | Import-Csv, Import-Module |

**查询类**：
| Verb | 中文 | 示例 |
|-----|------|------|
| Test | 测试 | Test-Path, Test-NetConnection |
| Search | 搜索 | （无标准命令） |
| Compare | 比较 | Compare-Object |
| Select | 选择 | Select-Object |

### 查看所有可用 Verb

```powershell
[System.Enum]::GetNames([System.Management.Automation.VerbsCommon])
```

### 查看命令的 Verb

```powershell
Get-Command -Verb Get
Get-Command -Noun Item
Get-Command -Module Microsoft.PowerShell.Management
```

## 2.2 参数（Parameters）

### 基本语法

```powershell
Verb-Noun -ParameterName ParameterValue
Verb-Noun -ParameterName1 Value1 -ParameterName2 Value2
```

### 参数类型

**位置参数**（可以不写参数名）：
```powershell
# 以下两种写法等价：
Get-ChildItem C:\Windows
Get-ChildItem -Path C:\Windows
```

**命名参数**（必须写参数名）：
```powershell
# -Path 是命名参数
Get-ChildItem -Path C:\Windows -Filter *.txt
```

**开关参数**（不需要值，布尔开关）：
```powershell
# -Recurse 是开关参数，有则启用，无则禁用
Get-ChildItem -Path C:\Windows -Recurse
```

### 常用参数

| 参数 | 含义 | 示例 |
|-----|------|------|
| `-Path` | 路径 | `-Path C:\Windows` |
| `-Filter` | 过滤器（快速） | `-Filter *.txt` |
| `-Include` | 包含模式 | `-Include *.txt,*.doc` |
| `-Exclude` | 排除模式 | `-Exclude *.tmp` |
| `-Recurse` | 递归子目录 | `-Recurse` |
| `-Force` | 强制操作（覆盖隐藏文件等） | `-Force` |
| `-WhatIf` | 模拟运行（不实际执行） | `-WhatIf` |
| `-Confirm` | 确认提示 | `-Confirm` |

### -WhatIf 和 -Confirm（安全参数）

```powershell
# 模拟删除（不实际删除）
Remove-Item -Path C:\temp\test.txt -WhatIf

# 输出: What if: Performing the operation "Remove File" on target "C:\temp\test.txt".

# 删除前确认
Remove-Item -Path C:\temp\test.txt -Confirm
```

## 2.3 变量

### 变量基础

PowerShell 变量以 `$` 开头：

```powershell
# 赋值
$name = "张三"
$age = 25
$isStudent = $true

# 输出
$name          # 张三
Write-Output $name
```

### 变量类型

PowerShell 是**动态类型**语言，但可以强制指定类型：

```powershell
# 动态类型
$var = "hello"
$var = 123

# 强类型
[string]$str = "hello"
[int]$num = 42
[bool]$flag = $true
[array]$arr = 1, 2, 3
[hashtable]$ht = @{key1 = "value1"; key2 = "value2"}
```

### 常用数据类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| `[string]` | 字符串 | `"Hello"` |
| `[int]` | 整数 | `42` |
| `[double]` | 浮点数 | `3.14` |
| `[bool]` | 布尔值 | `$true / $false` |
| `[array]` | 数组 | `1, 2, 3` |
| `[hashtable]` | 键值对 | `@{a=1; b=2}` |
| `[datetime]` | 日期时间 | `Get-Date` |
| `[regex]` | 正则表达式 | `[regex]::Match()` |

### 特殊变量

| 变量 | 含义 |
|-----|------|
| `$_` | 当前管道对象 |
| `$PSItem` | 当前管道对象（完整写法） |
| `$null` | 空值 |
| `$LASTEXITCODE` | 上一个命令的退出码 |
| `$HOME` | 用户主目录 |
| `$PWD` | 当前工作目录 |
| `$env:VAR` | 环境变量 |
| `$args` | 函数的参数数组 |
| `$true` / `$false` | 布尔值 |
| `$input` | 函数的所有输入 |

### 数组操作

```powershell
# 创建数组
$arr = 1, 2, 3, 4, 5
$arr = @(1, 2, 3)  # 明确声明

# 访问元素（索引从 0 开始）
$arr[0]   # 第一个元素
$arr[-1]  # 最后一个元素
$arr[0..2] # 前三个元素

# 数组长度
$arr.Length
$arr.Count

# 添加元素
$arr += 6
```

### Hashtable（哈希表/字典）

```powershell
# 创建
$person = @{
    Name = "张三"
    Age = 25
    City = "北京"
}

# 访问
$person.Name      # 张三
$person["Name"]   # 张三
$person.Age = 26  # 修改

# 添加
$person["Job"] = "工程师"

# 遍历
foreach ($key in $person.Keys) {
    Write-Output "$key : $($person[$key])"
}
```

## 2.4 运算符

### 算术运算符

```powershell
$a = 10
$b = 3

$a + $b   # 加法: 13
$a - $b   # 减法: 7
$a * $b   # 乘法: 30
$a / $b   # 除法: 3.333...
$a % $b   # 取余: 1
```

### 比较运算符

```powershell
# 数值比较
5 -eq 5     # 等于
5 -ne 3     # 不等于
5 -gt 3     # 大于
5 -lt 10    # 小于
5 -ge 5     # 大于等于
5 -le 5     # 小于等于

# 字符串比较
"hello" -eq "hello"   # 等于
"hello" -ne "world"   # 不等于
"hello" -like "*ll*"   # 通配符匹配
"hello" -match "^h"    # 正则匹配
```

### 逻辑运算符

```powershell
# 逻辑与
($a -gt 5) -and ($b -lt 10)

# 逻辑或
($a -gt 10) -or ($b -lt 5)

# 逻辑非
-not ($a -eq 5)
!($a -eq 5)    # 简写形式
```

### 字符串运算符

```powershell
# 字符串拼接
"Hello " + "World"           # Hello World

# 字符串重复
"-" * 20                     # --------------------

# 字符串方法
"hello".ToUpper()            # HELLO
"Hello".ToLower()            # hello
"Hello".Length               # 5
"Hello".Substring(1, 2)      # el
"hello world".Split(" ")     # @("hello", "world")
"hello world".Replace("world", "PowerShell")  # hello PowerShell
```

### 格式化运算符

```powershell
# -f 格式化运算符
"{0} + {1} = {2}" -f 1, 2, 3        # 1 + 2 = 3
"{0:N2}" -f 3.14159                  # 3.14
"{0:P}" -f 0.25                     # 25.00%
"{0:yyyy-MM-dd}" -f (Get-Date)      # 2026-04-08
```

### 类型运算符

```powershell
# 类型检查
"hello" -is [string]      # True
"hello" -is [int]         # False

# 类型转换
"123" -as [int]           # 123（转换失败返回 $null）
[int]"123"                # 123（转换失败报错）
```

## 2.5 条件语句

### if / elseif / else

```powershell
$score = 85

if ($score -ge 90) {
    Write-Output "优秀"
} elseif ($score -ge 70) {
    Write-Output "良好"
} elseif ($score -ge 60) {
    Write-Output "及格"
} else {
    Write-Output "不及格"
}
```

### 简化的条件判断

```powershell
# 单行条件
if ($condition) { $true_value } else { $false_value }

# 三元运算符（PowerShell 7+）
$result = $score -ge 60 ? "及格" : "不及格"
```

### switch 语句

```powershell
$day = (Get-Date).DayOfWeek

switch ($day) {
    "Saturday" { Write-Output "周末"; break }
    "Sunday"   { Write-Output "周末"; break }
    "Monday"   { Write-Output "周一开会" }
    default    { Write-Output "工作日" }
}
```

### 多种匹配条件

```powershell
$grade = "B"

switch -Wildcard ($grade) {
    "A*" { Write-Output "优秀" }
    "B*" { Write-Output "良好" }
    "C*" { Write-Output "一般" }
    default { Write-Output "需要努力" }
}
```

## 2.6 循环语句

### foreach-Object（管道中）

```powershell
# 基本用法
1..5 | ForEach-Object { $_ * 2 }

# 完整语法
1..5 | ForEach-Object -Process { $_ * 2 }

# 使用脚本块
@(1, 2, 3, 4, 5) | ForEach-Object {
    $square = $_ * $_
    Write-Output "$_ 的平方是 $square"
}
```

### foreach 循环（命令式）

```powershell
$fruits = @("苹果", "香蕉", "橙子")

foreach ($fruit in $fruits) {
    Write-Output "我喜欢吃 $fruit"
}
```

### for 循环

```powershell
# 传统 for 循环
for ($i = 0; $i -lt 5; $i++) {
    Write-Output $i
}

# 范围操作符
for ($i = 0; $i -lt 5; $i++) { ... }
1..5 | ForEach-Object { ... }  # 等价写法
```

### while 循环

```powershell
$i = 0
while ($i -lt 5) {
    Write-Output $i
    $i++
}

# 至少执行一次
do {
    $response = Read-Host "继续？(y/n)"
} while ($response -eq "y")
```

### 循环控制

```powershell
# break - 跳出循环
foreach ($i in 1..10) {
    if ($i -eq 5) { break }
    Write-Output $i  # 输出 1, 2, 3, 4
}

# continue - 跳过当前迭代
foreach ($i in 1..5) {
    if ($i -eq 3) { continue }
    Write-Output $i  # 输出 1, 2, 4, 5
}
```

## 2.7 帮助系统

### Get-Help（核心）

```powershell
# 查看命令帮助
Get-Help Get-Process

# 查看详细帮助
Get-Help Get-Process -Detailed

# 查看完整帮助（包含示例）
Get-Help Get-Process -Full

# 查看示例
Get-Help Get-Process -Examples

# 在线查看最新帮助
Get-Help Get-Process -Online
```

### Update-Help（更新帮助）

```powershell
# 更新本地帮助文件（需要管理员权限）
Update-Help -Module * -Force
```

### Get-Command（查找命令）

```powershell
# 查找所有 Get 开头的命令
Get-Command -Verb Get

# 查找所有包含 "Item" 的命令
Get-Command -Noun Item

# 查找所有命令
Get-Command

# 查找特定模块的命令
Get-Command -Module Microsoft.PowerShell.Management
```

### Get-Member（探索对象）

```powershell
# 查看命令返回对象的属性和方法
Get-Process | Get-Member

# 查看特定类型的成员
(Get-Date).GetType() | Get-Member

# 列出所有属性
Get-Process | Get-Member -MemberType Property

# 列出所有方法
Get-Process | Get-Member -MemberType Method
```

### 示例：探索对象

```powershell
# 查看进程对象的可用属性
Get-Process | Get-Member -MemberType Properties

# 获取进程名称和 CPU 时间
Get-Process | Select-Object Name, CPU, WorkingSet | Sort-Object CPU -Descending | Select-Object -First 10
```

## 2.8 函数基础

### 定义函数

```powershell
function Say-Hello {
    Write-Output "你好，世界！"
}

# 调用
Say-Hello
```

### 带参数的函数

```powershell
function Greet {
    param(
        [string]$Name = "访客",
        [int]$Age = 0
    )
    Write-Output "你好，$Name！你的年龄是 $Age 岁。"
}

Greet -Name "张三" -Age 25
# 输出: 你好，张三！你的年龄是 25 岁。
```

### 函数返回布尔值

```powershell
function Test-IsAdmin {
    $currentUser = [Security.Principal.WindowsIdentity]::GetCurrent()
    $principal = New-Object Security.Principal.WindowsPrincipal($currentUser)
    return $principal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
}

if (Test-IsAdmin) {
    Write-Output "当前以管理员身份运行"
} else {
    Write-Output "当前不是管理员"
}
```

### 管道函数

```powershell
function Get-Square {
    param(
        [Parameter(ValueFromPipeline=$true)]
        [int]$Number
    )
    process {
        $Number * $Number
    }
}

# 使用
1..5 | Get-Square
# 输出: 1, 4, 9, 16, 25
```

## 2.10 常见错误与调试

### 常见错误

**1. 空值引用**
```powershell
# 错误
$obj = $null
$obj.Property  # NullReferenceException

# 解决
$obj = $null
if ($null -ne $obj) {
    $obj.Property
}
```

**2. 类型不匹配**
```powershell
# 错误
"5" + 3  # 字符串拼接: "53"

# 解决
[int]"5" + 3  # 数值加法: 8
```

**3. 数组越界**
```powershell
$arr = @(1, 2, 3)
$arr[10]  # 返回 $null，不报错
```

### 调试技巧

```powershell
# Write-Debug（需要启用）
$DebugPreference = "Continue"
Write-Debug "调试信息"

# Write-Verbose（需要启用详细输出）
Write-Verbose "详细日志"

# Write-Host（立即输出，不经过管道）
Write-Host "提示信息" -ForegroundColor Yellow

# 断点调试
Set-PSBreakpoint -Script script.ps1 -Line 10
```
