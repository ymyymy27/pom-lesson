## 3.1 路径基础

### 绝对路径 vs 相对路径

```
绝对路径：从根目录开始的完整路径
  C:\Users\<用户名>\Documents\project\file.txt
  /home/user/documents/project/file.txt

相对路径：从当前目录出发的路径
  .\file.txt              # 当前目录的 file.txt
  ..\file.txt             # 上级目录的 file.txt
  ..\..\file.txt          # 上上级目录的 file.txt
  .\subdir\file.txt       # 子目录的 file.txt
```

### PowerShell 中的路径格式

```powershell
# Windows 路径（两种写法等价）
C:\Windows\System32
C:/Windows/System32  # PowerShell 也接受正斜杠

# 跨平台兼容性
$PSCommandPath          # 当前脚本的完整路径
$PSScriptRoot           # 当前脚本所在的目录
$PWD                    # 当前工作目录
$HOME                   # 用户主目录
```

### 路径命令

```powershell
# 获取当前目录
Get-Location
pwd  # 别名

# 切换目录
Set-Location 路径
cd 路径   # 别名
Set-Location C:\Windows

# 切换到用户主目录
Set-Location $HOME
cd ~     # ~ 也是主目录的别名

# 切换到上一次目录
Set-Location -  # 或
cd -
```

### Push-Location / Pop-Location（栈式导航）

```powershell
# pushd：进入目录并记住当前位置
Push-Location C:\Windows\System32
# 等同于：cd C:\Windows\System32
# 同时保存了之前的目录

Push-Location C:\Temp

# popd：返回上一个目录
Pop-Location  # 现在回到了 C:\Windows\System32

Pop-Location  # 回到了最初的地方
```

**用途**：在多个目录之间切换，不用记住路径：

```powershell
Push-Location C:\Project1
# 做事情...
Pop-Location

Push-Location C:\Project2
# 做事情...
Pop-Location
```

## 3.2 查看目录内容

### Get-ChildItem（ls / dir）

```powershell
# 基本用法
Get-ChildItem
ls        # 别名
dir       # 别名

# 查看指定目录
Get-ChildItem C:\Windows

# 递归查看（包含子目录）
Get-ChildItem -Recurse

# 只看文件（不包括目录）
Get-ChildItem -File

# 只看目录
Get-ChildItem -Directory

# 隐藏文件/目录
Get-ChildItem -Force  # 包括隐藏项

# 查看文件详细信息
Get-ChildItem | Format-Table Name, Length, LastWriteTime
```

### 过滤器

```powershell
# -Filter 参数（快速，推荐用于单一模式）
Get-ChildItem -Filter *.txt
Get-ChildItem -Filter ???.txt  # 3个字符的 txt 文件

# -Include 参数（支持多个模式）
Get-ChildItem -Include *.txt, *.doc, *.pdf

# -Exclude 参数（排除某些文件）
Get-ChildItem -Exclude *.tmp, *.bak

# -Path 参数（明确指定路径）
Get-ChildItem -Path C:\Windows\*.exe
```

### 递归搜索

```powershell
# 递归搜索所有子目录
Get-ChildItem -Path C:\Windows -Recurse

# 递归但限制深度（PowerShell 7+）
Get-ChildItem -Path C:\ -Recurse -Depth 2

# 递归搜索特定文件
Get-ChildItem -Path C:\ -Recurse -Filter *.py

# 递归搜索时排除某些目录
Get-ChildItem -Path C:\ -Recurse -Exclude "node_modules", ".git", "__pycache__"
```

## 3.3 创建文件与目录

### New-Item

```powershell
# 创建目录
New-Item -ItemType Directory -Path C:\Temp\TestFolder
mkdir C:\Temp\TestFolder   # 别名

# 创建文件
New-Item -ItemType File -Path C:\Temp\test.txt
ni C:\Temp\test.txt         # 别名

# 创建并写入内容
New-Item -ItemType File -Path C:\Temp\test.txt -Value "Hello World"

# 批量创建（使用循环）
1..5 | ForEach-Object {
    New-Item -ItemType Directory -Path "C:\Temp\Folder_$_"
}
```

### 快速创建文件

```powershell
# 方法 1: Set-Content
Set-Content -Path C:\Temp\test.txt -Value "内容"

# 方法 2: Out-File
"内容" | Out-File -FilePath C:\Temp\test.txt

# 方法 3: 重定向
"内容" > C:\Temp\test.txt

# 创建空文件
New-Item -ItemType File -Path test.txt

# 更新文件（追加）
Add-Content -Path C:\Temp\test.txt -Value "追加的内容"
```

## 3.4 查看文件内容

### Get-Content（cat / type）

```powershell
# 基本查看
Get-Content C:\Temp\test.txt
cat C:\Temp\test.txt       # 别名
type C:\Temp\test.txt      # CMD 别名

# 查看前 N 行
Get-Content C:\Temp\test.txt -TotalCount 10
Get-Content C:\Temp\test.txt | Select-Object -First 10

# 查看后 N 行
Get-Content C:\Temp\test.txt -Tail 10

# 动态监控文件（tail -f 等效）
Get-Content C:\Temp\test.txt -Wait -Tail 10

# 逐行读取大文件（不一次性加载）
Get-Content C:\bigfile.txt -ReadCount 1000 -PipelineVariable line |
    ForEach-Object {
        $line  # 处理每一行
    }
```

## 3.5 复制文件与目录

### Copy-Item

```powershell
# 复制单个文件
Copy-Item -Path C:\Temp\file.txt -Destination C:\Backup\file.txt
cp C:\Temp\file.txt C:\Backup\   # 别名

# 复制目录（包含所有内容）
Copy-Item -Path C:\Temp\MyFolder -Destination C:\Backup\MyFolder -Recurse

# 复制并保留属性
Copy-Item -Path C:\Temp\file.txt -Destination C:\Backup\ -Preserve

# 批量复制（复制所有 txt 文件）
Copy-Item -Path C:\Temp\*.txt -Destination C:\Backup\

# 复制时覆盖已存在的文件
Copy-Item -Path C:\Temp\file.txt -Destination C:\Backup\ -Force
```

### 高级复制

```powershell
# 复制并重命名
Copy-Item -Path C:\Temp\oldname.txt -Destination C:\Temp\newname.txt

# 复制到当前目录
Copy-Item -Path C:\Windows\*.dll -Destination .

# 复制时排除某些文件
Copy-Item -Path C:\Source -Destination C:\Dest -Recurse -Exclude *.tmp

# 模拟复制（预览）
Copy-Item -Path C:\Temp\* -Destination C:\Backup\ -WhatIf
```

## 3.6 移动与重命名

### Move-Item

```powershell
# 移动文件
Move-Item -Path C:\Temp\file.txt -Destination C:\Archive\file.txt
mv C:\Temp\file.txt C:\Archive\   # 别名

# 移动目录
Move-Item -Path C:\Temp\MyFolder -Destination C:\Archive\

# 移动并重命名（同一操作）
Move-Item -Path C:\Temp\file.txt -Destination C:\Temp\newfile.txt
```

### Rename-Item

```powershell
# 重命名文件
Rename-Item -Path C:\Temp\file.txt -NewName newfile.txt

# 重命名多个文件（需要循环）
Get-ChildItem -Path C:\Temp\*.txt | ForEach-Object {
    $newName = $_.Name -replace "\.txt$", ".md"
    Rename-Item -Path $_.FullName -NewName $newName
}

# 批量重命名示例：将所有 .txt 改为 .md
Get-ChildItem -Filter *.txt | Rename-Item -NewName { $_.Name -replace '\.txt$', '.md' }
```

### 批量重命名

```powershell
# 使用通配符重命名
# 例如：将所有 file1.txt, file2.txt 重命名为 doc1.txt, doc2.txt
1..3 | ForEach-Object {
    $old = "file$_.txt"
    $new = "doc$_.txt"
    Rename-Item -Path $old -NewName $new
}
```

## 3.7 删除文件与目录

### Remove-Item

```powershell
# 删除文件
Remove-Item -Path C:\Temp\file.txt
rm C:\Temp\file.txt            # 别名
del C:\Temp\file.txt           # CMD 别名

# 删除目录
Remove-Item -Path C:\Temp\MyFolder -Recurse

# 删除所有 txt 文件
Remove-Item -Path C:\Temp\*.txt

# 删除前确认
Remove-Item -Path C:\Temp\file.txt -Confirm

# 模拟删除（预览）
Remove-Item -Path C:\Temp\* -WhatIf

# 强制删除（即使只读文件）
Remove-Item -Path C:\Temp\file.txt -Force
```

**危险操作警告**：

```powershell
# 危险！删除 C:\ 下所有 .tmp 文件
Remove-Item -Path C:\*.tmp -Force -Recurse

# 安全做法：先用 -WhatIf 预览
Remove-Item -Path C:\*.tmp -WhatIf
```

## 3.8 Test-Path（路径测试）

```powershell
# 测试路径是否存在
Test-Path C:\Windows\System32  # True
Test-Path C:\NotExists         # False

# 测试文件是否存在
Test-Path C:\Temp\file.txt -PathType Leaf

# 测试目录是否存在
Test-Path C:\Temp\MyFolder -PathType Container

# 组合使用
if (Test-Path C:\Temp\file.txt) {
    Write-Output "文件存在"
    Get-Content C:\Temp\file.txt
} else {
    Write-Output "文件不存在，将创建"
    New-Item -ItemType File -Path C:\Temp\file.txt
}
```

## 3.9 获取文件信息

### Get-Item / Get-ItemProperty

```powershell
# 获取文件/目录对象
Get-Item C:\Temp\file.txt

# 获取详细属性
Get-Item C:\Temp\file.txt | Select-Object FullName, Length, LastWriteTime, Attributes

# 获取文件元数据
Get-ItemProperty -Path C:\Temp\file.txt

# 获取文件哈希（PowerShell 5+）
Get-FileHash C:\Temp\file.txt -Algorithm SHA256

# 获取文件版本信息
Get-ItemProperty -Path C:\Windows\System32\notepad.exe | Select-Object ProductName, FileVersion, ProductVersion
```

### 常见属性

```powershell
$file = Get-Item C:\Temp\file.txt

$file.FullName      # 完整路径
$file.Name          # 文件名（含扩展名）
$file.BaseName      # 文件名（不含扩展名）
$file.Extension      # 扩展名
$file.Length         # 文件大小（字节）
$file.LastWriteTime  # 最后修改时间
$file.CreationTime   # 创建时间
$file.Attributes     # 文件属性
```

## 3.11 通配符实战

### 常见模式

```powershell
# * 任意字符
Get-ChildItem C:\Windows\*.exe       # 所有 exe 文件
Get-ChildItem C:\Windows\*32*.exe    # 包含 32 的 exe

# ? 单个字符
Get-ChildItem C:\Windows\???.exe     # 3个字符的 exe

# [] 字符范围
Get-ChildItem C:\Windows\[abc]*.exe  # 以 a, b, 或 c 开头的 exe
Get-ChildItem C:\Windows\[!abc]*.exe # 不以 a, b, 或 c 开头的 exe

# 组合
Get-ChildItem C:\Windows\*[0-9]*.exe  # 包含数字的 exe
```

### 正则表达式匹配（Select-String）

```powershell
# 在文件中搜索匹配正则的行
Select-String -Path C:\logs\*.log -Pattern "ERROR"
Select-String -Path *.py -Pattern "def \w+\(" -Recurse

# 搜索多个模式（使用正则 OR）
Select-String -Path *.py -Pattern "(ERROR|WARN|CRITICAL)" -Recurse
```

## 3.12 实用脚本示例

### 批量重命名图片

```powershell
$folder = "C:\Photos"
$prefix = "IMG_"
$counter = 1

Get-ChildItem -Path $folder -Filter *.jpg |
    ForEach-Object {
        $newName = "{0}{1:0000}.jpg" -f $prefix, $counter
        Rename-Item -Path $_.FullName -NewName $newName
        $counter++
    }
```

### 清理临时文件

```powershell
# 删除临时文件
$tempFolders = @($env:TEMP, "C:\Temp", "$env:LOCALAPPDATA\Temp")

foreach ($folder in $tempFolders) {
    if (Test-Path $folder) {
        Get-ChildItem -Path $folder -Recurse -Force |
            Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-7) } |
            Remove-Item -Force -Recurse -ErrorAction SilentlyContinue
        Write-Output "已清理 $folder"
    }
}
```

### 查找大文件

```powershell
# 查找大于 100MB 的文件
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue |
    Where-Object { $_.Length -gt 100MB } |
    Sort-Object Length -Descending |
    Select-Object -First 20 FullName,
        @{Name="SizeMB";Expression={[math]::Round($_.Length/1MB, 2)}}
```

### 备份文件夹

```powershell
$source = "C:\Project"
$dest = "D:\Backup"
$date = Get-Date -Format "yyyyMMdd_HHmmss"

$backupPath = Join-Path $dest ("Backup_$date")
Copy-Item -Path $source -Destination $backupPath -Recurse
Write-Output "备份完成: $backupPath"
```
