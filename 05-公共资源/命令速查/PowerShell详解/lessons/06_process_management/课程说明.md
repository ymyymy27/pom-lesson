## 6.1 进程基础

### 什么是进程？

**进程（Process）** 是正在运行的程序的实例。每个进程都有自己独立的内存空间、进程 ID（PID）和系统资源。

```
进程 = 正在执行的程序

例如：
- 浏览器（chrome.exe, msedge.exe）
- 文本编辑器（code.exe, notepad.exe）
- PowerShell 本身（powershell.exe）
- Python 解释器（python.exe）
```

### 查看进程

```powershell
# 查看所有进程
Get-Process

# 查看特定进程
Get-Process -Name python
Get-Process -Name python, code

# 查看单个进程（使用 PID）
Get-Process -Id 1234

# 查看进程数量
Get-Process | Measure-Object
```

### 进程对象属性

```powershell
# 获取进程详细信息
Get-Process -Name python | Select-Object *

# 常用属性
Get-Process -Name python | Select-Object Name, Id, CPU, WorkingSet,
    @{Name="MemoryMB";Expression={[math]::Round($_.WorkingSet/1MB, 2)}},
    StartTime, Responding, Path
```

| 属性 | 说明 |
|-----|------|
| `Id` / `PID` | 进程 ID |
| `Name` | 进程名称 |
| `CPU` | CPU 时间（秒） |
| `WorkingSet` | 工作集内存（字节） |
| `PeakWorkingSet` | 峰值工作集内存 |
| `StartTime` | 启动时间 |
| `Responding` | 是否响应（UI 程序） |
| `Path` | 可执行文件路径 |
| `Company` | 公司名称 |
| `ProductVersion` | 产品版本 |

## 6.2 进程筛选与排序

### 筛选进程

```powershell
# 筛选特定进程
Get-Process | Where-Object Name -eq "python"

# 筛选 CPU 占用高的进程
Get-Process | Where-Object CPU -gt 10

# 筛选内存占用高的进程
Get-Process | Where-Object { $_.WorkingSet -gt 500MB }

# 筛选不响应的程序
Get-Process | Where-Object { $_.Responding -eq $false }

# 筛选指定用户启动的进程（需要管理员权限）
Get-Process | Where-Object { $_.GetOwner().User -eq "22271" }
```

### 排序进程

```powershell
# 按 CPU 占用排序
Get-Process | Sort-Object CPU -Descending

# 按内存占用排序
Get-Process | Sort-Object WorkingSet -Descending |
    Select-Object -First 10 Name,
        @{Name="MemoryMB";Expression={[math]::Round($_.WorkingSet/1MB,2)}}

# 综合排序
Get-Process | Sort-Object CPU, WorkingSet -Descending
```

### 组合操作

```powershell
# 找出 CPU 或内存占用最高的 5 个进程
Get-Process |
    Sort-Object CPU, WorkingSet -Descending |
    Select-Object -First 5 Name, Id, CPU,
        @{Name="MemoryMB";Expression={[math]::Round($_.WorkingSet/1MB,2)}}

# 找出特定用户的所有进程
Get-Process |
    Where-Object { $_.GetOwner().User -eq "22271" } |
    Sort-Object WorkingSet -Descending
```

## 6.3 启动进程

### Start-Process

```powershell
# 启动程序
Start-Process notepad.exe

# 启动并指定文件
Start-Process notepad.exe -ArgumentList "C:\Temp\test.txt"

# 启动程序并等待
Start-Process python.exe -ArgumentList "script.py" -Wait

# 启动并最大化窗口
Start-Process notepad.exe -Verb RunAs  # 以管理员身份运行

# 启动新 PowerShell 窗口
Start-Process powershell.exe

# 启动隐藏窗口的程序
Start-Process python.exe -ArgumentList "script.py" -WindowStyle Hidden

# 获取启动后的进程对象
$process = Start-Process notepad.exe -PassThru
$process.Id  # 获取 PID
```

### 启动参数

```powershell
# 常用参数
Start-Process -FilePath "程序路径"
    -ArgumentList "参数"      # 传递给程序的参数
    -WorkingDirectory "目录"  # 工作目录
    -Credential $cred          # 凭据
    -Verb RunAs               # 以管理员身份运行
    -WindowStyle Hidden/Normal/Minimized/Maximized
    -PassThru                 # 返回进程对象
    -RedirectStandardOutput "文件"  # 标准输出重定向
    -RedirectStandardError "文件"   # 标准错误重定向
```

### Start-Process vs Invoke-Expression

```powershell
# Start-Process：启动 GUI 程序或后台进程
Start-Process code.exe

# Invoke-Expression：执行命令字符串（慎用，有安全风险）
Invoke-Expression "Get-Process"  # 不推荐

# 直接调用（推荐）
Get-Process  # 直接执行命令
& "C:\path\command.exe" args  # 调用外部程序
```

## 6.4 停止进程

### Stop-Process

```powershell
# 按名称停止
Stop-Process -Name notepad

# 按名称停止（多个）
Stop-Process -Name python, node

# 按 PID 停止
Stop-Process -Id 1234

# 强制停止（不等待优雅关闭）
Stop-Process -Name python -Force

# 停止前确认
Stop-Process -Name python -Confirm

# 停止所有 Python 进程（递归）
Get-Process python | Stop-Process -Force
```

### Wait-Process

```powershell
# 启动进程并等待它结束
$process = Start-Process python.exe -ArgumentList "script.py" -PassThru
Wait-Process -Id $process.Id
Write-Output "脚本执行完成"
```

### 优雅关闭 vs 强制关闭

```
优雅关闭（SIGTERM）：
  - 发送关闭信号给进程
  - 进程有机会保存数据、清理资源
  - 可能需要等待
  - PowerShell: Stop-Process (默认)

强制关闭（SIGKILL）：
  - 立即终止进程
  - 数据可能丢失
  - 立即返回
  - PowerShell: Stop-Process -Force
```

## 6.5 后台任务

### Start-Job（后台作业）

```powershell
# 启动后台任务
Start-Job -ScriptBlock {
    Get-Process | Sort-Object WorkingSet -Descending |
        Select-Object -First 10
}

# 启动命名作业
Start-Job -Name "MyLongTask" -ScriptBlock {
    # 模拟长时间运行
    Start-Sleep -Seconds 30
    "任务完成"
}

# 获取后台任务输出
Get-Job
Receive-Job -Name "MyLongTask"
```

### 任务管理

```powershell
# 查看所有作业
Get-Job

# 等待作业完成
Wait-Job -Name "MyLongTask"

# 获取输出（保留数据）
Receive-Job -Name "MyLongTask" -Keep

# 停止作业
Stop-Job -Name "MyLongTask"

# 删除作业
Remove-Job -Name "MyLongTask"

# 等待所有作业
Get-Job | Wait-Job
```

### Start-ThreadJob（多线程，PowerShell 7+）

```powershell
# 比 Start-Job 更轻量
Install-Module -Name ThreadJob -Scope CurrentUser

Start-ThreadJob -ScriptBlock {
    Get-Process | Sort-Object WorkingSet -Descending
} -ThrottleLimit 4
```

## 6.6 Windows 服务

### 什么是服务？

**Windows 服务** 是后台运行的程序，通常在系统启动时自动启动，不需要用户登录即可运行。

```
服务 vs 进程：
- 进程：由用户启动，关闭用户会话后结束
- 服务：由系统启动，不依赖用户会话
```

### 查看服务

```powershell
# 查看所有服务
Get-Service

# 查看服务状态
Get-Service -Name wuauserv  # Windows Update

# 按状态筛选
Get-Service | Where-Object Status -eq "Running"
Get-Service | Where-Object Status -eq "Stopped"

# 按名称筛选
Get-Service -Name W32Time, Spooler, wuauserv

# 查看所有自动启动的服务
Get-Service | Where-Object { $_.StartType -eq "Automatic" }

# 查看依赖服务
Get-Service -Name W32Time | Select-Object -ExpandProperty DependentServices
```

### 服务状态

| 状态 | 说明 |
|-----|------|
| `Running` | 正在运行 |
| `Stopped` | 已停止 |
| `Paused` | 已暂停 |
| `StartPending` | 正在启动 |
| `StopPending` | 正在停止 |

### Start-Service / Stop-Service

```powershell
# 启动服务
Start-Service -Name wuauserv

# 停止服务
Stop-Service -Name Spooler

# 重启服务
Restart-Service -Name Spooler

# 启动多个服务
Start-Service -Name wuauserv, Spooler

# 带确认的启动
Start-Service -Name wuauserv -Confirm
```

### Set-Service（修改启动类型）

```powershell
# 设置服务为自动启动
Set-Service -Name wuauserv -StartupType Automatic

# 设置服务为手动启动
Set-Service -Name wuauserv -StartupType Manual

# 禁用服务
Set-Service -Name wuauserv -StartupType Disabled
```

### 常见 Windows 服务

| 服务名 | 显示名称 | 说明 |
|-------|---------|------|
| `wuauserv` | Windows Update | 系统更新 |
| `Spooler` | Print Spooler | 打印服务 |
| `WSearch` | Windows Search | 搜索索引 |
| `BITS` | Background Intelligent Transfer | 后台传输 |
| `W32Time` | Windows Time | 时间同步 |
| `Dhcp` | DHCP Client | IP 地址分配 |
| `Dnscache` | DNS Client | DNS 缓存 |

## 6.7 任务计划程序

### 基本概念

任务计划程序（Task Scheduler）用于自动化定时任务，类似 Linux 的 cron。

### 快速创建计划任务

```powershell
# 创建简单的计划任务（每天 9:00 执行）
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-File C:\Scripts\backup.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At 9am
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
$principal = New-ScheduledTaskPrincipal -UserId "$env:USERNAME" -LogonType Interactive -RunLevel Limited

Register-ScheduledTask -Action $action -Trigger $trigger -Settings $settings -Principal $principal -TaskName "DailyBackup"
```

### 常用触发器

```powershell
# 每天指定时间
New-ScheduledTaskTrigger -Daily -At 9am

# 每周指定时间
New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday -At 9am

# 每次启动
New-ScheduledTaskTrigger -AtStartup

# 每次登录
New-ScheduledTaskTrigger -AtLogOn

# 指定日期
New-ScheduledTaskTrigger -Once -At "2026-04-15 10:00"
```

### 计划任务管理

```powershell
# 查看所有计划任务
Get-ScheduledTask

# 查看特定任务
Get-ScheduledTask -TaskName "DailyBackup"

# 查看任务状态
Get-ScheduledTask -TaskName "DailyBackup" | Get-ScheduledTaskInfo

# 启动任务
Start-ScheduledTask -TaskName "DailyBackup"

# 停止任务
Stop-ScheduledTask -TaskName "DailyBackup"

# 禁用/启用任务
Disable-ScheduledTask -TaskName "DailyBackup"
Enable-ScheduledTask -TaskName "DailyBackup"

# 删除任务
Unregister-ScheduledTask -TaskName "DailyBackup" -Confirm:$false
```

## 6.8 系统资源监控

### CPU 监控

```powershell
# 查看 CPU 使用率
Get-WmiObject -Class Win32_Processor | Select-Object Name, LoadPercentage

# 查看进程 CPU 占用
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10 Name, Id, CPU

# 持续监控 CPU（每 2 秒刷新）
while ($true) {
    Clear-Host
    Get-WmiObject -Class Win32_Processor | Select-Object Name, LoadPercentage
    Start-Sleep -Seconds 2
}
```

### 内存监控

```powershell
# 查看内存使用情况
Get-WmiObject -Class Win32_OperatingSystem |
    Select-Object TotalVisibleMemorySize,
        @{Name="TotalGB";Expression={[math]::Round($_.TotalVisibleMemorySize/1MB,2)}},
        FreePhysicalMemory,
        @{Name="FreeGB";Expression={[math]::Round($_.FreePhysicalMemory/1MB,2)}}

# 实时监控内存
while ($true) {
    $mem = Get-WmiObject -Class Win32_OperatingSystem
    $used = [math]::Round(($mem.TotalVisibleMemorySize - $mem.FreePhysicalMemory) / 1MB, 2)
    $total = [math]::Round($mem.TotalVisibleMemorySize / 1MB, 2)
    $percent = [math]::Round($used / $total * 100, 1)
    Write-Host "内存: $used GB / $total GB ($percent%)" -ForegroundColor $(if ($percent -gt 80) {"Red"} else {"Green"})
    Start-Sleep -Seconds 2
}
```

### 磁盘监控

```powershell
# 查看磁盘空间
Get-WmiObject -Class Win32_LogicalDisk -Filter "DriveType=3" |
    Select-Object DeviceID,
        @{Name="TotalGB";Expression={[math]::Round($_.Size/1GB,2)}},
        @{Name="FreeGB";Expression={[math]::Round($_.FreeSpace/1GB,2)}},
        @{Name="UsedPercent";Expression={[math]::Round(($_.Size - $_.FreeSpace) / $_.Size * 100, 1)}}
```

## 6.9 事件日志

### 查看系统日志

```powershell
# 查看系统日志（最近 20 条错误）
Get-WinEvent -LogName System -MaxEvents 20 | Where-Object { $_.LevelDisplayName -eq "错误" }

# 查看应用日志
Get-WinEvent -LogName Application -MaxEvents 50

# 按时间筛选
Get-WinEvent -LogName System -MaxEvents 100 |
    Where-Object { $_.TimeCreated -gt (Get-Date).AddDays(-7) }

# 查看错误和警告
Get-WinEvent -LogName System |
    Where-Object { $_.Level -le 3 } |  # 1=Critical, 2=Error, 3=Warning
    Select-Object TimeCreated, LevelDisplayName, Message |
    Format-Table -AutoSize -Wrap
```

## 6.10 实用脚本

### 批量管理进程

```powershell
# 强制关闭所有 Python 进程
Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force

# 查找并关闭占用端口的进程
$port = 8080
$pid = (Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue).OwningProcess
if ($pid) {
    Stop-Process -Id $pid -Force
    Write-Output "已关闭端口 $port 上的进程 (PID: $pid)"
}
```

### 监控系统资源

```powershell
# 创建监控脚本
@"
`$logFile = "C:\Logs\system-monitor.log"
while (`$true) {
    `$cpu = (Get-WmiObject -Class Win32_Processor).LoadPercentage
    `$mem = [math]::Round(((Get-WmiObject -Class Win32_OperatingSystem).TotalVisibleMemorySize -
                          (Get-WmiObject -Class Win32_OperatingSystem).FreePhysicalMemory) /
                          (Get-WmiObject -Class Win32_OperatingSystem).TotalVisibleMemorySize * 100, 1)
    `$time = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    "`$time | CPU: `$cpu% | MEM: `$mem%" | Out-File -FilePath `$logFile -Append
    Start-Sleep -Seconds 60
}
"@ | Out-File -FilePath C:\Scripts\monitor.ps1 -Encoding UTF8
```
