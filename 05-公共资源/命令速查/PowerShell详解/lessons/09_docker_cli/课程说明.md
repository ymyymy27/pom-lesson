## 9.1 Docker 基础概念

### 什么是容器？

容器是一个轻量级的虚拟化技术，它将应用程序及其依赖打包在一起，确保"在我机器上能跑，在你机器上也能跑"。

```
虚拟机 vs 容器：

虚拟机（VM）：
┌────────────────────┐
│ Guest OS           │ ← 每个 VM 都有完整操作系统
│ ├─ App1           │
│ ├─ App2           │
│ └─ Dependencies   │
└────────────────────┘
┌────────────────────┐
│ Hypervisor         │ ← VMware, VirtualBox
└────────────────────┘
┌────────────────────┐
│ Host OS           │
│ (Windows/Linux)    │
└────────────────────┘

容器：
┌────────────────────┐
│ Container         │ ← 共享宿主机内核，轻量得多
│ ├─ App1           │
│ └─ Dependencies   │
└────────────────────┘
┌────────────────────┐
│ Container Runtime │ ← Docker, containerd
└────────────────────┘
┌────────────────────┐
│ Host OS           │ ← 共享宿主机操作系统
└────────────────────┘
```

### Docker 核心概念

| 概念 | 说明 | 类比 |
|-----|------|------|
| **镜像（Image）** | 容器模板，只读 | 类（Class） |
| **容器（Container）** | 镜像的运行实例 | 对象（Object） |
| **仓库（Registry）** | 存储和分发镜像 | GitHub |
| **Dockerfile** | 构建镜像的脚本 | 构建配方 |

### Docker 工作流程

```
1. 编写 Dockerfile → 定义镜像构建规则
           ↓
2. docker build → 从 Dockerfile 构建镜像
           ↓
3. docker run → 从镜像启动容器
           ↓
4. 容器运行 → 应用程序执行
```

## 9.2 Docker 安装与验证

### 检查 Docker 是否安装

```powershell
# 检查 Docker 版本
docker --version

# 检查 Docker 信息
docker info

# 检查 Docker 是否运行
docker ps
```

2. 安装并启动
3. 确保 WSL 2 后端已启用

```powershell
# 检查 WSL
wsl --status

wsl --install
```

## 9.3 镜像操作

### 镜像基础

```powershell
# 查看本地镜像
docker images
docker image ls

# 查看镜像详细信息
docker image inspect nginx:latest

# 查看镜像大小
docker images --format "{{.Repository}}:{{.Tag}} - {{.Size}}"
```

### 拉取镜像

```powershell
# 拉取镜像（默认 latest）
docker pull nginx

# 拉取特定版本
docker pull nginx:1.25-alpine

# 拉取官方镜像（默认）
docker pull ubuntu
docker pull python:3.11-slim

# 拉取前先确认版本
docker search nginx  # 搜索镜像
```

### 删除镜像

```powershell
# 删除镜像
docker rmi nginx:latest

# 强制删除（正在被容器使用）
docker rmi -f nginx:latest

# 删除所有未使用的镜像
docker image prune

# 删除所有镜像
docker rmi $(docker images -q)
```

### 构建镜像

```powershell
# 从 Dockerfile 构建（当前目录）
docker build -t myapp:latest .

# 从指定目录构建
docker build -t myapp:latest ./path/to/context

# 构建并指定标签
docker build -t myapp:1.0 -t myapp:latest .

# 构建时传入变量
docker build --build-arg VERSION=1.0 -t myapp:1.0 .

# 构建时指定 Dockerfile
docker build -f Dockerfile.dev -t myapp:dev .

# 查看构建历史
docker history myapp:latest
```

## 9.4 容器生命周期

### 创建与启动容器

```powershell
# 创建并启动容器（交互式）
docker run -it ubuntu /bin/bash

# 创建并启动容器（后台运行）
docker run -d --name myapp nginx

# 只创建容器，不启动
docker create --name myapp nginx

# 启动已存在的容器
docker start myapp

# 创建并启动，退出后删除（临时容器）
docker run --rm -it ubuntu /bin/bash
```

### 常用运行参数

```powershell
# -d: 后台运行
docker run -d nginx

# -it: 交互式终端
docker run -it ubuntu bash

# -p: 端口映射（主机端口:容器端口）
docker run -d -p 80:80 nginx
docker run -d -p 8080:80 -p 443:443 nginx

# -v: 挂载卷（主机路径:容器路径）
docker run -v C:\data:/app/data nginx

# -e: 设置环境变量
docker run -e APP_ENV=production -e DB_HOST=localhost nginx

# --name: 命名容器
docker run --name my-nginx nginx

# --network: 加入网络
docker run --network my-network nginx

# --restart: 重启策略
docker run --restart unless-stopped nginx  # 除非手动停止，否则自动重启
docker run --restart always nginx         # 总是重启
docker run --restart on-failure nginx    # 失败时重启

# --rm: 退出后自动删除
docker run --rm nginx

# -w: 工作目录
docker run -w /app node npm start

# -u: 指定用户
docker run -u 1000:1000 nginx
```

### 容器命名与重命名

```powershell
# 启动时命名
docker run --name myapp nginx

# 重命名容器
docker rename myapp newname

# 使用容器 ID（部分即可）
docker start abc123
```

## 9.5 管理运行中的容器

### 查看容器

```powershell
# 查看运行中的容器
docker ps

# 查看所有容器（包括已停止）
docker ps -a

# 查看容器 ID 列表
docker ps -aq

# 格式化输出
docker ps --format "table {{.ID}}\t{{.Names}}\t{{.Status}}\t{{.Ports}}"
```

### 进入容器

```powershell
# 进入运行中的容器
docker exec -it myapp /bin/bash
docker exec -it myapp bash       # 如果容器有 bash
docker exec -it myapp sh          # 如果容器只有 sh

# 在容器中执行命令
docker exec myapp ls /app
docker exec myapp cat /etc/nginx/nginx.conf

# 以 root 用户进入
docker exec -it -u root myapp bash
```

### 停止与启动

```powershell
# 停止容器
docker stop myapp

# 启动容器
docker start myapp

# 重启容器
docker restart myapp

# 停止所有容器
docker stop $(docker ps -aq)

# 强制停止（SIGKILL）
docker kill myapp
```

### 查看容器日志

```powershell
# 查看日志
docker logs myapp

# 实时跟踪日志（类似 tail -f）
docker logs -f myapp

# 查看最近 N 行
docker logs --tail 100 myapp

# 查看特定时间段的日志
docker logs --since "2024-01-01" myapp
docker logs --since 30m myapp

# 显示时间戳
docker logs -t myapp

# 只显示错误日志
docker logs myapp 2>&1 | Select-String "ERROR"
```

### 查看容器信息

```powershell
# 查看容器进程
docker top myapp

# 查看容器端口映射
docker port myapp

# 查看容器文件系统变更
docker diff myapp
# A = Added（新增文件）
# C = Changed（修改文件）
# D = Deleted（删除文件）

# 查看容器详细信息
docker inspect myapp

# 查看资源使用
docker stats myapp
```

## 9.6 网络管理

### Docker 网络模式

| 模式 | 说明 |
|-----|------|
| bridge | 默认模式，容器在独立网络 |
| host | 容器直接使用宿主机网络 |
| overlay | 跨 Docker 主机通信（Swarm） |
| none | 无网络 |
| container | 共享另一个容器的网络栈 |

### 网络操作

```powershell
# 查看网络列表
docker network ls

# 创建网络
docker network create mynetwork

# 查看网络详细信息
docker network inspect bridge

# 将容器连接到网络
docker network connect mynetwork myapp

# 断开容器与网络的连接
docker network disconnect mynetwork myapp

# 删除网络
docker network rm mynetwork

# 删除未使用的网络
docker network prune
```

### 容器间通信

```powershell
# 容器间通信示例
# 1. 创建网络
docker network create myapp-net

# 2. 启动应用容器
docker run -d --name app --network myapp-net myapp:latest

# 3. 启动数据库容器
docker run -d --name db --network myapp-net mysql:8

# 4. 应用容器可以通过 "db" 主机名访问数据库
docker exec app ping db
```

## 9.7 卷（Volume）管理

### 卷的作用

持久化数据，确保容器删除后数据不丢失。

```
匿名卷：
  docker run -v /data nginx  # 存储在 /var/lib/docker/volumes/随机名称/

命名卷（推荐）：
  docker run -v mydata:/data nginx  # 存储在 /var/lib/docker/volumes/mydata/

绑定挂载（开发用）：
  docker run -v C:\data:/data nginx  # 主机目录直接挂载
```

### 卷操作

```powershell
# 创建命名卷
docker volume create mydata

# 查看卷列表
docker volume ls

# 查看卷详细信息
docker volume inspect mydata

# 删除未使用的卷
docker volume prune

# 删除指定卷
docker volume rm mydata

# 查看卷使用情况
docker volume ls -f dangling=true  # 未使用的卷
```

### 使用卷

```powershell
# 使用命名卷
docker run -d -v mydata:/app/data --name app nginx

# 使用绑定挂载
docker run -d -v "$(Get-Location):/app" --name app nginx

# 容器间共享卷
docker run -d --name app1 -v shared:/data nginx
docker run -d --name app2 -v shared:/data nginx
```

## 9.8 Docker Compose

Docker Compose 用于定义和运行多容器应用。

### docker-compose.yml 示例

```yaml
version: "3.8"

services:
  web:
    build: .
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgres://db:5432/mydb
    depends_on:
      - db
    volumes:
      - ./app:/app

  db:
    image: postgres:15
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
    volumes:
      - db-data:/var/lib/postgresql/data

volumes:
  db-data:
```

### 常用命令

```powershell
# 启动所有服务
docker-compose up

# 后台启动
docker-compose up -d

# 重新构建并启动
docker-compose up --build

# 停止并删除
docker-compose down

# 停止并删除卷
docker-compose down -v

# 查看日志
docker-compose logs -f

# 查看状态
docker-compose ps

# 执行命令
docker-compose exec web python manage.py migrate

# 构建服务
docker-compose build

# 扩展服务（运行多个实例）
docker-compose up -d --scale web=3
```

## 9.9 Dockerfile 基础

### 基本结构

```dockerfile
# 指定基础镜像
FROM python:3.11-slim

# 设置工作目录
WORKDIR /app

# 复制文件
COPY requirements.txt .
COPY . .

# 安装依赖
RUN pip install --no-cache-dir -r requirements.txt

# 设置环境变量
ENV APP_ENV=production

# 暴露端口
EXPOSE 8000

# 启动命令
CMD ["python", "main.py"]
```

### 常用指令

```dockerfile
# 基础镜像
FROM ubuntu:22.04

# 元数据
LABEL maintainer="your@email.com"
LABEL version="1.0"
LABEL description="My App"

# 执行命令
RUN apt-get update && apt-get install -y nginx

# 复制文件
COPY ./src /app/src

# 设置环境变量
ENV PATH=/app/bin:$PATH
ENV APP_ENV=production

# 设置工作目录
WORKDIR /app

# 暴露端口
EXPOSE 80
EXPOSE 443

# 定义启动命令
CMD ["python", "app.py"]
ENTRYPOINT ["./entrypoint.sh"]

# 设置用户
USER appuser

# 添加（与 COPY 类似，但支持 URL 和解压）
ADD https://example.com/file.zip /app/
ADD archive.tar.gz /app/
```

### 多阶段构建

```dockerfile
# 阶段 1: 构建
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 阶段 2: 运行
FROM node:18-slim
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/app.js"]
```

## 9.11 常见问题

### 容器无法启动

```powershell
# 1. 查看日志
docker logs myapp

# 2. 查看容器状态
docker inspect myapp

# 3. 检查端口占用
docker port myapp
```

### 权限问题

```powershell
# Linux: 解决权限被拒绝
docker exec -it myapp chown -R user:user /app

# 使用正确的用户
docker run -u $(id -u):$(id -g) myapp
```

### 网络问题

```powershell
# 检查 DNS
docker exec myapp cat /etc/resolv.conf

# 使用 host 网络模式
docker run --network host myapp
```
