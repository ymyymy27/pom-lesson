# 入门命令

PowerShell：`Get-Location` 查看目录；`Get-ChildItem` 列出文件；`Set-Location "目录"` 切换目录；`python "文件.py"` 运行程序。先确认当前目录再操作。

Git：`git status` 查看状态；`git diff` 查看修改；`git add "文件"` 选择提交内容；`git commit -m "修改目的"` 保存提交；`git log --oneline` 查看历史。

Python环境：`python -m venv .venv` 创建环境；`& ".venv/Scripts/python.exe" -m pip install -r requirements.txt` 安装本项目依赖。

先理解正在完成的任务，再查具体命令；完整PowerShell、Git和Bash参考位于同目录。
