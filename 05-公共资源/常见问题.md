# 常见问题

| 现象 | 先检查 | 下一步 |
|---|---|---|
| 找不到python | `python --version` 与 `py --version` | 安装Python并重新打开终端，或选择正确解释器 |
| can't open file | `Get-Location`、`Get-ChildItem` | 回到仓库根目录，给完整相对路径加引号 |
| 运行结果没变化 | 文件是否保存，运行的是不是另一份副本 | 查看命令中的文件名，保存后再次运行 |
| IndentationError | 缩进是否一致 | 每层使用4个空格，不混用Tab |
| NameError | 变量是否先定义，大小写是否一致 | 从报错行向上跟踪赋值 |
| ValueError | 输入能否转换，数据格式是否正确 | 使用最小输入复现，并说明合法格式 |
| ModuleNotFoundError | 解释器与安装环境是否相同 | 用对应解释器的 `-m pip` 安装该项目依赖 |
| PowerShell无法激活环境 | 是否必须激活 | 直接运行 `.venv/Scripts/python.exe` |
| 端口被占用 | 是否已启动另一个服务 | 停止自己的旧服务，或改用另一个端口 |
| CSV或JSON中文乱码 | 文件读写编码 | 使用UTF-8，先备份自己的数据再转换 |

求助模板：我在什么目录执行了什么命令；预期是什么；实际输出或完整错误是什么；最小复现输入是什么；已经尝试了哪些检查。不要附带个人密钥。

AI可以帮助解释错误或提供提示；提交代码时仍需要自己解释和验证。
