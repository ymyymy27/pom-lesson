# 术语表

第一次遇到术语先看直觉解释，再回到具体例子。

| 术语 | 入门解释 |
|---|---|
| 程序 | 保存的指令集合 |
| 进程 | 正在运行的程序实例 |
| 终端 | 输入命令并查看输出的界面 |
| Shell | 解释命令的程序，如PowerShell |
| 解释器 | 执行Python程序的运行环境 |
| 变量 | 绑定到值的名字 |
| 函数 | 接收输入并完成一个任务的过程 |
| 参数 | 传给函数的数据 |
| 返回值 | 函数交给调用者的结果 |
| 列表 | 按顺序保存一组元素 |
| 字典 | 通过键定位值 |
| 异常 | 程序执行失败的信号 |
| 调试 | 基于证据定位和修复问题 |
| 测试 | 检查行为是否满足预期 |
| JSON | 常用文本数据交换格式 |
| SQL | 操作关系数据库的语言 |
| 主键 | 唯一标识表中一行的字段 |
| 事务 | 一组整体提交或回滚的操作 |
| Git | 记录版本和协作的工具 |
| HTTP | 客户端与服务端交换请求响应的协议 |
| API | 程序之间约定的调用接口 |
| 模型 | 从数据或规则得到输出的计算过程 |
| RAG | 检索增强生成：先检索资料，再依据资料生成 |
| Embedding | 把内容表示为数值向量 |
| Agent | 使用模型与工具完成任务的程序结构 |
| MCP | 连接模型应用与外部工具、资源的协议 |
| 训练集 | 用于拟合模型的数据 |
| 测试集 | 用于独立评估的数据 |
