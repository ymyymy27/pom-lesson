## 4. 单元测试示例：UserService

```python
# tests/test_user_service.py
import pytest
from unittest.mock import Mock
from user_service import UserService, UserNotFoundError, User

@pytest.fixture
def mock_repo():
    return Mock()

@pytest.fixture
def service(mock_repo):
    return UserService(repo=mock_repo)

def test_get_user_success(service, mock_repo):
    mock_repo.find_by_id.return_value = User(id=1, name="Alice")
    user = service.get(1)
    assert user.name == "Alice"
    mock_repo.find_by_id.assert_called_once_with(1)

def test_get_user_not_found(service, mock_repo):
    mock_repo.find_by_id.return_value = None
    with pytest.raises(UserNotFoundError):
        service.get(999)
```

## 5. 集成测试示例：Todo API

```python
# tests/test_api.py
import pytest
from fastapi.testclient import TestClient
from app.main import app, todos

@pytest.fixture
def client():
    return TestClient(app)

@pytest.fixture(autouse=True)
def reset_todos():
    todos.clear()
    yield
    todos.clear()

@pytest.mark.integration
def test_create_and_list_todos(client):
    client.post("/todos", json={"title": "学习 pytest", "done": False})
    response = client.get("/todos")
    assert response.status_code == 200
    assert len(response.json()) == 1
    assert response.json()[0]["title"] == "学习 pytest"

@pytest.mark.integration
def test_mark_todo_done(client):
    create = client.post("/todos", json={"title": "任务", "done": False})
    todo_id = create.json()["id"]
    response = client.patch(f"/todos/{todo_id}", json={"done": True})
    assert response.json()["done"] is True
```

## 7. TDD 小练习：添加「优先级」字段

用红-绿-重构为 Todo 添加 `priority: low | medium | high`：

1. **红**：写失败测试 `test_create_todo_with_priority`
2. **绿**：改 `main.py` 让测试通过
3. **重构**：提取校验到 `validators.py`
4. 运行 `pytest --cov=src` 确认仍 ≥ 80%

## 9. 常见问题排查

| 问题 | 解决 |
|------|------|
| `ModuleNotFoundError: calculator` | 确认 `pytest.ini` 中 `pythonpath = src` |
| 集成测试互相污染 | `autouse` fixture 清数据 |
| 覆盖率 0% | `--cov=src` 路径要对 |
| asyncio 测试不跑 | 安装 pytest-asyncio，`asyncio_mode = auto` |
| Windows 路径问题 | 用 `tmp_path` 而非硬编码 `/tmp` |
