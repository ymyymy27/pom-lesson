# Lesson 1: Python 环境与多版本管理

> 理解 Python 是如何安装的、多版本如何共存、以及 Windows 上的特殊机制

---

## 1.1 什么是 Python 环境？

当你运行 `python code.py` 时，系统经历以下步骤：

```
用户输入 python
    ↓
系统查找 python 可执行文件（通过 PATH 环境变量）
    ↓
找到 python.exe 后，启动 Python 解释器进程
    ↓
解释器加载标准库（stdlib）
    ↓
运行代码 code.py
```

**"Python 环境"** 指的是：某个特定 `python.exe` + 它能找到的所有包（site-packages）的组合。

---

## 1.2 Windows 上的 Python 安装位置

### 三种安装方式

| 安装方式 | 典型路径 | 影响范围 |
|---------|---------|---------|
| Microsoft Store | `C:\Users\<用户>\AppData\Local\Microsoft\WindowsApps\` | 当前用户 |
| 官网安装器 | `C:\Program Files\Python311\` | 所有用户 |
| 用户级安装 | `C:\Users\<用户>\AppData\Local\Programs\Python\` | 当前用户 |
| 其他（Anaconda） | `C:\ProgramData\Anaconda3\` | 所有用户 |

### 查看你的 Python 安装信息

```powershell
# 查看所有 Python 解释器路径（可能找到多个）
where python

# 查看当前使用的 Python
python --version
python -c "import sys; print(sys.executable)"

# 查看 sys.path（Python 搜索包的路径列表）
python -c "import sys; print('\n'.join(sys.path))"
```

### 你的情况分析

环境输出示例：
```
Python:  C:\Program Files\Python311\python.exe
pip:     C:\Users\<用户名>\AppData\Roaming\Python\Python311\site-packages\pip
包安装到: C:\Users\<用户名>\AppData\Roaming\Python\Python311\site-packages\
```

这说明你的 Python 是通过 **官网安装器** 安装到 Program Files，但包被安装到了用户级的 Roaming 目录（这是用户级 pip 的默认行为）。

## 1.3 PATH 环境变量

PATH 是操作系统用来查找可执行文件的目录列表。Python 能被找到，就是因为 `python.exe` 所在的目录被加入了 PATH。

### 查看 PATH

```powershell
# 查看所有包含 python 的 PATH 路径
$env:PATH -split ";" | Select-String python

# 或者
[Environment]::GetEnvironmentVariable("Path", "User")
```

### PATH 的优先级

当你在终端输入 `python` 时，系统从左到右在 PATH 列表中搜索，先找到的生效。

例如你的 PATH 可能包含：
```
C:\Program Files\Python311\           ← 找到 python.exe，停！
C:\Users\<用户名>\AppData\Roaming\Python\Python311\
C:\Program Files\nodejs\
...
```

**如果有两个 python.exe，先找到的会被使用。**

---

## 1.4 py launcher（Python 启动器）

Windows 独占功能，帮你管理多个 Python 版本。

### 安装

从 Python 3.3 起，安装 Windows 版 Python 时会自动带上 `py.exe` 启动器。

### 常用命令

```powershell
# 列出所有已安装的 Python 版本
py --list

# 运行默认 Python（通常是最新的）
py code.py

# 指定版本运行
py -3.11 code.py       # 用 3.11 运行
py -3.10 code.py       # 用 3.10 运行

# 查看版本
py --version
```

### 版本选择文件（pyvenv.cfg）

在项目根目录创建 `pyvenv.cfg` 或 `.python-version` 文件，可以指定项目使用的 Python 版本：

```txt
# pyvenv.cfg（在虚拟环境中）
home = C:\Program Files\Python311
include-system-site-packages = false
version = 3.11.9
```

```txt
# .python-version（用于 py launcher）
3.11
```

## 1.5 多版本共存的原理

Python 官方从 3.5 开始支持多版本共存，通过版本号后缀区分：

```
C:\Program Files\Python311\python.exe      # Python 3.11
C:\Program Files\Python311\Scripts\pip.exe # pip for 3.11
C:\Program Files\Python310\python.exe      # Python 3.10
C:\Program Files\Python310\Scripts\pip.exe # pip for 3.10
```

每个 Python 版本有独立的：
- `site-packages/` 目录（包的安装位置）
- `Scripts/` 目录（pip, wheel 等工具）
- 注册表项（Windows）

**关键点**：不同版本的 Python 是**完全隔离**的。安装到 Python 3.11 的包，Python 3.10 完全看不到。

---

## 1.6 系统 Python vs 用户 Python

### 系统 Python

- 安装在 Program Files（需要管理员权限）
- 对所有用户可见
- 容易被系统脚本依赖（不要轻易修改！）

### 用户 Python

- 安装在用户目录下
- 不影响系统和其他用户
- 推荐日常使用

### pip 的两种模式

```powershell
# 用户级安装（默认，pip install）
# 包被安装到: C:\Users\<用户>\AppData\Roaming\Python\

# 全局安装（需要管理员权限）
pip install --global 包名
```

## 1.7 彻底卸载 Python（避免残留导致混乱）

### 官方卸载方式

1. 去 Windows **设置 → 应用 → 已安装的应用**
2. 找到所有 Python 相关项（Python 3.11, Python Launcher 等）
3. 逐一卸载

### 清理残留

卸载后手动检查：

```powershell
# 删除用户 site-packages 残留
Remove-Item -Recurse -Force "$env:APPDATA\Python"

# 删除虚拟环境残留
Remove-Item -Recurse -Force "你的项目\.venv"

# 清理 PATH 中无效的 Python 路径（手动在系统环境变量中删除）
```

### 验证卸载干净

```powershell
where python     # 应该无输出
python --version # 应该报错：'python' 不是内部或外部命令
```

## 1.8 常见问题

### Q1: 有多个 Python，不知道该用哪个？

**答案**：统一使用一个。

在终端运行 `where python`，只保留你决定使用的那个 Python 的路径在 PATH 最前面，其他全部移除（或卸载）。

### Q2: pip 安装的包，IDE 找不到

这正是你遇到的问题。原因是 **IDE 使用的 Python 解释器** 与 **pip 安装包时使用的 Python** 不是同一个。

解决方法：
1. 确定你希望使用的 Python（`python --version`）
2. 在 IDE 中将解释器切换为同一个
3. 或者在该 Python 对应的 Scripts 目录下运行 pip

### Q3: 如何判断某个包安装到了哪个 Python？

```powershell
python -c "import sys; print(sys.prefix)"
# 这就是当前 Python 的"根目录"，包就在 site-packages 下
```
