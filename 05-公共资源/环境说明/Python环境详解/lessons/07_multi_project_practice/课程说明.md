## 7.1 场景概览

你的 `learn` 项目包含多个 stage，每个 stage 可能有不同的依赖需求：

```
learn/
├─ stage-01-data-science/     # numpy, pandas, matplotlib
├─ stage-02-ml-basics/         # scikit-learn, numpy, pandas
├─ stage-03-deep-learning/     # PyTorch, TensorFlow
├─ stage-05-llm-api/          # langchain, openai, langchain-openai
├─ stage-06-fine-tuning/       # transformers, peft, bitsandbytes
├─ stage-07-vector-db/         # chromadb, faiss, qdrant-client
├─ stage-08-rag/               # langchain, langchain-community
└─ stage-11-ai-engineering/   # fastapi, uvicorn
```

**问题**：不同 stage 依赖差异极大，不能共用一个环境。

**解决方案**：每个 stage 使用独立的虚拟环境。

## 7.2 场景 1：AI 学习项目（langchain）

这是你当前遇到的场景。目标是让 `study/01.py` 能正常导入 langchain。

### 当前问题回顾

```
study/01.py 的导入语句：
  from langchain_openai import ChatOpenAI
  from langchain_core.messages import ...

报错原因：Cursor 使用的 Python 解释器 ≠ pip 安装包的 Python
```

### 解决方案

**Option A：使用虚拟环境（推荐）**

```powershell
# 1. 进入项目目录
cd 02-方向选修\02-AI应用\参考资料\02-LLM接口开发

# 2. 创建虚拟环境
python -m venv .venv

# 3. 激活
.\.venv\Scripts\Activate.ps1

# 4. 安装依赖
pip install langchain langchain-openai

# 5. 在 Cursor 中选择虚拟环境的 Python
#    Ctrl+Shift+P → Python: Select Interpreter
#    → Browse → 选择 study\.venv\Scripts\python.exe
```

**Option B：统一使用系统 Python（如果你只有一个 Python）**

```powershell
# 1. 确认只有一个 Python
where python

# 2. 在 Cursor 中选择这个 Python
#    Ctrl+Shift+P → Python: Select Interpreter
#    → 选择 C:\Program Files\Python311\python.exe

# 3. 如果 pip install 到的不是这个 Python，改用：
C:\Program Files\Python311\python.exe -m pip install langchain langchain-openai
```

### 验证修复

1. 在 Cursor 中重新打开 `01.py`
2. `import langchain_openai` 不应有红色下划线
3. 如果仍有报错，`Ctrl+Shift+P` → `Python: Restart LS`

## 7.4 统一管理所有 stage（进阶）

如果你希望有一个统一的地方管理所有环境，可以在父目录创建脚本：

### Windows PowerShell 脚本：创建环境

```powershell
# 在 learn 根目录创建脚本: setup-env.ps1
# 内容：

param(
    [Parameter(Mandatory=$true)]
    [string]$ProjectName
)

$projectPath = Join-Path $PSScriptRoot $ProjectName

if (-Not (Test-Path $projectPath)) {
    Write-Error "项目目录不存在: $projectPath"
    exit 1
}

Set-Location $projectPath

if (Test-Path ".venv") {
    Write-Warning "虚拟环境已存在: .venv"
    $response = Read-Host "是否删除并重建？(y/n)"
    if ($response -eq "y") {
        Remove-Item -Recurse -Force ".venv"
    } else {
        Write-Host "跳过"
        exit 0
    }
}

Write-Host "创建虚拟环境..."
python -m venv .venv

Write-Host "激活虚拟环境..."
.\.venv\Scripts\Activate.ps1

Write-Host "安装基础包..."
pip install --upgrade pip

Write-Host "完成！"
Write-Host "接下来请运行: pip install -r requirements.txt"
```

### 使用脚本

```powershell
# 在 learn 根目录运行
.\setup-env.ps1 -ProjectName "stage-05-llm-api"
```

## 7.6 调试清单

当你遇到环境问题时，按以下清单逐一排查：

```
□ 1. 终端中 `python -c "import 包名"` 是否成功？
□ 2. `where python` 和 IDE 的 Python 路径是否一致？
□ 3. 是否在正确的 Python 下运行的 pip install？
□ 4. 是否创建了虚拟环境但 IDE 未选择该环境？
□ 5. 重启语言服务器（Python: Restart LS）是否解决问题？
□ 6. 是否有多个 Python 安装导致混淆？
□ 7. `pip list` 中的包和 IDE 看到的包是否一致？
```
