# Python 环境与虚拟环境完全指南

> 从零开始，系统掌握 Python 环境管理的完整知识体系

---

## 课程概述

本课程面向 Python 开发者，系统讲解从 **Python 多版本管理** 到 **IDE 环境配置** 的完整知识链条。解决你在日常开发中遇到的"包找不到"、"环境冲突"、"依赖混乱"等问题。

### 前置知识

- 会使用命令行终端（PowerShell / CMD / Bash）
- 了解什么是 Python 和 pip

### 学习目标

- 理解 Python 运行时环境的层次结构
- 掌握 pip / venv / Conda 等环境管理工具
- 熟练使用虚拟环境隔离项目依赖
- 能够正确配置 IDE（Cursor / VS Code）的 Python 解释器
- 能够管理多人协作项目的依赖

## 快速参考命令卡

### 环境查看
```bash
python --version          # 查看当前 Python 版本
which python              # 查看 Python 路径（Linux/Mac）
where python              # 查看 Python 路径（Windows）
pip --version             # 查看 pip 版本和路径
pip list                  # 列出已安装的包
pip show <包名>            # 查看包详情
```

### 虚拟环境
```bash
# 创建（venv）
python -m venv .venv

# 激活
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# Windows CMD:
.\.venv\Scripts\activate.bat
# Linux/Mac:
source .venv/bin/activate

# 停用
deactivate
```

### 包管理
```bash
pip install 包名           # 安装
pip install -r requirements.txt  # 从文件安装
pip freeze > requirements.txt    # 导出依赖
pip uninstall 包名         # 卸载
pip install -U 包名        # 升级
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名  # 使用镜像
```
