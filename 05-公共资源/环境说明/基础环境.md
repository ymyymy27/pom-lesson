# 基础环境

基础课程使用Python标准库。本次自动验证环境：Windows、Python 3.11.9。建议学校统一维护Python 3.11或3.12环境；其他版本需先运行仓库检查。

## Windows PowerShell

```powershell
python --version
python -c "import sys; print(sys.executable)"
```

VS Code中选择同一解释器。第一课不安装第三方依赖。第一次需要外部包时，进入该项目目录执行：

```powershell
python -m venv .venv
& ".venv/Scripts/python.exe" -m pip --version
& ".venv/Scripts/python.exe" -m pip install -r requirements.txt
```

直接调用环境中的python可以避免激活脚本的执行策略问题。requirements.txt只适用于其所在项目；不要把别的项目依赖安装过来。

## macOS与Linux Bash

```bash
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 编码和路径

Python源码与数据使用UTF-8。读写文本指定 encoding="utf-8"；中文路径和有空格的路径放进引号。终端中文显示异常时可使用 `python -X utf8` 运行脚本。
