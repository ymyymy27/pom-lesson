# 第 2 课：高效移动 —— 扔掉方向键

> 目标：完全脱离方向键，靠键盘完成所有光标移动

## 2.1 核心原则：操作 + 移动

Vim/Neovim 的强大之处在于**组合**：

```
操作符（operator）+ 移动命令（motion）= 动作
```

例如：
- `dw` = delete word（删除一个词）
- `y$` = yank to end（复制到行尾）
- `c3w` = change 3 words（修改3个词）

今天先专注学**移动命令**，下一课再学操作符。

## 2.2 基本移动（替代方向键）

| 按键 | 移动方向 |
|------|----------|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |

> 小技巧：右手不用离开主键盘区，j 是向下，l 是向右，记住这两个就能推导其余。

**必须戒掉方向键！** 从今天开始，逼自己只用 h j k l。

## 2.3 词间跳转

| 按键 | 含义 |
|------|------|
| `w` | 跳到下一个**词首** (word) |
| `b` | 跳回上一个**词首** (back) |
| `e` | 跳到当前**词尾** (end) |
| `ge` | 跳回上一个**词尾** |

## 2.4 行内快速跳转

| 按键 | 含义 |
|------|------|
| `0` | 跳到**行首**（绝对第一个字符） |
| `^` | 跳到行首**第一个非空字符** |
| `$` | 跳到**行尾** |
| `f{char}` | 跳到当前行下一个指定字符 (find) |
| `F{char}` | 跳到当前行上一个指定字符 (find backward) |
| `;` | 重复上一次的 f/F 跳转 |
| `,` | 反向重复 f/F |

## 2.5 文件内跳转

| 按键 | 含义 |
|------|------|
| `gg` | 跳到文件**第一行** |
| `G` | 跳到文件**最后一行** |
| `{n}G` | 跳到**第 n 行**（如 `15G`） |
| `{n}%` | 跳到文件的 n% 位置 |
| `Ctrl+o` | 跳回**上一次**位置（older） |
| `Ctrl+i` | 跳到**更新的**位置（newer） |
| `''` | 跳回上一个位置（两个单引号） |

## 2.6 屏幕内跳转

| 按键 | 含义 |
|------|------|
| `H` | 跳到屏幕**最上方** (High) |
| `M` | 跳到屏幕**中间** (Middle) |
| `L` | 跳到屏幕**最下方** (Low) |
| `Ctrl+d` | 向下滚动**半屏** (down) |
| `Ctrl+u` | 向上滚动**半屏** (up) |
| `Ctrl+f` | 向下滚动**一整屏** (forward) |
| `Ctrl+b` | 向上滚动**一整屏** (backward) |
| `zz` | 当前行**居中**屏幕 |
| `zt` | 当前行**置顶**屏幕 |
| `zb` | 当前行**置底**屏幕 |

## 2.7 练习任务

打开 `lessons/02_motion/practice.txt`，完成后对照检查：

1. 只用 h j k l 从头走到尾
2. 用 `w` 跳过一个词，用 `b` 跳回来
3. 用 `0` 和 `$` 快速到行首行尾
4. 用 `f{` 跳到当前行的第一个括号（如果有的话）
5. 用 `G` 跳到文件末尾，再用 `gg` 跳回来
6. 随意跳几次，用 `Ctrl+o` 和 `Ctrl+i` 在位置间切换
