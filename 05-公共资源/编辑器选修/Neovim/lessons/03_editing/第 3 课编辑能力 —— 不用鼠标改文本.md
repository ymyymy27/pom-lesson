# 第 3 课：编辑能力 —— 不用鼠标改文本

> 目标：熟练掌握删除、复制、粘贴、修改操作

## 3.1 删除（Delete）

**格式**：`d` + 移动命令

| 命令 | 含义 |
|------|------|
| `dd` | 删除**整行** |
| `dw` | 删除从光标到**词尾** |
| `d$` | 删除从光标到**行尾** |
| `d^` | 删除从光标到**行首**（不含空白） |
| `d0` | 删除从光标到**行首**（含空白） |
| `daw` | 删除**整个词**含周围空格 (delete a word) |
| `di"` | 删除**引号内**内容（不删引号） |
| `di(` | 删除**括号内**内容 |
| `x` | 删除光标**当前字符**（相当于 `dl`） |
| `X` | 删除光标**前一个字符**（相当于 `dh`） |

### 数字前缀（重复执行）

- `3dd` — 删除 3 行
- `2dw` — 删除 2 个词
- `5x` — 删除 5 个字符

## 3.2 复制 / 粘贴（Yank / Paste）

**格式**：`y` + 移动命令（y = yank，即复制）

| 命令 | 含义 |
|------|------|
| `yy` | 复制**整行** |
| `yw` | 复制到**词尾** |
| `y$` | 复制到**行尾** |
| `p` | 在光标**后**粘贴 |
| `P` | 在光标**前**粘贴 |

- 复制完后用 `p` 粘贴，`p` 在光标**之后**贴，`P` 在**之前**贴
- `yy` + `p` = 复制整行并粘贴到下方

## 3.3 修改（Change）

**格式**：`c` + 移动命令（c = change，即删除后进入插入模式）

| 命令 | 含义 |
|------|------|
| `cc` | 删除整行并进入插入模式 |
| `cw` | 删除到词尾并进入插入模式 |
| `c$` | 删除到行尾并进入插入模式 |
| `ci"` | 修改引号内的内容 |
| `ci(` | 修改括号内的内容 |

**小技巧**：`cc` 和 `S` 效果相同，`C` = `c$`（删到行尾）。

## 3.4 撤销 / 重做

| 命令 | 含义 |
|------|------|
| `u` | 撤销上一次操作 (undo) |
| `Ctrl+r` | 重做 (redo) |
| `U` | 撤销当前行的所有修改 |

## 3.5 重复与替换

| 命令 | 含义 |
|------|------|
| `.` | 重复**上次操作**（最常用！） |
| `~` | 切换当前字符**大小写** |
| `guu` | 当前行**变小写** |
| `gUU` | 当前行**变大写** |
| `r{char}` | 替换光标处**单个字符**，不进入插入模式 |
| `R` | 进入**替换模式**，连续覆盖 |

## 3.6 操作符总结

```
d  = delete（删除）
y  = yank（复制）
c  = change（修改 = 删除 + 插入）
~  = toggle case
<  = 左缩进
>  = 右缩进
=  = 自动格式化
```

每个操作符都可以加数字前缀和移动命令：
- `3d2w` — 删除 3 个"两个词"（共6个词）
- `2y}` — 复制两段
- `dG` — 删除到文件末尾
