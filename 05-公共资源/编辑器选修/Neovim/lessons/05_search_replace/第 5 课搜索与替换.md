# 第 5 课：搜索与替换

> 目标：掌握快速查找和批量替换

## 5.1 搜索

```vim
/{pattern}        " 向下搜索
?{pattern}        " 向上搜索
n                " 下一个匹配
N                " 上一个匹配
*                " 搜索光标下的单词（向下）
#                " 搜索光标下的单词（向上）
g*               " 同 * 但不匹配单词边界
g#               " 同 # 但不匹配单词边界
```

### 搜索选项

```vim
:set incsearch    " 开启增量搜索（边打边高亮）
:set hlsearch     " 高亮所有匹配
:noh              " 清除搜索高亮 (no highlight)
:set ignorecase   " 忽略大小写
:set smartcase    " 如果有大写则区分大小写
```

## 5.2 正则搜索

```vim
/\bword\b         " 匹配完整单词
/\d+              " 匹配数字
/\S+              " 匹配非空白字符
```

## 5.3 替换

```vim
:s/old/new/       " 替换当前行**第一个**匹配
:s/old/new/g      " 替换当前行**所有**匹配
:s/old/new/gc     " 替换所有并逐个确认
:%s/old/new/      " 替换所有行的第一个匹配
:%s/old/new/g     " 替换所有行的所有匹配
:%s/old/new/gc    " 替换所有行，逐个确认
:5,10s/a/b/g      " 替换第 5-10 行
```

### 替换确认提示

执行 `:%s/old/new/gc` 后，每处匹配会显示：

```
replace with new (y/n/a/q/l/^E/^Y)?
```

- `y` — 替换
- `n` — 跳过
- `a` — 全部替换（answer all）
- `q` — 退出
- `l` — 替换后退出
- `^E` / `^Y` — 上下滚动

## 5.4 替换中的特殊符号

```vim
:%s/\(old\)/new/g            " 用括号捕获
:%s/\1/\2/g                   " 交换内容
:%s/^/prefix/                 " 行首加前缀
:%s/$/suffix/                 " 行尾加后缀
```

## 5.5 快速行查找

```vim
:{num}                        " 跳到第 num 行
:/pattern                     " 跳到下一个匹配并进入命令模式
:f {text}                     " 快速跳到包含 text 的行
```
