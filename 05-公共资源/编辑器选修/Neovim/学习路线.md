# Neovim 学习路线图

> 适合零基础，按阶段递进，每天 1-2 小时，约 2-3 周掌握核心用法。

## 学习目标

- 阶段一：能够在 Neovim 中完成日常文本编辑（相当于 Notepad 级别）
- 阶段二：掌握高效移动和批量编辑（vim 思维模式）
- 阶段三：配置自己的 Neovim，理解插件生态
- 阶段四：深度定制，打造高效开发环境

---

## 阶段一：生存模式（第 1-3 天）

**目标：不死，不丢数据，能打出字**

### 必背操作

1. **进入/退出**
   - `i` — 进入插入模式
   - `Esc` — 退回普通模式
   - `:wq` + 回车 — 保存退出（一定要先练这个！）

2. **打出文字**
   - `i` 进入插入模式后，像普通编辑器一样打字
   - `a` 在光标后插入（append）
   - `o` 在下行新建行

3. **紧急撤离**
   - 如果操作混乱了，连按几次 `Esc`，然后 `:q!` 强制退出不会丢数据
   - `:w` 随时保存

### 练习任务

打开 `lessons/01_basics/practice.txt`，按里面的步骤练习。

### 验收标准

- 能在 Neovim 里新建文件并写入内容
- 能保存文件并重新打开确认内容存在
- 不会因为误操作导致无法退出

## 阶段二：高效移动（第 4-6 天）

**目标：不用方向键，靠键盘走天下**

### 核心概念

Vim 的精髓在于**操作与移动分离**：

- 移动命令（motion）告诉你"到哪里"
- 操作命令（operator）告诉你"做什么"
- 组合起来：`operator + motion`

### 必学内容

1. **基本移动**
   - `h j k l` — 左下上右（取代方向键）
   - `w b` — 词间跳转（word forward/back）
   - `0 $` — 行首行尾

2. **跨文件移动**
   - `gg G` — 文件开头/结尾
   - `{n}G` — 跳转到第 n 行
   - `Ctrl+o / Ctrl+i` — 跳转历史

3. **查找跳转**
   - `/word` — 向下搜索，`n` 下一处，`N` 上一处
   - `f{char}` — 跳到当前行下一个字符，`;` 重复
   - `%` — 跳转到匹配括号

### 练习任务

打开 `lessons/02_motion/practice.txt`，完成里面的移动练习。

### 验收标准

- 编辑时全程不用方向键
- 能快速在文件任意位置间跳转
- 能在一屏内精确定位

---

## 阶段三：编辑能力（第 7-10 天）

**目标：不用鼠标做任何操作**

### 必学内容

1. **删除、复制、粘贴**
   - `dd dw d$ d^` — 删行/删词/删到行尾/删到行首
   - `yy yw y$` — 复制（yank）
   - `p P` — 粘贴（paste）
   - `x` — 删除当前字符

2. **撤销与恢复**
   - `u` — 撤销（undo）
   - `Ctrl+r` — 重做（redo）
   - `.` — 重复上次操作

3. **快速修改**
   - `ci"` — 修改引号内的内容
   - `ci(` — 修改括号内的内容
   - `ca"` — 含引号一起改
   - `cis` — 修改当前句子

4. **大小写与替换**
   - `~` — 切换大小写
   - `guu` — 整行变小写，`gUU` 整行变大写
   - `r{char}` — 替换单个字符

### 练习任务

打开 `lessons/03_editing/practice.txt`。

### 验收标准

- 能熟练删除、复制、粘贴
- 熟练使用 `ci"` 类文本对象
- 能用 `.` 重复操作

## 阶段四：Buffers / Windows / Tabs（第 11-12 天）

### 概念澄清

- **Buffer** — 内存中的文件副本（看不见但存在）
- **Window** — Buffer 的可视化窗口（你看到的画面）
- **Tab** — Window 的分组容器

### 必学命令

```vim
:ls              " 列出所有 buffer
:bn / :bp        " 切换下一个/上一个 buffer
:bd              " 删除当前 buffer
:sp file         " 水平分割窗口
:vsp file        " 垂直分割窗口
Ctrl+w h/j/k/l   " 窗口间移动
Ctrl+w w         " 下一个窗口
Ctrl+w c         " 关闭当前窗口
:tabnew          " 新建标签页
gt / gT          " 标签页切换
```

### 验收标准

- 能同时打开和切换多个文件
- 能分屏查看两个文件内容

## 阶段五：搜索与替换（第 13 天）

```vim
/pattern          " 搜索（n下一个 N上一个）
*                " 搜索光标下单词
:%s/old/new/g    " 全局替换
:%s/old/new/gc   " 逐个确认替换
:2,10s/a/b/g     " 替换第2到10行
```

---

## 阶段六：宏与寄存器（第 14 天）

```vim
qa               " 开始录制到寄存器 a
q                " 停止录制
@{a}             " 执行寄存器 a 的宏
10@a             " 执行10次
"ayy             " 复制当前行到寄存器 a
"ap              " 粘贴寄存器 a 的内容
:reg             " 查看所有寄存器
```

---

## 阶段七：可视化模式（第 15 天）

```
v                " 字符可视化
V                " 行可视化
Ctrl+v           " 块可视化（多行编辑！）
```

块可视化 + `I` / `A` + 打字 + `Esc` = 多行同时插入。

## 阶段八：配置 Neovim（第 16-20 天）

### 现代配置结构

```
~/.config/nvim/
├── init.lua         " 入口文件
├── lua/
│   └── user/
│       ├── init.lua " 选项设置
│       ├── keymaps.lua " 快捷键
│       └── plugins.lua " 插件列表
└── plugin/          " 插件配置
```

### 入门配置示例

见 `config/init.lua`

### 必装插件（推荐）

| 插件 | 用途 |
|------|------|
| `lazy.nvim` | 插件管理器 |
| `nvim-treesitter` | 语法高亮 |
| `nvim-lspconfig` | LSP 支持 |
| `telescope.nvim` | 文件搜索/模糊查找 |
| `oil.nvim` | 文件管理器 |
| `mini.nvim` | 一系列小型优秀插件 |

### 学习资源

- `:help user-manual` — 内置官方手册
- `:help {topic>` — 查任意主题
- `vim-adventures.com` — 打字游戏学 vim 移动
- `neovim.io` — 官方网站
