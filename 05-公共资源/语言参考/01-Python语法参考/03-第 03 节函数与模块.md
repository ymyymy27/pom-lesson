# 第 03 节：函数与模块

## 一、函数基础

### 1.1 定义与调用

```python
# 基本函数定义
def greet(name):
    """向某人打招呼（这是文档字符串 docstring）"""
    return f"你好，{name}！"

# 调用
message = greet("张三")
print(message)  # "你好，张三！"
```

### 1.2 参数类型

```python
# 1. 位置参数 — 按顺序传入
def add(a, b):
    return a + b

add(1, 2)  # 3

# 2. 默认参数 — 有默认值，调用时可省略
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

greet("张三")           # "你好，张三！"
greet("张三", "早上好")  # "早上好，张三！"

# 3. 关键字参数 — 用参数名传入，顺序无所谓
greet(greeting="晚上好", name="李四")

# 4. *args — 接收任意数量的位置参数，打包成元组
def sum_all(*args):
    print(type(args))  # <class 'tuple'>
    return sum(args)

sum_all(1, 2, 3)       # 6
sum_all(1, 2, 3, 4, 5) # 15

# 5. **kwargs — 接收任意数量的关键字参数，打包成字典
def create_user(**kwargs):
    print(type(kwargs))  # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key} = {value}")

create_user(name="张三", age=25, city="北京")

# 6. 组合使用（顺序：位置参数 → *args → 关键字参数 → **kwargs）
def func(a, b, *args, key="default", **kwargs):
    print(a, b)
    print(args)
    print(key)
    print(kwargs)
```

### 1.3 返回值

```python
# 返回单个值
def square(x):
    return x ** 2

# 返回多个值（本质是返回元组）
def divide(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide(10, 3)  # q=3, r=1

# 没有 return 或 return 后不带值 → 返回 None
def say_hello(name):
    print(f"Hello, {name}")
    # 隐式返回 None

result = say_hello("张三")
print(result)  # None
```

## 二、作用域

### 2.1 LEGB 规则

Python 查找变量的顺序：**L → E → G → B**

```
L (Local)      — 函数内部局部变量
E (Enclosing)  — 外层嵌套函数的变量
G (Global)     — 模块级全局变量
B (Built-in)   — Python 内置变量（print, len, ...）
```

```python
x = "全局变量"        # G

def outer():
    x = "外层变量"    # E
    
    def inner():
        x = "局部变量" # L
        print(x)      # "局部变量" — 优先找 L
    
    inner()
    print(x)          # "外层变量"

outer()
print(x)              # "全局变量"
```

### 2.2 global 和 nonlocal

```python
count = 0

def increment():
    global count        # 声明使用全局变量
    count += 1

increment()
print(count)  # 1

def outer():
    value = 10
    
    def inner():
        nonlocal value  # 声明使用外层函数的变量
        value += 1
    
    inner()
    print(value)  # 11
```

> ⚠️ **建议**：尽量避免使用 `global`，通过参数和返回值传递数据更清晰。

## 三、Lambda 表达式

匿名函数，适合简短的一次性操作。

```python
# 普通函数
def square(x):
    return x ** 2

# 等价的 lambda
square = lambda x: x ** 2

# 常与高阶函数搭配
numbers = [3, 1, 4, 1, 5, 9, 2, 6]

# sorted — 自定义排序
users = [{"name": "张三", "age": 30}, {"name": "李四", "age": 25}]
sorted_users = sorted(users, key=lambda u: u["age"])
# [{"name": "李四", "age": 25}, {"name": "张三", "age": 30}]

# map — 对每个元素应用函数
squares = list(map(lambda x: x ** 2, numbers))

# filter — 过滤元素
evens = list(filter(lambda x: x % 2 == 0, numbers))
```

> ⚠️ 如果 lambda 逻辑复杂，请改用普通函数，保持代码可读性。

## 四、高阶函数

"接收函数作为参数"或"返回函数"的函数。

```python
# 函数作为参数
def apply(func, value):
    return func(value)

result = apply(abs, -10)     # 10
result = apply(str.upper, "hello")  # "HELLO"

# 函数作为返回值
def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))   # 10
print(triple(5))   # 15
```

### 内置高阶函数

```python
numbers = [1, 2, 3, 4, 5]

# map(func, iterable) — 对每个元素应用函数
doubled = list(map(lambda x: x * 2, numbers))  # [2, 4, 6, 8, 10]

# filter(func, iterable) — 保留返回 True 的元素
evens = list(filter(lambda x: x % 2 == 0, numbers))  # [2, 4]

# reduce(func, iterable) — 累积计算
from functools import reduce
total = reduce(lambda a, b: a + b, numbers)  # 15

# 实际开发中，列表推导式通常比 map/filter 更 Pythonic
doubled = [x * 2 for x in numbers]
evens = [x for x in numbers if x % 2 == 0]
```

## 五、模块与包

### 5.1 模块 (Module)

一个 `.py` 文件就是一个模块。

```python
# math_utils.py
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

PI = 3.14159
```

```python
# main.py

# 方式1：导入整个模块
import math_utils
print(math_utils.add(1, 2))
print(math_utils.PI)

# 方式2：导入特定内容
from math_utils import add, PI
print(add(1, 2))
print(PI)

# 方式3：导入并重命名
from math_utils import add as addition
import math_utils as mu

# 方式4：导入所有（不推荐，容易命名冲突）
from math_utils import *
```

### 5.2 包 (Package)

包含 `__init__.py` 的文件夹就是一个包。

```
my_package/
├── __init__.py        # 标识这是一个包（可以为空）
├── utils.py
├── models.py
└── services/
    ├── __init__.py
    └── email.py
```

```python
# 导入包中的模块
from my_package import utils
from my_package.services import email
from my_package.models import User
```
