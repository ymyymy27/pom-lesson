# AI 开发学习路线图

> 13 阶段 · 约 75 天 · 贯穿项目 AI Hub

## 前置要求

- Python 基础（函数、类、装饰器、异步）
- Web 开发基础（HTTP、REST API）
- Git 与命令行

**环境准备：** 若 Python 环境不熟悉，先完成 [`stage-00-python-env/`](../../../05-公共资源/环境说明/Python环境详解)（7 课，约 2 天）。
