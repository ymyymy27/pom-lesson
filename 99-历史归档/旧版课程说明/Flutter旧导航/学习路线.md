# Flutter 学习路线图（周计划）

面向已有开发经验的 6–7 周计划，每天 2–3 小时。核心原则：**每个阶段都有可见产出**，语言与框架知识只学到够用即进入实战。

## 总体节奏

```text
第 1 周    Dart 速成 + Flutter 环境        → 跑通第一个 App
第 2–3 周  Widget 与 UI 构建               → TaskFlow 静态 UI
第 3–4 周  状态管理 + 路由                  → 可交互的任务列表
第 4–5 周  本地存储 + 网络对接              → 对接 Django API 的完整 App
第 5 周    测试与 CI                       → 核心逻辑覆盖率 80%+
第 6 周    平台能力 + 原生集成              → 拍照上传 + 推送
第 7 周    构建发布 + 生产运维              → 可安装 APK + 上架文档
```

## 第 1 周：语言与环境

| 天 | 内容 | 文件 | 产出 |
|----|------|------|------|
| 1 | Dart 语法速览（与 TS 对照）：空安全、类型、集合、记录 | `stage-01/01` | 运行 20 个对照代码片段 |
| 2 | 面向对象：类、继承、mixin、接口、枚举 | `stage-01/02` | 用 Dart 重写一个之前的 Python 小模块 |
| 3 | 函数式 + 集合操作：闭包、高阶函数、扩展方法 | `stage-01/03` | 完成集合处理练习 |
| 4 | 异步：Future、Stream、async/await | `stage-01/04` | 实现一个流式文件读取示例 |
| 5 | 泛型、错误处理、pub 依赖管理 | `stage-01/05` | 跑通依赖安装与单测 |
| 6–7 | Flutter 环境搭建 + 工程结构 + 计数器逐行解读 | `stage-02/01`–`03` | 跑通 Windows 桌面端 App |

**验收**：能不看资料说出 Dart 与 TypeScript 的 5 个关键差异；能解释 Flutter 项目每个目录的作用。

## 每日学习节奏（参考）

```text
1. 阅读（30–45 min）  当课 Markdown，概念 + 代码示例
2. 动手（45–90 min）  运行示例 → 改造成 TaskFlow 的一部分
3. 反思（10 min）     自检清单 + 用 3 句话向同事解释今天学到的概念
```

## 弹性调整建议

- React 经验扎实：Stage 03 可压缩至 4–5 天，重点做差异对照
- 想先出成果：可跳到 Stage 07 先联调，再回来补 UI 细节
- 后端 API 未就绪：先用 json-server 或 Mock 数据，Stage 07 再切换
