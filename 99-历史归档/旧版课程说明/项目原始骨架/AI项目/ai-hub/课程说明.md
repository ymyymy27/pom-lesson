# AI Hub — AI 智能助手平台

贯穿 AI 开发课程的实战项目。随各阶段学习进度，逐步集成 ML 分类、LLM 问答、RAG 知识库、多模态理解与 Agent 能力。

## 项目结构

```
ai-hub/
├── app/
│   └── main.py       # FastAPI 入口
├── requirements.txt
└── README.md
```

## 里程碑

| 完成阶段 | AI Hub 能力 |
|----------|-------------|
| 02 | 文本分类 / 情感分析（Scikit-learn） |
| 05 | LLM 智能问答 |
| 08 | RAG 知识库检索 |
| 09 | AI Agent 自主任务 |
| 11–12 | 生产级 API 部署与监控 |

## 快速启动

```bash
cd 99-历史归档/旧版课程说明/项目原始骨架/AI项目/ai-hub
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

访问 http://127.0.0.1:8000/docs 查看 API 文档。
