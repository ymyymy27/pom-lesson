# 简化GPT实验源码

保留旧实验中有教学内容的源码，供已经学习PyTorch、序列模型和注意力机制的学生对照阅读。此目录属于进阶参考，源码仅做语法检查，尚未在当前环境完成训练复现。

| 文件 | 阅读内容 |
|---|---|
| [01.py](01.py) | 张量练习 |
| [02.py](02.py) | 简单训练过程 |
| [03.py](03.py) | CNN结构 |
| [04.py](04.py) | RNN、LSTM与GRU |
| [05.py](05.py) | 注意力结构 |
| [06.py](06.py) | 简化模型与训练循环 |
| [train.py](train.py) | 文本训练与保存检查点 |
| [demo.py](demo.py) | 加载自己训练的检查点 |

个人训练语料、已有权重和无关图片已清理。复现时在自己的项目副本准备`data/train.txt`和`data/val.txt`，训练输出位于`checkpoints/`；运行生成脚本前需自行完成训练。模型输出和耗时应按自己的数据与设备记录。

旧数据下载脚本和预处理脚本依赖作者机器路径，不再作为入口保留。请使用教师提供、来源明确的数据自行准备输入。PyTorch环境与知识先修见[深度学习参考](../../03-进阶专题/05-模型训练与推理部署/01-深度学习/课程说明.md)。
