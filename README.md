# 从零开始学习编程与计算机实践

面向零基础计算机专业大学生。先学会运行、解释、修改和编写小程序，再选择一个方向完成应用。

**第一次来：[开始学习](开始学习.md)。**

| 入口 | 你会找到什么 |
|---|---|
| [课程总览](课程总览.md) | 16周基础主线、先修关系、方向选择与状态 |
| [基础必修](01-基础必修/课程说明.md) | 32课、96小时，示例、练习、提示、答案与验收 |
| [项目实践](04-项目实践/课程说明.md) | TaskFlow、资料问答、校园数据分析 |
| [公共资源](05-公共资源/课程说明.md) | 环境、术语、排错与命令速查 |
| [教学管理](06-教学管理/课程说明.md) | 教学计划、评价标准、迁移与验证记录 |

基础阶段使用 Python 标准库；Web方向逐步引入 Django；AI方向先完成离线检索与评估。技术名称保留英文，内容说明使用中文。

课程状态“可试学”表示配套材料与自动运行检查已就绪；“已验证”需要真实学生试学通过。详细边界见[运行验证记录](06-教学管理/运行验证记录.md)。

维护者检查：`python "工具脚本/检查课程目录.py"`、`python "工具脚本/检查课程链接.py"`、`python "工具脚本/验证课程.py"`。
