# 第 07 课：主流搜索引擎实践

## 1. 核心问题

原理懂了，生产用什么？这一课对比主流搜索引擎产品，
并给出 Elasticsearch 的核心概念和相关性调优路径。

## 2. 产品对比

| 产品 | 底层 | 特点 | 适合 |
|------|------|------|------|
| Elasticsearch | Lucene | 生态最全、分布式、向量检索内置 | 企业搜索/RAG 标配 |
| OpenSearch | Lucene | ES 分支，AWS 托管 | 需要开源合规 |
| Meilisearch | 自研 | 开箱即用、错字容忍强 | 小型站点/快速上线 |
| Tantivy | Rust | 库而非服务，性能好 | 嵌入产品自研 |
| Vespa | 自研 | 支持 ML 排序、大规模 | 大厂复杂排序 |
| Whoosh | Python | 纯 Python、教学友好 | 学习原型 |

## 3. Elasticsearch 核心概念

### 3.1 术语映射

| ES 术语 | 类比关系数据库 | 本课程概念 |
|---------|--------------|-----------|
| Index | 数据库 | 一个文档集合 |
| Type（已废弃） | 表 | —— |
| Document | 行 | 一篇文档 |
| Mapping | Schema | 字段类型 + 分析器 |
| Shard | 分片 | 分布式分片 |
| Segment | —— | 不可变段 |

### 3.2 Mapping 与分析器

```json
{
  "mappings": {
    "properties": {
      "title": { "type": "text", "analyzer": "ik_max_word" },
      "content": { "type": "text", "analyzer": "ik_max_word" },
      "views": { "type": "integer" },
      "published_at": { "type": "date" }
    }
  }
}
```

要点：

- `text` 类型：分词后进倒排索引（用于搜索）
- `keyword` 类型：原样存储（用于过滤、排序、聚合）
- 分析器选错 = 搜索全部失效，**上线前必须测试分析器**
- 中文需要 IK 分词插件（或内置 ICU/自建词典）

### 3.3 搜索 API

```json
GET /docs/_search
{
  "query": {
    "bool": {
      "must": [{ "match": { "content": "报销 流程" } }],
      "filter": [{ "term": { "status": "published" } }],
      "should": [{ "match": { "title": "报销" } }]
    }
  },
  "size": 10
}
```

- `must`：必须匹配（参与打分）
- `filter`：必须匹配（不参与打分，可缓存）
- `should`：加分项（title 命中加分）

## 4. 相关性调优路径

```
第一步：确认分析器（分词一致）
第二步：用 match + bool 结构（字段权重）
第三步：function_score 叠加业务权重（新鲜度、浏览量）
第四步：同义词扩展召回
第五步：向量字段 + 混合检索（kNN + BM25，RRF）
第六步：精排（LTR / Cross-Encoder）
```

每一步都要用评估集验证（第 8 课），不要凭感觉调参。

### 4.1 字段权重

```json
{
  "query": {
    "multi_match": {
      "query": "报销流程",
      "fields": ["title^3", "content"],
      "type": "best_fields"
    }
  }
}
```

标题命中权重是正文的 3 倍。

### 4.2 业务加权

```json
{
  "query": {
    "function_score": {
      "query": { "match": { "content": "报销" } },
      "functions": [
        { "gauss": { "published_at": { "origin": "now", "scale": "30d" } } }
      ]
    }
  }
}
```

越新的文档分数越高（高斯衰减）。

## 5. 常见坑

1. **Mapping 建完才发现类型错了**：text 和 keyword 不能直接改，需要重建索引
2. **分析器不一致**：索引和查询用了不同分析器
3. **深分页**：`from + size` 超过 1 万会越来越慢，用 `search_after`
4. **分片过多**：每个分片都有开销，小数据别拆太多分片
5. **同义词放错位置**：同义词是查询侧还是索引侧，效果完全不同

## 6. 迷你搜索 vs 产品级搜索的差距

| 能力 | 迷你搜索引擎（第 10 课） | 产品级（ES） |
|------|------------------------|-------------|
| 索引 | 内存倒排索引 | 磁盘段 + 压缩 |
| 分布式 | 无 | 分片/副本 |
| 排序 | BM25 | BM25 + 向量 + function_score + LTR |
| 高可用 | 无 | 副本 + 故障转移 |
| 运维 | 无 | 监控/容量/升级 |

先理解原理（迷你版），再使用产品（ES），是最高效的学习路径。
