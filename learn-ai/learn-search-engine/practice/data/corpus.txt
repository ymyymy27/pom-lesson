[1] 报销制度
日常报销单笔金额不超过5000元，由部门主管审批即可。单笔超过5000元的报销，需要额外提交财务总监审批，并附上完整的发票和说明。差旅报销需在行程结束后15个工作日内提交。
[2] 年假制度
员工入职满一年后，每年可享受5天带薪年假。入职满三年后，年假增至10天；满五年后增至15天。年假需提前3个工作日在OA系统申请，经主管审批后生效。
[3] 远程办公政策
公司实行每周最多两天的远程办公政策。远程办公需提前一天在系统登记，并保证工作时间内可随时联系。研发部门在版本发布周暂停远程办公。
[4] 加班制度
加班需要提前提交加班申请，经部门主管审批后生效。工作日加班按1.5倍工资计算，周末加班按2倍工资计算，法定节假日加班按3倍工资计算。每月加班时长累计不超过36小时。
[5] 后端技术栈
公司后端主要使用 Python 和 FastAPI 构建服务，接口遵循 REST 风格。代码仓库使用 Git 管理，通过 CI/CD 流水线自动部署。
[6] 数据存储选型
业务数据主库使用 PostgreSQL，热数据缓存使用 Redis，大数据分析使用 ClickHouse。所有数据库均提供读写分离和定期备份。
[7] 项目X：智云平台
智云平台是公司的核心订单服务平台，后端使用 Python、FastAPI，数据存储使用 PostgreSQL 和 Redis。项目由研发部负责，服务部署在 Kubernetes 集群。
[8] 项目Y：星图分析
星图分析是公司的大数据可视化项目，使用 ClickHouse 存储分析数据，前端使用 React 构建数据大屏。支持实时指标展示和报表导出。
[9] 新员工入职流程
新员工入职当天需携带身份证、学历证书和离职证明。HR会安排工位和办公设备，导师会在第一周安排培训计划，帮助新员工熟悉团队。
[10] 薪资发放制度
公司每月15日发放上月薪资，如遇节假日则提前至最近工作日。工资条可在HR系统中查看，如有异议可在发薪后5个工作日内提出。
[11] 机器学习平台规范
机器学习训练任务需申请GPU资源，任务在训练队列中排队执行。训练完成后模型需注册到模型仓库，并记录版本、数据和指标。
[12] 模型部署规范
模型上线前需通过离线评测和压测，使用 vLLM 部署推理服务，支持灰度发布和快速回滚。线上服务需配置监控告警和限流。
