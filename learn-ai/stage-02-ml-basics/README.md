# 第 02 阶段：机器学习基础

## 学习目标

完成本阶段后，你将能够：
- 理解监督/无监督学习的基本概念与工作流程
- 使用 Scikit-learn 实现回归与分类模型
- 掌握特征工程、交叉验证与超参数调优
- 用评价指标（准确率、F1、AUC 等）评估模型性能
