# PyTorch 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_tensors.py` | 张量(Tensor)基础操作 |
| 第2课 | `02_autograd.py` | 自动求导机制 |
| 第3课 | `03_neural_network.py` | 构建神经网络 |
| 第4课 | `04_data_loading.py` | 数据加载与预处理 |
| 第5课 | `05_mnist_project.py` | 完整项目：手写数字识别 |
| 第6课 | `06_save_load.py` | 模型保存与加载 |
| 第7课 | `07_gpu_tips.py` | GPU加速与实用技巧 |

## 环境配置

```bash
# 1. 创建虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate    # Windows

# 2. 安装依赖
pip install -r requirements.txt
```

## 学习方式

建议按顺序学习每个文件，每个文件都可以直接运行：
```bash
python 01_tensors.py
```

每个文件都有详细的中文注释，建议边读代码边运行，观察输出结果。
