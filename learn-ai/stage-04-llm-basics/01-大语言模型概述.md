## 2. LLM 核心原理

### 自回归生成

LLM 本质上是一个概率模型，逐个预测下一个 token：

```
P(x₁, x₂, ..., xₙ) = P(x₁) × P(x₂|x₁) × P(x₃|x₁,x₂) × ...

输入: "今天天气"
模型: P(真|今天天气) = 0.3, P(不|今天天气) = 0.2, P(很|今天天气) = 0.4
输出: "很" → 继续生成...
```

### 预训练 + 微调范式

```
1. 预训练（Pre-training）
   - 在海量文本上学习语言规律
   - 无监督：预测下一个 token
   - 需要巨大算力

2. 指令微调（Instruction Tuning / SFT）
   - 用 <指令, 回复> 数据对齐人类意图
   - 让模型学会遵循指令

3. 人类反馈强化学习（RLHF / DPO）
   - 用人类偏好优化输出质量
   - 使输出更安全、更有帮助
```

## 3. Tokenizer

LLM 不直接处理文本，而是处理 token（词元）。

```python
# 使用 tiktoken（OpenAI 的 tokenizer）
import tiktoken

enc = tiktoken.encoding_for_model("gpt-4")

text = "Hello, world! 你好世界"
tokens = enc.encode(text)
print(f"文本: {text}")
print(f"Token IDs: {tokens}")
print(f"Token 数量: {len(tokens)}")

# 解码
decoded = enc.decode(tokens)
print(f"解码: {decoded}")

# 查看每个 token
for token_id in tokens:
    print(f"  {token_id} → '{enc.decode([token_id])}'")
```

```python
# 使用 HuggingFace tokenizer
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")
result = tokenizer("今天天气很好", return_tensors="pt")
print(result)
# {'input_ids': tensor([[...]]), 'attention_mask': tensor([[...]])}
```

### Token 计费

```
OpenAI 计费单位是 token（约 4 个英文字符 = 1 token）

估算规则：
- 英文: 1 word ≈ 1.3 tokens
- 中文: 1 字 ≈ 1-2 tokens
- 代码: 视语言而定

上下文窗口（Context Window）：
- GPT-4o: 128K tokens
- Claude 3.5: 200K tokens
- DeepSeek: 128K tokens
```

## 4. 主流 LLM 对比

### 闭源模型

| 模型 | 公司 | 特点 |
|------|------|------|
| GPT-4o | OpenAI | 多模态，综合能力强 |
| Claude 3.5 Sonnet | Anthropic | 长上下文，代码能力强 |
| Gemini 1.5 Pro | Google | 超长上下文（1M tokens） |
| 通义千问 | 阿里 | 中文能力强，开源生态 |

### 开源模型

| 模型 | 参数量 | 特点 |
|------|--------|------|
| LLaMA 3 | 8B/70B | Meta 出品，社区活跃 |
| Qwen 2.5 | 0.5B-72B | 阿里出品，中文强 |
| DeepSeek V3/R1 | 671B(MoE) | 推理能力强，性价比高 |
| Mistral | 7B/8x7B | 欧洲出品，效率高 |
| GLM-4 | 9B | 智谱出品，中文 |

### 选型建议

```
个人学习 / 本地运行 → Qwen 2.5 7B / LLaMA 3 8B / DeepSeek
API 调用 / 生产环境 → GPT-4o / Claude 3.5 / DeepSeek API
中文场景优先       → Qwen / DeepSeek / GLM
代码生成          → Claude 3.5 / DeepSeek Coder
推理任务          → DeepSeek R1 / o1
```

## 5. 本地运行 LLM（Ollama）

```bash
# 安装 Ollama（https://ollama.ai）
# Windows/Mac 直接下载安装

# 下载并运行模型
ollama run qwen2.5:7b
ollama run llama3.1:8b
ollama run deepseek-r1:8b

# 列出已下载的模型
ollama list

# API 调用
curl http://localhost:11434/api/generate -d '{
  "model": "qwen2.5:7b",
  "prompt": "什么是机器学习？",
  "stream": false
}'
```

```python
# Python 调用 Ollama
import requests

response = requests.post('http://localhost:11434/api/generate', json={
    'model': 'qwen2.5:7b',
    'prompt': '用 Python 写一个快速排序',
    'stream': False
})
print(response.json()['response'])
```

## 6. 关键概念

| 概念 | 说明 |
|------|------|
| Temperature | 控制随机性，0=确定性，1=创意性 |
| Top-p | 核采样，控制候选 token 范围 |
| Max tokens | 最大输出长度 |
| Context window | 上下文窗口大小 |
| System prompt | 系统提示，定义模型角色和行为 |
| Few-shot | 在提示中给出几个示例 |
| Chain-of-Thought | 让模型逐步推理 |
