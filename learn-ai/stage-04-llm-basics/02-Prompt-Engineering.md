# Prompt Engineering

## 学习目标

- 掌握 Prompt 设计的核心原则和技巧
- 学会 Few-shot、CoT、结构化 Prompt 等高级方法
- 能为不同任务设计高效的 Prompt

## 1. Prompt 基础结构

```
一个好的 Prompt 包含：
┌──────────────┐
│  角色定义     │  你是一个...专家
│  任务描述     │  请你做...
│  上下文/输入   │  给定以下信息...
│  输出格式要求  │  请以 JSON 格式输出
│  约束条件     │  不要...，注意...
│  示例（可选）  │  例如：输入→输出
└──────────────┘
```

## 2. 核心原则

### 原则一：清晰具体

```
❌ 差的 Prompt：
"帮我写点关于 AI 的东西"

✅ 好的 Prompt：
"请写一篇 500 字的科普文章，面向非技术读者介绍大语言模型的工作原理。
要求：语言通俗易懂，使用 2-3 个生活化比喻，分 3 个小节。"
```

### 原则二：提供足够上下文

```
❌ 差的 Prompt：
"这段代码有什么问题？"

✅ 好的 Prompt：
"以下 Python 代码在处理大文件时报 MemoryError。
文件大小约 5GB，服务器内存 8GB。
请分析原因并给出内存优化方案。

```python
data = open('large_file.csv').read()
lines = data.split('\n')
...
```
"
```

### 原则三：指定输出格式

```
请分析以下用户评论的情感，以 JSON 格式输出：
{
  "sentiment": "positive/negative/neutral",
  "confidence": 0.0-1.0,
  "keywords": ["关键词1", "关键词2"]
}

评论：这款手机拍照效果很好，但电池续航太差了。
```

## 3. 高级 Prompt 技巧

### Few-shot（少样本示例）

```
请将以下英文翻译为中文，保持技术术语准确：

示例 1：
英文：The gradient descent algorithm minimizes the loss function.
中文：梯度下降算法最小化损失函数。

示例 2：
英文：Overfitting occurs when the model memorizes training data.
中文：当模型记住训练数据时，会发生过拟合。

请翻译：
英文：The transformer architecture uses self-attention mechanisms.
```

### Chain-of-Thought（思维链）

```
请逐步分析以下问题：

问题：一个班有 30 名学生，其中 60% 喜欢数学，40% 喜欢英语，
20% 两门都喜欢。问：至少喜欢一门课的学生有多少？

请按以下步骤思考：
1. 计算喜欢数学的人数
2. 计算喜欢英语的人数
3. 计算两门都喜欢的人数
4. 使用容斥原理计算结果
```

### 角色扮演

```
你是一位资深 Python 后端工程师，有 10 年经验，精通 Django 和 FastAPI。
你在做 Code Review 时：
- 关注性能和安全性
- 指出潜在的 bug
- 给出具体的改进建议和代码示例
- 用中文回复

请 review 以下代码：
[代码]
```

### 自一致性（Self-Consistency）

多次采样，取多数答案：

```
请独立思考 3 次，给出 3 个不同的解题思路，
最后综合判断最可能正确的答案。
```

### 思维树（Tree of Thought）

```
对于以下设计问题，请：
1. 提出 3 种不同的方案
2. 分析每种方案的优缺点
3. 打分（1-10）
4. 推荐最优方案并说明理由
```

## 4. 结构化 Prompt 模板

### 文本分类

```
你是一个文本分类专家。请将用户输入分类到以下类别之一：
- 技术问题
- 账号问题
- 投诉建议
- 咨询了解

输出格式：
类别：[类别名]
置信度：[高/中/低]
理由：[一句话说明]

用户输入：{user_input}
```

### 数据提取

```
从以下文本中提取结构化信息，以 JSON 格式输出：

提取字段：
- name: 姓名
- phone: 电话号码
- email: 邮箱地址
- company: 公司名称

如果某字段未找到，设为 null。

文本：{text}
```

### 代码生成

```
请用 {language} 实现以下功能：

功能描述：{description}

要求：
1. 包含类型注解
2. 包含文档字符串
3. 处理边界情况和异常
4. 附带 3 个单元测试

输入输出示例：
输入：{example_input}
输出：{example_output}
```

## 5. Prompt 优化策略

```
1. 迭代优化
   初始 Prompt → 测试 → 分析失败案例 → 调整 → 重测

2. 分解复杂任务
   大任务 → 拆成多步 → 每步一个 Prompt → 串联

3. 使用分隔符
   用 ```、---、### 等分隔不同部分

4. 指定"不要做什么"
   "不要编造信息，如果不确定请说'我不确定'"

5. 让模型自检
   "在给出最终答案前，请检查你的推理过程是否有逻辑错误"
```

## 6. 常见陷阱

| 陷阱 | 解决方案 |
|------|----------|
| 模型编造事实 | 要求引用来源，或说"不知道" |
| 输出格式不稳定 | 给出严格的格式示例 |
| 忽略部分指令 | 将关键指令放在 Prompt 末尾 |
| 回答过于冗长 | 明确字数/长度限制 |
| 上下文遗失 | 在 Prompt 中重复关键信息 |

## 练习

1. 为"文本情感分析"设计一个 Few-shot Prompt，测试 5 条评论
2. 用 CoT 方法让模型解决一个数学问题
3. 设计一个结构化 Prompt，从新闻文本中提取人物、地点、事件
4. 对比同一任务下 Zero-shot vs Few-shot vs CoT 的效果
