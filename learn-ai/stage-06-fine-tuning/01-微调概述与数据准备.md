# 微调概述与数据准备

## 学习目标

- 理解微调（Fine-tuning）的原理和适用场景
- 掌握训练数据的准备与格式化
- 了解全参微调 vs 参数高效微调的区别

## 1. 为什么需要微调

```
Prompt Engineering 的局限：
- 上下文窗口有限，不能塞入所有知识
- 风格/格式控制不够稳定
- 每次调用都重复传入指令，费用高
- 无法学习领域专业知识

微调解决：
- 将知识"烧录"到模型参数中
- 稳定的输出风格和格式
- 更低的推理成本（不需要长 prompt）
- 领域适配（医疗、法律、金融等）
```

## 2. 微调方式对比

| 方式 | 说明 | 显存需求 | 适用场景 |
|------|------|----------|----------|
| 全参微调 | 更新所有参数 | 极高（7B→~60GB） | 资源充足、大改动 |
| LoRA | 低秩适配器 | 低（7B→~16GB） | 最主流方案 |
| QLoRA | 量化 + LoRA | 更低（7B→~6GB） | 消费级显卡 |
| Prefix Tuning | 学习前缀向量 | 低 | 特定任务 |
| Adapter | 插入适配层 | 中 | 多任务切换 |

## 3. 数据准备

### 对话格式（最常用）

```json
[
  {
    "messages": [
      {"role": "system", "content": "你是一个专业的医疗咨询助手。"},
      {"role": "user", "content": "我最近经常头痛，可能是什么原因？"},
      {"role": "assistant", "content": "头痛可能由多种原因引起...（专业回答）"}
    ]
  },
  {
    "messages": [
      {"role": "system", "content": "你是一个专业的医疗咨询助手。"},
      {"role": "user", "content": "感冒了应该怎么办？"},
      {"role": "assistant", "content": "感冒的处理建议如下...（专业回答）"}
    ]
  }
]
```

### Alpaca 格式

```json
[
  {
    "instruction": "将以下文本翻译为英文",
    "input": "机器学习是人工智能的一个分支",
    "output": "Machine learning is a branch of artificial intelligence"
  }
]
```

## 4. 数据质量原则

```
1. 质量 > 数量
   - 1000 条高质量数据 > 10000 条低质量数据
   - 确保回答准确、专业、格式一致

2. 多样性
   - 覆盖不同类型的问题
   - 包含边界情况和特殊场景

3. 一致性
   - 同类问题的回答风格统一
   - System prompt 保持一致

4. 数据量参考
   - 风格微调：100-500 条
   - 知识注入：1000-5000 条
   - 复杂任务：5000-50000 条
```

## 5. 数据处理工具

```python
import json
import pandas as pd
from datasets import Dataset

# 从 CSV 转换为微调格式
df = pd.read_csv('qa_data.csv')  # columns: question, answer

training_data = []
for _, row in df.iterrows():
    training_data.append({
        "messages": [
            {"role": "system", "content": "你是一个专业的客服助手。"},
            {"role": "user", "content": row['question']},
            {"role": "assistant", "content": row['answer']},
        ]
    })

# 保存
with open('train.json', 'w', encoding='utf-8') as f:
    json.dump(training_data, f, ensure_ascii=False, indent=2)

# 数据验证
def validate_data(data):
    errors = []
    for i, item in enumerate(data):
        if 'messages' not in item:
            errors.append(f"第{i}条缺少 messages")
            continue
        for msg in item['messages']:
            if msg['role'] not in ['system', 'user', 'assistant']:
                errors.append(f"第{i}条角色错误: {msg['role']}")
            if not msg['content'].strip():
                errors.append(f"第{i}条内容为空")
    return errors

errors = validate_data(training_data)
if errors:
    print(f"发现 {len(errors)} 个错误:")
    for e in errors[:10]:
        print(f"  - {e}")
else:
    print(f"数据验证通过，共 {len(training_data)} 条")
```

## 6. 数据增强

```python
# 利用 LLM 生成训练数据
from openai import OpenAI
client = OpenAI()

def generate_qa_pair(topic: str, style: str) -> dict:
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": f"""生成一个关于{topic}的问答对。
问题应该是用户真实可能问的，回答要专业且{style}。
以 JSON 格式输出：{{"question": "...", "answer": "..."}}"""},
            {"role": "user", "content": "生成一个问答对"},
        ],
        response_format={"type": "json_object"},
    )
    return json.loads(response.choices[0].message.content)

# 批量生成
topics = ["Python 基础", "数据结构", "算法复杂度", "面向对象"]
for topic in topics:
    pair = generate_qa_pair(topic, "简洁易懂")
    print(pair)
```
