# 多模态融合处理 从零开始深入学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_multimodal_overview.py` | 多模态 AI 概述（融合原理/GPT-4o/Gemini） |
| 第2课 | `02_vision_language.py` | 视觉-语言模型（图文理解/VQA/文档分析） |
| 第3课 | `03_audio_language.py` | 音频-语言模型（语音对话/音频理解） |
| 第4课 | `04_multimodal_rag.py` | 多模态 RAG（图文混合检索与生成） |
| 第5课 | `05_multimodal_agent.py` | 多模态 Agent（视觉+语音+工具） |
| 第6课 | `06_video_and_realtime.py` | 视频理解与实时多模态交互 |
| 第7课 | `07_multimodal_project.py` | 完整项目：多模态智能助手 |

## 环境配置

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 前置课程

建议先完成以下课程再学习本课：
- learn-vision（视觉模型）
- learn-voice（语音处理）
- learn-image-gen（图像生成）

## 学习方式

按顺序学习，每个文件可直接运行：`python 01_multimodal_overview.py`
