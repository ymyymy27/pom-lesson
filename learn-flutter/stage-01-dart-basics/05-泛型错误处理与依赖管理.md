# 第 05 节：泛型、错误处理与依赖管理

## 本节目标

- 掌握泛型与约束，写出可复用的容器/函数
- 建立 Dart 的错误处理规范
- 会用 pub 管理依赖、运行测试与代码检查

## 一、泛型

```dart
// 泛型函数
T firstOrNull<T>(List<T> list) => list.isEmpty ? throw StateError('empty') : list.first;

// 泛型类
class Result<T> {
  final T data;
  final bool isSuccess;
  const Result(this.data, {required this.isSuccess});
}

// 类型约束：T 必须是 num 的子类型
num sum<T extends num>(List<T> values) =>
    values.fold<num>(0, (acc, v) => acc + v);

void main() {
  final r = Result<int>(42, isSuccess: true);
  final s = Result<String>('ok', isSuccess: true);
}
```

在 Flutter 里泛型最常出现在：`Future<T>`、`List<T>`、`Stream<T>`、`ValueNotifier<T>`、`Provider<T>`。

## 二、错误处理规范

自定义异常类型：

```dart
class ApiException implements Exception {
  final int statusCode;
  final String message;
  const ApiException(this.statusCode, this.message);

  @override
  String toString() => 'ApiException($statusCode): $message';
}

Future<String> fetchTask(String id) async {
  throw const ApiException(404, '任务不存在');
}

void main() async {
  try {
    await fetchTask('1');
  } on ApiException catch (e) {
    print('业务错误：${e.statusCode} ${e.message}');
  } catch (e) {
    print('兜底：$e');
  }
}
```

规范：

- 用 `on` 捕获特定类型，用 `catch` 捕获一切
- 网络层抛出**带上下文的自定义异常**（状态码 + 信息），别把原始异常直接抛给 UI
- 不要 `catch` 后吞掉错误，至少打日志

## 三、依赖管理：pub（对应 npm / pip）

`pubspec.yaml` 是 Dart/Flutter 的 `package.json` + `requirements.txt`：

```yaml
name: dart_basics
description: 练习用 Dart 项目
environment:
  sdk: ^3.0.0

dependencies:
  http: ^1.2.0          # 运行时依赖

dev_dependencies:
  test: ^1.25.0         # 仅开发/测试用
  lints: ^4.0.0
```

常用命令：

```powershell
dart pub get            # 安装依赖（对应 npm install）
dart pub add http       # 添加依赖并更新 pubspec
dart pub upgrade        # 升级
dart run                # 运行 bin/main.dart
dart test               # 运行测试
dart format .           # 格式化
dart analyze            # 静态检查
```

## 四、写第一个测试

```dart
// test/task_test.dart
import 'package:test/test.dart';

int priorityScore(int priority) => priority >= 8 ? 3 : 1;

void main() {
  group('priorityScore', () {
    test('高优先级返回 3', () {
      expect(priorityScore(9), 3);
    });

    test('普通优先级返回 1', () {
      expect(priorityScore(5), 1);
    });
  });
}
```

运行：`dart test`。

## 常见坑

- `pubspec.yaml` 缩进必须是两个空格，YAML 对缩进敏感
- 版本号 `^1.2.0` 表示"1.x 的最新版"，别手写成精确版本（除非有理由）
- 本地包路径依赖：`dependencies: my_lib: path: ../my_lib`
- `pub get` 后生成的 `pubspec.lock` 要提交（锁版本），Flutter 模板会自动处理
