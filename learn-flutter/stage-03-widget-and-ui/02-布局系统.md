# 第 02 节：布局系统

## 本节目标

- 理解 Flutter 的约束传递机制（父→子约束，子→父尺寸）
- 熟练使用 Row / Column / Stack / Expanded / Flexible
- 能徒手还原常见页面布局

## 一、核心心法：约束向下，尺寸向上

Flutter 布局分两步：

1. 父组件给子组件一个**约束**（最大/最小宽高）
2. 子组件在约束内决定自己的**尺寸**，返回给父组件

```text
父：你可以占 0~400 宽
子：我选 200 宽
父：好，按 200 摆放
```

这与 CSS 的"流式布局"不同，更像"层层传递的约束谈判"。遇到布局问题时先问：**是谁在限制我的尺寸？**

## 二、Row 与 Column

```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,  // 主轴（水平）
  crossAxisAlignment: CrossAxisAlignment.center,      // 交叉轴（垂直）
  children: [
    const Icon(Icons.star),
    const Text('任务标题'),
    IconButton(onPressed: () {}, icon: const Icon(Icons.more_vert)),
  ],
)

Column(
  mainAxisAlignment: MainAxisAlignment.center,
  children: [
    Text(priority.toString()),
    const SizedBox(height: 8),
    Text(title),
  ],
)
```

对照 CSS Flexbox：

| Flutter | CSS |
|---------|-----|
| `Row` | `display: flex; flex-direction: row` |
| `Column` | `flex-direction: column` |
| `mainAxisAlignment` | `justify-content` |
| `crossAxisAlignment` | `align-items` |
| `Expanded` | `flex: 1` |
| `SizedBox(width: 16)` | `gap` / margin |

## 三、Expanded 与 Flexible：分配剩余空间

```dart
Row(
  children: [
    Expanded(
      flex: 2,                    // 占剩余空间的比例 2
      child: Text(title, overflow: TextOverflow.ellipsis),
    ),
    Expanded(
      flex: 1,                    // 占 1
      child: Text(dueDate),
    ),
  ],
)
```

- `Expanded`：强制子组件填满分配空间
- `Flexible`：允许子组件**小于**分配空间（比如内容自适应宽度）
- 屏幕空间不够时，Expanded 会压缩内容，配合 `TextOverflow.ellipsis` 防溢出

## 四、Stack：层叠布局

```dart
Stack(
  clipBehavior: Clip.none,
  children: [
    Positioned.fill(child: Image.network(url, fit: BoxFit.cover)),
    Positioned(
      left: 12,
      bottom: 12,
      child: Text(title, style: const TextStyle(color: Colors.white)),
    ),
    // 没被 Positioned 包住的子组件按 alignment 对齐
  ],
)
```

对照 CSS `position: absolute`。`Positioned` 必须直接作为 Stack 的 child。

## 五、Container / SizedBox / Center / Padding

```dart
Container(
  width: double.infinity,          // 撑满
  padding: const EdgeInsets.all(16),
  margin: const EdgeInsets.symmetric(horizontal: 12),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(12),
    boxShadow: [BoxShadow(blurRadius: 4, color: Colors.black12)],
  ),
  child: const Text('卡片'),
)
```

常用尺寸控制：

```dart
const SizedBox(width: 8);           // 固定间隙
const SizedBox(height: 16);
Center(child: child);               // 居中
ConstrainedBox(
  constraints: const BoxConstraints(maxWidth: 400),
  child: child,
);
```

## 六、实战：还原一个任务卡片

```dart
Card(
  child: Padding(
    padding: const EdgeInsets.all(12),
    child: Row(
      children: [
        const CircleAvatar(child: Text('高')),
        const SizedBox(width: 12),
        Expanded(
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              const Text('写 Flutter 教程', style: TextStyle(fontWeight: FontWeight.bold)),
              const SizedBox(height: 4),
              Text('今天 18:00', style: TextStyle(color: Colors.grey[600])),
            ],
          ),
        ),
        const Icon(Icons.more_vert),
      ],
    ),
  ),
)
```

## 常见坑

- `RenderFlex overflowed`：内容超过主轴，用 Expanded / Flexible / 滚动
- `Unbounded constraints`：在 ListView 里放 Column 不包 Expanded，垂直方向无限高
- 误用 `SizedBox(width: double.infinity)` 在无界约束里会报错
