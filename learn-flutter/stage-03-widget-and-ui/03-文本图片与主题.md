# 第 03 节：文本、图片与 Material 3 主题

## 本节目标

- 掌握 Text 样式体系与中文字体注意事项
- 学会加载网络图片、本地图片并做缓存优化
- 用 Material 3 主题统一风格，支持明暗模式

## 一、Text 与 TextStyle

```dart
Text(
  '你好，Flutter',
  style: TextStyle(
    fontSize: 18,
    fontWeight: FontWeight.w600,
    color: Theme.of(context).colorScheme.onSurface,
    letterSpacing: 0.5,
    height: 1.4,                       // 行高倍数
  ),
  maxLines: 2,
  overflow: TextOverflow.ellipsis,     // 超长显示省略号
  textAlign: TextAlign.center,
)
```

不要直接写死颜色，尽量从主题取：

```dart
Theme.of(context).colorScheme.primary;        // 主色
Theme.of(context).colorScheme.onSurface;      // 主文字色
Theme.of(context).colorScheme.error;          // 错误色
Theme.of(context).textTheme.titleMedium;      // 预定义文字样式
```

## 二、图片加载

```dart
// 网络图片（自带内存缓存，但无磁盘缓存）
Image.network(
  url,
  fit: BoxFit.cover,
  cacheWidth: 400,               // 按需解码，省内存
  loadingBuilder: (context, child, progress) =>
      progress == null ? child : const Center(child: CircularProgressIndicator()),
  errorBuilder: (context, error, stack) => const Icon(Icons.broken_image),
)

// 本地资源（需在 pubspec.yaml 声明）
Image.asset('assets/images/logo.png')

// 磁盘缓存推荐：cached_network_image 包
// CachedNetworkImage(imageUrl: url, fit: BoxFit.cover)
```

图片三问：

1. 是网络图？→ `Image.network` 或 `cached_network_image`
2. 是本地打包资源？→ `Image.asset` + pubspec 声明
3. 内存会不会爆？→ 用 `cacheWidth` / `ResizeImage`

## 三、Material 3 主题

Material 3 是 2021 年推出的设计语言，Flutter 3.16+ 默认启用。用种子色自动生成整套配色：

```dart
MaterialApp(
  theme: ThemeData(
    useMaterial3: true,                     // 默认 true，可省略
    colorScheme: ColorScheme.fromSeed(
      seedColor: Colors.indigo,
      brightness: Brightness.light,
    ),
  ),
  darkTheme: ThemeData(
    colorScheme: ColorScheme.fromSeed(
      seedColor: Colors.indigo,
      brightness: Brightness.dark,
    ),
  ),
  themeMode: ThemeMode.system,              // 跟随系统亮暗
  home: const HomePage(),
)
```

主题化实践：

```dart
// 全局统一按钮/卡片风格
ThemeData(
  cardTheme: const CardThemeData(
    elevation: 0,
    shape: RoundedRectangleBorder(borderRadius: BorderRadius.all(Radius.circular(12))),
  ),
  inputDecorationTheme: const InputDecorationTheme(
    border: OutlineInputBorder(),
  ),
)
```

## 四、暗色模式适配

- 用 `colorScheme.*` 取色，不要用 `Colors.black` / `Colors.white` 写死
- 需要手动感知模式时：`Theme.of(context).brightness == Brightness.dark`
- 图片、自定义绘制也要提供暗色版本

## 常见坑

- 中文字体默认用系统字体，不要依赖特殊字体文件不声明
- `Image.network` 在 Web 端 CORS 限制会失败，用 errorBuilder 兜底
- `ColorScheme.fromSeed` 的 seed 色不会 1:1 作为主色，它是"种子"
