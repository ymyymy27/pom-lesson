# 第 04 节：列表与滚动

## 本节目标

- 使用 ListView / GridView 构建高效列表
- 用 CustomScrollView + Sliver 做复杂滚动页面
- 掌握懒加载与滚动监听

## 一、ListView：三种写法

```dart
// 1. 少量固定子项
ListView(
  children: [
    ListTile(title: Text('任务1')),
    ListTile(title: Text('任务2')),
  ],
)

// 2. 大量数据（必须用 builder 懒加载）
ListView.builder(
  itemCount: tasks.length,
  itemBuilder: (context, index) {
    final task = tasks[index];
    return TaskCard(key: ValueKey(task.id), task: task);
  },
)

// 3. 混合头部 + 列表
ListView.builder(
  itemCount: tasks.length + 1,
  itemBuilder: (context, index) {
    if (index == 0) return const HeaderWidget();
    return TaskCard(task: tasks[index - 1]);
  },
)
```

带分隔线：

```dart
ListView.separated(
  itemCount: tasks.length,
  separatorBuilder: (_, __) => const Divider(height: 1),
  itemBuilder: (context, index) => TaskCard(task: tasks[index]),
)
```

## 二、GridView

```dart
GridView.builder(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,        // 每行 2 个
    crossAxisSpacing: 12,
    mainAxisSpacing: 12,
    childAspectRatio: 3 / 4,  // 宽高比
  ),
  itemCount: projects.length,
  itemBuilder: (context, index) => ProjectCard(project: projects[index]),
)
```

需要自适应列数时用 `SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 200)`，类似 CSS `grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))`。

## 三、CustomScrollView + Sliver

复杂页面（吸顶标题 + 横向滚动 + 网格 + 列表）用 Sliver 组合：

```dart
CustomScrollView(
  slivers: [
    SliverAppBar(
      title: const Text('任务'),
      pinned: true,                        // 滚动时吸顶
      expandedHeight: 120,
      flexibleSpace: FlexibleSpaceBar(
        background: Image.network(bannerUrl, fit: BoxFit.cover),
      ),
    ),
    SliverToBoxAdapter(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Text('进行中的任务', style: Theme.of(context).textTheme.titleLarge),
      ),
    ),
    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, i) => TaskCard(task: tasks[i]),
        childCount: tasks.length,
      ),
    ),
    SliverPadding(
      padding: const EdgeInsets.all(16),
      sliver: SliverGrid(
        gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 2),
        delegate: SliverChildBuilderDelegate(
          (context, i) => ProjectCard(project: projects[i]),
          childCount: projects.length,
        ),
      ),
    ),
  ],
)
```

心法：**所有 Sliver 都负责"自己这一块怎么滚动"**，CustomScrollView 负责整体协调。

## 四、滚动监听与控制

```dart
final controller = ScrollController();

// 滚动到底部自动加载更多
controller.addListener(() {
  if (controller.position.pixels >= controller.position.maxScrollExtent - 200) {
    loadMore();
  }
});

// 回到顶部
controller.animateTo(
  0,
  duration: const Duration(milliseconds: 300),
  curve: Curves.easeOut,
);
```

记得在 `dispose()` 里释放控制器。

## 五、性能要点

- `ListView.builder` / `GridView.builder` 只构建可见项（懒加载）
- 不要用 `ListView(children: [...])` 渲染上千项
- 列表项尽量 `const`，避免无谓重建
- 图片按需解码（`cacheWidth`），避免大图卡顿
