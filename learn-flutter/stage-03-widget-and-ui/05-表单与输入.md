# 第 05 节：表单与输入

## 本节目标

- 掌握 TextField / TextFormField 与控制器

- 处理焦点、键盘类型、输入格式化

## 一、受控输入：TextEditingController

Flutter 没有"双向绑定"，用控制器手动管理（类似 React 受控组件）：

```dart
class _LoginFormState extends State<LoginForm> {
  final _emailCtrl = TextEditingController();
  final _passwordCtrl = TextEditingController();
  final _focusNode = FocusNode();

  @override
  void dispose() {
    _emailCtrl.dispose();       // 必须释放
    _passwordCtrl.dispose();
    _focusNode.dispose();
    super.dispose();
  }

  void _login() {
    final email = _emailCtrl.text;
    final password = _passwordCtrl.text;
    debugPrint('登录：$email / $password');
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        TextField(
          controller: _emailCtrl,
          keyboardType: TextInputType.emailAddress,
          decoration: const InputDecoration(
            labelText: '邮箱',
            prefixIcon: Icon(Icons.email),
            border: OutlineInputBorder(),
          ),
        ),
        TextField(
          controller: _passwordCtrl,
          focusNode: _focusNode,
          obscureText: true,
          onSubmitted: (_) => _login(),
          decoration: const InputDecoration(
            labelText: '密码',
            prefixIcon: Icon(Icons.lock),
          ),
        ),
        ElevatedButton(onPressed: _login, child: const Text('登录')),
      ],
    );
  }
}
```

要点：

- `controller.text` 读值，`controller.clear()` 清空
- 焦点管理：`FocusNode` + `FocusScope.of(context).requestFocus(...)` 切换焦点
- 键盘"下一步/完成"：`textInputAction: TextInputAction.next`

## 二、Form + TextFormField：统一校验

```dart
final _formKey = GlobalKey<FormState>();

Form(
  key: _formKey,
  autovalidateMode: AutovalidateMode.onUserInteraction,
  child: Column(
    children: [
      TextFormField(
        validator: (value) {
          if (value == null || value.isEmpty) return '请输入标题';
          if (value.length < 2) return '标题至少 2 个字';
          return null;                    // 返回 null 表示通过
        },
      ),
      TextFormField(
        keyboardType: TextInputType.number,
        inputFormatters: [FilteringTextInputFormatter.digitsOnly],
        validator: (v) => (int.tryParse(v ?? '') ?? 0) < 0 ? '优先级不能为负' : null,
      ),
      ElevatedButton(
        onPressed: () {
          if (_formKey.currentState!.validate()) {
            // 全部通过，提交
            _formKey.currentState!.save();
          }
        },
        child: const Text('保存'),
      ),
    ],
  ),
)
```

校验流程：

1. 每个 `TextFormField` 的 `validator` 返回错误文案或 `null`
2. 点提交时调 `_formKey.currentState!.validate()`
3. 全部通过后，`onSaved` 回调被逐个调用（或直接读控制器）

## 三、常用输入控制

```dart
TextField(
  keyboardType: TextInputType.multiline,
  maxLines: 4,                              // 多行
  maxLength: 200,                           // 自动带字数统计
  inputFormatters: [
    FilteringTextInputFormatter.allow(RegExp(r'[a-zA-Z0-9]')),
  ],
  onChanged: (v) => setState(() {}),        // 实时响应，比如实时校验
)
```

常用 `TextInputType`：

- `emailAddress`（邮箱键盘）
- `number` / `numberWithOptions(decimal: true)`
- `datetime`（日期键盘）
- `multiline`（多行）

## 四、键盘遮挡问题

表单在屏幕下半部时，键盘可能遮挡输入框。三种方案：

```dart
// 1. 整页可滚动（最常用）
SingleChildScrollView(
  padding: EdgeInsets.only(bottom: MediaQuery.of(context).viewInsets.bottom),
  child: form,
)

// 2. resizeToAvoidBottomInset（Scaffold 默认 true，自动抬起内容）
Scaffold(resizeToAvoidBottomInset: true, body: ...)

// 3. 键盘类型不带"完成"时，监听焦点滚到可见处
```

## 常见坑

- 忘记 `dispose()` 控制器 → 内存泄漏（热重载时尤其明显）
- `validator` 返回 `''` 空字符串会被当作错误；通过必须返回 `null`
- `obscureText` 切换可见时，光标会跳到最后，用 `TextSelection.collapsed(offset: text.length)` 修正
