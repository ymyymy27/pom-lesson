# 第 07 节：动画基础与组件封装

## 本节目标

- 用隐式动画（AnimatedXxx）快速实现动效
- 用 AnimationController 做显式动画
- 掌握组件封装的通用原则

## 一、隐式动画：声明"目标值"，自动过渡

```dart
// 状态变化时自动补间
AnimatedContainer(
  duration: const Duration(milliseconds: 300),
  curve: Curves.easeInOut,
  width: expanded ? 300 : 100,
  height: expanded ? 300 : 100,
  decoration: BoxDecoration(
    color: expanded ? Colors.indigo : Colors.orange,
    borderRadius: BorderRadius.circular(expanded ? 12 : 50),
  ),
)

// 常用隐式动画：
// AnimatedOpacity / AnimatedPadding / AnimatedSwitcher / AnimatedPositioned
```

对照 CSS `transition: all 0.3s`。

## 二、显式动画：完全掌控

```dart
class _FadeInState extends State<FadeIn> with SingleTickerProviderStateMixin {
  late final AnimationController _controller = AnimationController(
    vsync: this,                                    // 帧同步
    duration: const Duration(milliseconds: 800),
  );
  late final Animation<double> _opacity =
      CurvedAnimation(parent: _controller, curve: Curves.easeOut);

  @override
  void initState() {
    super.initState();
    _controller.forward();                          // 开始
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      child: child,                                  // 不依赖动画的部分传 child 复用
      builder: (context, child) => Opacity(
        opacity: _opacity.value,
        child: child,
      ),
    );
  }
}
```

要点：

- `SingleTickerProviderStateMixin` 提供 vsync（动画的"心跳"）
- `AnimationController` 必须 `dispose`
- `AnimatedBuilder` 只在动画变化时重建必要部分
- 多个动画可用 `AnimationController` 的 `TweenSequence` 或 `CurvedAnimation` 组合

## 四、组件封装原则

好的封装 = 明确的输入 + 明确的职责：

```dart
class PriorityBadge extends StatelessWidget {
  const PriorityBadge({super.key, required this.priority});
  final int priority;

  @override
  Widget build(BuildContext context) {
    final color = switch (priority) {
      >= 8 => Colors.red,
      >= 5 => Colors.orange,
      _ => Colors.grey,
    };
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
      decoration: BoxDecoration(
        color: color.withValues(alpha: 0.12),
        borderRadius: BorderRadius.circular(999),
      ),
      child: Text('P$priority', style: TextStyle(color: color, fontSize: 12)),
    );
  }
}
```

封装检查清单：

1. **输入最小**：只接收真正需要的参数，其余用 `required` 明确
2. **单一职责**：一个组件只做一件事
3. **对外可控**：把回调（`onTap`、`onChanged`）留给父组件
4. **const 优先**：参数都是 final，构造器加 `const`
5. **可测**：不依赖全局状态（后续测试阶段会强调）

## 常见坑

- 忘加 `SingleTickerProviderStateMixin` → `vsync` 报错
- `AnimatedBuilder` 的 builder 里创建新对象 → 无法复用，动画卡顿
- Hero 的 tag 重复 → 运行时异常
