# 第 05 阶段：路由与导航

## 学习目标

完成本阶段后，你将能够：
- 使用 Navigator 完成页面跳转、传参与回传
- 使用 go_router 声明式配置路由、嵌套路由与 ShellRoute
- 实现登录守卫与路由重定向
- 处理深链接与页面生命周期

## 前置要求

- 完成 Stage 04
- 熟悉 React Router（对照学习更高效）

## 课程内容

| 节 | 课时文件 | 内容 |
|----|-------------|------|
| 1 | `01-导航基础.md` | Navigator push/pop、命名路由、参数传递与回传 |
| 2 | `02-go_router.md` | 声明式路由、ShellRoute、redirect、错误页 |
| 3 | `03-深链接与页面生命周期.md` | 深链接、App 前后台切换、路由守卫与拦截 |

## 练习与产出

- `exercises/`：路由场景练习（传参、回传、404）
- `project/`：TaskFlow 底部导航 + 登录守卫 + 任务详情页跳转

## 预计时长：3 天

## 验收标准

- 未登录访问受保护页面时自动跳转登录页
- 通知点击后能直达对应任务详情页
- 能画出 TaskFlow 的路由树
