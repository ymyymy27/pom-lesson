# 第 02 节：偏好与安全存储

## 本节目标

- 用 shared_preferences 存轻量配置
- 用 flutter_secure_storage 存 Token 等敏感数据
- 建立存储分级规范

## 一、shared_preferences：轻量键值存储

类似 Web 的 localStorage。

```powershell
flutter pub add shared_preferences
```

```dart
class SettingsService {
  Future<String?> getLastProjectId() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString('last_project_id');
  }

  Future<void> setLastProjectId(String id) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('last_project_id', id);
  }
}
```

支持类型：`setString` / `setBool` / `setInt` / `setDouble` / `setStringList`。

注意：

- 写入是异步的，但**不保证立刻落盘**，不要存关键数据
- 不适合存大对象；复杂 JSON 建议用数据库
- 所有 key 建议集中定义，避免字符串散落

## 二、flutter_secure_storage：安全存储

Token、密码这类敏感数据要用系统级安全存储（Android Keystore / iOS Keychain / Windows DPAPI）。

```powershell
flutter pub add flutter_secure_storage
```

```dart
class TokenStorage {
  static const _storage = FlutterSecureStorage(
    aOptions: AndroidOptions(encryptedSharedPreferences: true),
  );

  Future<void> saveTokens({
    required String access,
    required String refresh,
  }) async {
    await _storage.write(key: 'access_token', value: access);
    await _storage.write(key: 'refresh_token', value: refresh);
  }

  Future<String?> getAccessToken() =>
      _storage.read(key: 'access_token');

  Future<void> clear() async {
    await _storage.deleteAll();
  }
}
```

## 三、存储分级规范

| 数据 | 存放位置 | 理由 |
|------|----------|------|
| 主题、上次打开的筛选条件 | shared_preferences | 非敏感、可丢失 |
| Access Token | flutter_secure_storage | 敏感、短期 |
| Refresh Token | flutter_secure_storage | 敏感、长期 |
| 任务列表/离线数据 | 数据库（下一节 drift） | 结构化、量大、需查询 |
| 附件图片 | 文件系统缓存 | 二进制大对象 |

## 四、与 Web 的对照

| Web | Flutter |
|-----|---------|
| localStorage | shared_preferences |
| sessionStorage | 内存变量（App 重启即失） |
| Cookie（HttpOnly） | flutter_secure_storage |
| IndexedDB | drift / sqflite |
| Cache Storage | cached_network_image / 文件缓存 |

## 动手练习

1. 记住用户上次选择的筛选条件，启动时自动恢复
2. 用 TokenStorage 实现登录后保存、登出清空
3. 在设置页做"清除缓存"按钮，清空 preferences（保留 token）

## 验收标准

- 能说清三种存储的适用场景
- Token 不会出现在 shared_preferences 里
- 重启 App 后主题/筛选条件能恢复
