# 第 04 节：文件与缓存

## 本节目标

- 找到正确的文件目录（path_provider）
- 完成文件读写与附件管理
- 用 cached_network_image 做图片磁盘缓存

## 一、path_provider：找目录

```powershell
flutter pub add path_provider
```

```dart
final docs = await getApplicationDocumentsDirectory();  // 应用私有文档
final cache = await getTemporaryDirectory();            // 临时目录，可清
final downloads = await getDownloadsDirectory();        // 下载目录（桌面端）
```

不要硬编码路径（`C:\Users\...`），不同平台目录不同，用 API 获取。

## 二、文件读写

```dart
import 'dart:io';

class AttachmentStorage {
  Future<File> saveAttachment({required String name, required List<int> bytes}) async {
    final dir = await getApplicationDocumentsDirectory();
    final file = File('${dir.path}/attachments/$name');
    await file.create(recursive: true);
    await file.writeAsBytes(bytes);
    return file;
  }

  Future<File> downloadToFile(Uri url, String fileName) async {
    final dir = await getTemporaryDirectory();
    final file = File('${dir.path}/$fileName');
    final response = await HttpClient().getUrl(url);
    final request = await response.close();
    await request.pipe(file.openWrite());
    return file;
  }
}
```

## 三、图片缓存：cached_network_image

`Image.network` 只有内存缓存；`cached_network_image` 增加磁盘缓存：

```powershell
flutter pub add cached_network_image
```

```dart
CachedNetworkImage(
  imageUrl: avatarUrl,
  fit: BoxFit.cover,
  placeholder: (_, __) => const Center(child: CircularProgressIndicator()),
  errorWidget: (_, __, ___) => const Icon(Icons.person),
  memCacheWidth: 200,          // 解码尺寸上限，省内存
)
```

## 四、缓存策略

```text
图片：cached_network_image（内存 + 磁盘）
附件：手动下载到 documents / temporary
数据：drift（离线数据库）
登录态：secure_storage
```

缓存清理：

```dart
Future<void> clearImageCache() async {
  final cache = await getTemporaryDirectory();
  final dir = Directory(cache.path);
  if (await dir.exists()) {
    await dir.delete(recursive: true);
  }
}
```
