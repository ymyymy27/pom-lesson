# 第 04 节：上传下载与进度

## 本节目标

- 用 FormData 上传文件（含图片压缩）
- 展示上传/下载进度
- 支持取消

## 一、文件上传

```dart
Future<Task> uploadAttachment({
  required int taskId,
  required File file,
  void Function(double progress)? onProgress,
}) async {
  final formData = FormData.fromMap({
    'task': taskId,
    'file': await MultipartFile.fromFile(
      file.path,
      filename: file.uri.pathSegments.last,
    ),
  });

  final resp = await dio.post(
    '/api/tasks/$taskId/attachments/',
    data: formData,
    onSendProgress: (sent, total) {
      if (total > 0) onProgress?.call(sent / total);
    },
  );
  return Task.fromJson(resp.data as Map<String, dynamic>);
}
```

## 三、下载与进度

```dart
Future<File> downloadFile(
  String url, {
  required String savePath,
  void Function(double progress)? onProgress,
  CancelToken? cancelToken,
}) async {
  final resp = await dio.download(
    url,
    savePath,
    cancelToken: cancelToken,
    onReceiveProgress: (received, total) {
      if (total > 0) onProgress?.call(received / total);
    },
  );
  if (resp.statusCode != 200) {
    throw ApiException(statusCode: resp.statusCode, message: '下载失败');
  }
  return File(savePath);
}
```

## 四、进度 UI

```dart
class UploadProgress extends StatelessWidget {
  const UploadProgress({super.key, required this.progress, this.cancel});
  final double progress;          // 0.0 ~ 1.0
  final VoidCallback? cancel;

  @override
  Widget build(BuildContext context) {
    return Row(
      children: [
        Expanded(
          child: LinearProgressIndicator(value: progress),
        ),
        const SizedBox(width: 8),
        Text('${(progress * 100).toStringAsFixed(0)}%'),
        if (cancel != null)
          IconButton(onPressed: cancel, icon: const Icon(Icons.close)),
      ],
    );
  }
}
```

class AttachmentUploadNotifier extends Notifier<Map<int, double>> {

    await api.uploadAttachment(
      taskId: taskId,

      onProgress: (p) => state = {...state, taskId: p},

    state = {...state}..remove(taskId);   // 完成后移除
  }
