# 第 05 节：实时通知与离线策略

## 本节目标

- 用 WebSocket 接收实时事件
- 实现乐观更新与离线队列
- 打通"本地数据库 + 远程 API"的同步

## 一、WebSocket 接入

```powershell
flutter pub add web_socket_channel
```

```dart
class WsService {
  WsService(this.token);
  final String token;
  WebSocketChannel? _channel;
  final _controller = StreamController<WsEvent>.broadcast();
  Stream<WsEvent> get events => _controller.stream;

  void connect() {
    _channel = WebSocketChannel.connect(
      Uri.parse('wss://api.taskflow.example.com/ws/tasks/?token=$token'),
    );
    _channel!.stream.listen(
      (message) {
        final json = jsonDecode(message as String) as Map<String, dynamic>;
        _controller.add(WsEvent.fromJson(json));
      },
      onDone: () => _controller.close(),
    );
  }

  void disconnect() {
    _channel?.sink.close();
    _channel = null;
  }
}
```

接入 Riverpod：

```dart
final wsEventsProvider = StreamProvider<WsEvent>((ref) {
  final ws = ref.watch(wsServiceProvider);
  ws.connect();
  ref.onDispose(ws.disconnect);     // Provider 销毁时断开
  return ws.events;
});
```

## 二、事件驱动刷新

后端推送 `task.updated` 事件后，不要整页刷新，而是**更新本地数据库**：

```dart
ref.listen(wsEventsProvider, (prev, next) {
  final event = next.value;
  if (event == null) return;
  switch (event.type) {
    case 'task.created':
      dao.upsert(event.task);
    case 'task.updated':
      dao.upsert(event.task);
    case 'task.deleted':
      dao.deleteById(event.taskId);
  }
});
```

数据库变化 → StreamProvider 自动推送 → UI 自动更新。这就是"本地单一数据源"的好处。

## 三、乐观更新

用户操作先改本地 UI，失败再回滚：

```dart
Future<void> toggleDone(Task task) async {
  // 1. 立即更新 UI（乐观）
  await dao.upsert(task.copyWith(done: !task.done));

  try {
    // 2. 同步服务器
    await repo.updateTask(task.id, done: !task.done);
  } catch (e) {
    // 3. 失败回滚 + 提示
    await dao.upsert(task);
    rethrow;
  }
}
```

## 四、离线队列

离线时的写操作先进本地队列，恢复网络后按序重放：

```dart
class PendingSync extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get action => text()();          // create / update / delete
  TextColumn get payload => text()();         // JSON
  DateTimeColumn get createdAt => dateTime().withDefault(currentDateAndTime)();
}
```

```dart
Future<void> syncPending() async {
  final pending = await dao.getPending();
  for (final item in pending) {
    try {
      await applyToServer(item);
      await dao.deletePending(item.id);
    } catch (e) {
      break;    // 失败就停，等待下次机会（避免顺序错乱）
    }
  }
}

// 网络恢复时触发
final hasConnectionProvider = StreamProvider<bool>((ref) {
  return Connectivity().onConnectivityChanged.map(
    (results) => results.any((r) => r != ConnectivityResult.none),
  );
});

ref.listen(hasConnectionProvider, (prev, next) {
  if (next.value == true && prev?.value != true) {
    syncPending();
    ref.invalidate(tasksProvider);    // 全量刷新
  }
});
```

## 五、同步策略总结

```text
读：本地数据库优先（秒开）→ 后台拉远程 → 写库 → 自动刷新
写：乐观更新本地 → 入队 → 在线立即同步 / 离线等网络恢复
实时：WebSocket 推送 → 更新本地库 → UI 自动刷新
冲突：简单场景"服务器为准"；复杂场景用 updated_at 时间戳比较
```
