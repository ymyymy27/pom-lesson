# 第 01 节：权限与隐私

## 本节目标

- 理解移动端权限模型与 Web 的差异
- 学会声明权限并动态申请
- 建立隐私合规意识

## 一、移动权限模型

Web 权限（定位、通知）是**页面级、可撤销**；移动端是**应用级 + 系统级弹窗**，且 Android/iOS 规则不同：

| 维度 | Android | iOS |
|------|---------|-----|
| 声明 | AndroidManifest.xml | Info.plist |
| 运行时申请 | 需要 | 需要 |
| 敏感权限 | 分组授权 | 严格说明文案（必须写用途） |
| 撤销 | 设置里可关 | 设置里可关 |

## 二、声明权限

Android `android/app/src/main/AndroidManifest.xml`：

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

iOS `ios/Runner/Info.plist`（必须写用途说明，否则审核被拒）：

```xml
<key>NSCameraUsageDescription</key>
<string>用于拍摄任务附件</string>
<key>NSLocationWhenInUseUsageDescription</key>
<string>用于任务地点定位</string>
```

## 三、运行时申请：permission_handler

```powershell
flutter pub add permission_handler
```

```dart
Future<bool> requestCamera() async {
  final status = await Permission.camera.request();
  return switch (status) {
    PermissionStatus.granted => true,
    PermissionStatus.permanentlyDenied => false,
    _ => false,
  };
}
```

处理"永久拒绝"：引导用户去系统设置打开：

```dart
if (status == PermissionStatus.permanentlyDenied) {
  openAppSettings();        // 跳到系统设置页
}
```

## 四、权限申请流程规范

```text
用户点击"拍照"
  ↓
1. 检查状态（Permission.camera.status）
2. 已授权 → 直接打开相机
3. 未决定 → 弹窗申请（先解释为什么需要，再 request）
4. 被拒 → 提示原因 + 引导设置
```

不要在页面加载时一口气申请所有权限（审核差评 + 用户反感）。**用到的时刻才申请**。

## 五、隐私合规清单

- 只申请业务必需的权限
- 申请前说明用途（应用内弹窗）
- 权限拒绝时功能降级（不崩溃、可手动选择文件替代拍照）
- 收集的数据（定位等）要在隐私政策里写明
- 测试账号与生产数据隔离
