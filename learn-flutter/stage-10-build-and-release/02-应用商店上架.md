# 第 02 节：应用商店上架

## 本节目标

- 了解 Google Play / 国内商店 / iOS 的上架流程
- 准备上架材料（截图、隐私政策、数据安全声明）
- 制定发布前检查清单

## 一、上架渠道概览

| 渠道 | 格式 | 账号成本 | 特点 |
|------|------|----------|------|
| Google Play | AAB | $25 一次性 | 全球主流，审核 1–3 天 |
| 国内应用商店 | APK | 实名/软著 | 华为/小米/OPPO/vivo 等逐个提交，需备案 |
| App Store | IPA | $99/年 | 需 macOS + 开发者账号 |
| 企业分发/自建 | APK/IPA | 视渠道 | 测试分发、内网使用 |

## 二、上架材料清单

```markdown
- 应用名称 + 简介（中英文）
- 图标（多尺寸）+ 横幅/截屏（手机、平板）
- 隐私政策 URL（收集哪些数据、如何删除）
- 数据安全声明（是否收集定位/通讯录/广告标识）
- 内容分级问卷（暴力/成人/赌博等）
- 联系人邮箱
```

## 三、Android 上架流程（Google Play）

1. 注册开发者账号（$25，需真实信息）
2. 上传 AAB（`flutter build appbundle --release`）
3. 填写商店信息 + 隐私政策 + 数据安全
4. 内部测试 → 封闭测试 → 生产发布（建议渐进放量）

国内商店额外：

- App 备案（工信部，服务器在国内必须）
- 软件著作权（部分商店要求）
- 各商店自己的审核规范（推送权限、隐私合规、开机自启等）

## 四、iOS 上架（条件说明）

Windows 上无法构建 iOS 应用（Xcode 仅 macOS）。可选方案：

- 购买/借用 Mac 或 Mac mini（构建机）
- 使用云端 Mac 构建（Codemagic、MacStadium）
- 先学 Android 上架，iOS 留到有 Mac 环境

流程：开发者账号 → 证书/描述文件 → TestFlight 内测 → App Store Connect 提交 → 审核（1–7 天）。

## 五、发布前检查清单

```markdown
- [ ] release 构建通过，真机冒烟测试
- [ ] 隐私政策上线（HTTPS）
- [ ] 数据安全声明与代码一致
- [ ] 权限全部有用途说明
- [ ] 深链接/推送配置正确
- [ ] 版本号与构建号正确
- [ ] 崩溃监控已接入（下节）
- [ ] 测试账号数据已清理
- [ ] 图标/截图符合渠道规格
```
