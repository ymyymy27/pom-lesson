# 快速开始

欢迎学习 **前后端分离全栈 Web 应用** 课程。本课程以 Django + DRF + React + TypeScript 为核心，通过贯穿项目 **TaskFlow（任务协作平台）** 带你从零构建生产级全栈应用。

## 前置要求

- 基本的计算机操作与命令行使用能力
- 无需 prior Web 开发经验（课程从 Python 基础讲起）

## 学习步骤

1. 阅读 [课程总览](README.md)，了解 14 个阶段与技术栈
2. 从 **[第 01 阶段：Python 基础](stage-01-python-basics/)** 开始按顺序学习
3. 每阶段阅读 `README.md` → 按课时文档学习 → 在 `exercises/` 与 `code/` 中完成练习
4. 阶段 03 起，在 [project/taskflow/](project/taskflow/) 中逐步构建贯穿项目

## 推荐环境

- Python 3.11+
- Node.js 20+（前端阶段需要）
- PostgreSQL 15+、Redis 7+（数据库阶段起需要）
- Docker Desktop（容器化阶段起需要）

## 预计时长

约 **80 天（12 周）**，可按自身节奏调整。
