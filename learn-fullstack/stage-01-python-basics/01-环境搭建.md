## 一、安装 Python

### 1.1 下载与安装

- 官网下载：https://www.python.org/downloads/
- Windows 安装时 **务必勾选** "Add Python to PATH"
- 推荐版本：Python 3.11+

### 1.2 验证安装

```bash
python --version    # 查看 Python 版本
pip --version       # 查看 pip 版本
```

### 1.3 Python 解释器是什么？

Python 是解释型语言，代码通过 **解释器** 逐行执行，不需要像 C/Java 那样先编译。

```
你写的代码(.py) → Python 解释器 → 逐行翻译执行 → 输出结果
```

## 三、虚拟环境

### 3.1 为什么需要虚拟环境？

不同项目可能依赖不同版本的库。虚拟环境为每个项目创建 **独立的 Python 环境**，避免版本冲突。

```
全局 Python 环境
├── 项目A 的虚拟环境 → Django 4.2 + requests 2.28
├── 项目B 的虚拟环境 → Django 5.0 + requests 2.31
└── 项目C 的虚拟环境 → Flask 3.0 + httpx 0.25
```

### 3.2 使用 venv（内置）

```bash
# 创建虚拟环境
python -m venv .venv

# 激活（Windows PowerShell）
.venv\Scripts\Activate.ps1

# 激活（Mac/Linux）
source .venv/bin/activate

# 看到命令行前缀变成 (.venv) 表示激活成功

# 退出虚拟环境
deactivate
```

### 3.3 使用 Poetry（推荐，后续项目使用）

Poetry 是现代 Python 依赖管理工具，类似于前端的 npm/yarn。

```bash
# 安装 Poetry
pip install poetry

# 创建新项目
poetry new my-project

# 在已有项目中初始化
poetry init

# 安装依赖
poetry add django
poetry add --group dev pytest black ruff

# 激活虚拟环境
poetry shell

# 运行命令
poetry run python manage.py runserver
```

Poetry 会生成两个文件：
- `pyproject.toml` — 项目配置 & 依赖声明（类似 package.json）
- `poetry.lock` — 锁定的依赖版本（类似 package-lock.json）

## 四、包管理

### 4.1 pip 基础命令

```bash
pip install requests          # 安装包
pip install requests==2.31.0  # 安装指定版本
pip uninstall requests        # 卸载包
pip list                      # 查看已安装的包
pip freeze > requirements.txt # 导出依赖列表
pip install -r requirements.txt # 从文件安装依赖
```

### 4.2 requirements.txt 示例

```
django==5.0
djangorestframework==3.14.0
psycopg2-binary==2.9.9
redis==5.0.1
celery==5.3.4
```

### 4.3 pip vs Poetry 对比

| 功能 | pip | Poetry |
|------|-----|--------|
| 安装包 | `pip install django` | `poetry add django` |
| 开发依赖 | 手动分组 | `poetry add --group dev pytest` |
| 锁定版本 | `pip freeze` 手动导出 | 自动生成 `poetry.lock` |
| 虚拟环境 | 需要手动创建 | 自动管理 |
| 依赖解析 | 基础 | 智能解析冲突 |

## 五、第一个 Python 程序

创建文件 `hello.py`：

```python
def greet(name: str) -> str:
    """向指定的人打招呼"""
    return f"你好，{name}！欢迎学习全栈开发。"

if __name__ == "__main__":
    message = greet("同学")
    print(message)
```

运行：

```bash
python hello.py
# 输出：你好，同学！欢迎学习全栈开发。
```

### 关键概念解析

- `def` — 定义函数
- `name: str` — 类型提示，表示参数是字符串
- `-> str` — 返回值类型提示
- `f"..."` — f-string 格式化字符串
- `if __name__ == "__main__"` — 只有直接运行此文件时才执行，被导入时不执行
