# 第 04 节：面向对象编程

## 一、什么是面向对象？

面向对象编程（OOP）是一种 **用"对象"来组织代码** 的编程方式。对象把 **数据（属性）** 和 **操作数据的方法（函数）** 封装在一起。

```
现实世界          →       代码世界
─────────────────────────────────
一辆车             →       Car 对象
  颜色、品牌       →         属性 (color, brand)
  启动、刹车       →         方法 (start(), brake())
```

### 为什么需要 OOP？

- **封装**：把相关数据和方法放在一起，结构清晰
- **复用**：通过继承共享代码，减少重复
- **扩展**：通过多态灵活替换行为

## 二、类与对象

### 2.1 定义类

```python
class User:
    """用户类"""
    
    # 类属性 — 所有实例共享
    platform = "TaskFlow"
    
    # 构造方法 — 创建对象时自动调用
    def __init__(self, name: str, email: str, age: int = 0):
        # 实例属性 — 每个对象独有
        self.name = name
        self.email = email
        self.age = age
        self.is_active = True
    
    # 实例方法 — 操作实例数据
    def greet(self) -> str:
        return f"你好，我是{self.name}，邮箱是{self.email}"
    
    def deactivate(self):
        self.is_active = False
        print(f"用户 {self.name} 已停用")
```

### 2.2 创建和使用对象

```python
# 创建对象（实例化）
user1 = User("张三", "zhangsan@example.com", 25)
user2 = User("李四", "lisi@example.com")

# 访问属性
print(user1.name)       # "张三"
print(user1.age)        # 25
print(user2.age)        # 0（使用默认值）

# 调用方法
print(user1.greet())    # "你好，我是张三，邮箱是zhangsan@example.com"
user1.deactivate()      # "用户 张三 已停用"

# 访问类属性
print(User.platform)    # "TaskFlow"
print(user1.platform)   # "TaskFlow"（实例也可以访问类属性）
```

### 2.3 self 是什么？

`self` 代表 **当前对象本身**。调用 `user1.greet()` 时，Python 自动把 `user1` 传给 `self`。

```python
# 这两种写法等价
user1.greet()           # Python 自动传 self=user1
User.greet(user1)       # 手动传入（不推荐，但有助理解）
```

## 三、继承

### 3.1 基本继承

```python
# 父类（基类）
class Animal:
    def __init__(self, name: str, sound: str):
        self.name = name
        self.sound = sound
    
    def speak(self) -> str:
        return f"{self.name}说：{self.sound}"

# 子类 — 继承 Animal 的所有属性和方法
class Dog(Animal):
    def __init__(self, name: str):
        super().__init__(name, "汪汪")  # 调用父类的 __init__
        self.tricks = []
    
    def learn_trick(self, trick: str):
        self.tricks.append(trick)

class Cat(Animal):
    def __init__(self, name: str):
        super().__init__(name, "喵喵")

# 使用
dog = Dog("旺财")
print(dog.speak())         # "旺财说：汪汪"（继承了父类方法）
dog.learn_trick("握手")     # 子类独有的方法

cat = Cat("咪咪")
print(cat.speak())         # "咪咪说：喵喵"
```

### 3.2 方法重写（Override）

子类可以重写父类的方法，改变行为。

```python
class Dog(Animal):
    def __init__(self, name: str):
        super().__init__(name, "汪汪")
    
    # 重写父类方法
    def speak(self) -> str:
        return f"🐕 {self.name}兴奋地叫：{self.sound}！{self.sound}！"

dog = Dog("旺财")
print(dog.speak())  # "🐕 旺财兴奋地叫：汪汪！汪汪！"
```

### 3.3 isinstance 和 issubclass

```python
dog = Dog("旺财")

print(isinstance(dog, Dog))     # True — dog 是 Dog 的实例
print(isinstance(dog, Animal))  # True — dog 也是 Animal 的实例

print(issubclass(Dog, Animal))  # True — Dog 是 Animal 的子类
print(issubclass(Animal, Dog))  # False
```

## 四、封装与访问控制

Python 没有 Java 那样的 `private`/`public` 关键字，通过 **命名约定** 实现访问控制。

```python
class BankAccount:
    def __init__(self, owner: str, balance: float = 0):
        self.owner = owner          # 公开属性
        self._bank_name = "中国银行"  # 受保护属性（约定：不建议外部直接访问）
        self.__balance = balance     # 私有属性（名称修饰，外部无法直接访问）
    
    # 通过公开方法操作私有属性
    def deposit(self, amount: float):
        if amount <= 0:
            raise ValueError("存款金额必须大于零")
        self.__balance += amount
    
    def withdraw(self, amount: float):
        if amount > self.__balance:
            raise ValueError("余额不足")
        self.__balance -= amount
    
    def get_balance(self) -> float:
        return self.__balance

account = BankAccount("张三", 1000)
account.deposit(500)
print(account.get_balance())    # 1500

# account.__balance              # AttributeError! 无法直接访问
# account._BankAccount__balance  # 技术上可以（名称修饰），但不要这么做
```

### property 装饰器（更 Pythonic 的方式）

```python
class User:
    def __init__(self, first_name: str, last_name: str, age: int):
        self.first_name = first_name
        self.last_name = last_name
        self._age = age
    
    @property
    def full_name(self) -> str:
        """只读属性 — 像访问属性一样调用"""
        return f"{self.first_name} {self.last_name}"
    
    @property
    def age(self) -> int:
        return self._age
    
    @age.setter
    def age(self, value: int):
        """设置 age 时自动校验"""
        if value < 0:
            raise ValueError("年龄不能为负数")
        self._age = value

user = User("三", "张", 25)
print(user.full_name)   # "三 张"（像属性一样访问，不需要加括号）

user.age = 30           # 触发 setter
print(user.age)         # 30

user.age = -1           # ValueError: 年龄不能为负数
```

## 五、魔术方法（Dunder Methods）

以双下划线开头和结尾的特殊方法，让自定义类支持 Python 内置操作。

```python
class Vector:
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y
    
    # 字符串表示（给开发者看，用于调试）
    def __repr__(self) -> str:
        return f"Vector({self.x}, {self.y})"
    
    # 字符串表示（给用户看，print() 时调用）
    def __str__(self) -> str:
        return f"({self.x}, {self.y})"
    
    # 加法运算符 +
    def __add__(self, other: "Vector") -> "Vector":
        return Vector(self.x + other.x, self.y + other.y)
    
    # 相等比较 ==
    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Vector):
            return False
        return self.x == other.x and self.y == other.y
    
    # 长度 len()
    def __len__(self) -> int:
        return 2
    
    # 支持下标访问 v[0], v[1]
    def __getitem__(self, index: int) -> float:
        if index == 0:
            return self.x
        elif index == 1:
            return self.y
        raise IndexError("索引超出范围")

v1 = Vector(1, 2)
v2 = Vector(3, 4)

print(v1)          # (1, 2)        → __str__
print(repr(v1))    # Vector(1, 2)  → __repr__
print(v1 + v2)     # (4, 6)        → __add__
print(v1 == v2)    # False          → __eq__
print(v1[0])       # 1              → __getitem__
```

### 常用魔术方法速查

| 方法 | 触发方式 | 用途 |
|------|---------|------|
| `__init__` | `MyClass()` | 构造函数 |
| `__str__` | `print(obj)`, `str(obj)` | 用户友好的字符串 |
| `__repr__` | `repr(obj)`, 交互式终端 | 开发者调试字符串 |
| `__eq__` | `obj1 == obj2` | 相等比较 |
| `__lt__` | `obj1 < obj2` | 小于比较 |
| `__len__` | `len(obj)` | 长度 |
| `__getitem__` | `obj[key]` | 下标访问 |
| `__setitem__` | `obj[key] = value` | 下标赋值 |
| `__contains__` | `item in obj` | 成员检查 |
| `__iter__` | `for x in obj` | 迭代 |
| `__call__` | `obj()` | 像函数一样调用对象 |
| `__enter__/__exit__` | `with obj:` | 上下文管理器 |

## 六、类方法与静态方法

```python
class User:
    _user_count = 0
    
    def __init__(self, name: str):
        self.name = name
        User._user_count += 1
    
    # 实例方法 — 第一个参数是 self（实例）
    def greet(self):
        return f"你好，{self.name}"
    
    # 类方法 — 第一个参数是 cls（类本身），用于操作类属性或作为工厂方法
    @classmethod
    def get_user_count(cls) -> int:
        return cls._user_count
    
    @classmethod
    def from_dict(cls, data: dict) -> "User":
        """工厂方法：从字典创建 User"""
        return cls(name=data["name"])
    
    # 静态方法 — 不接收 self 或 cls，跟类相关但不操作实例/类属性
    @staticmethod
    def validate_email(email: str) -> bool:
        return "@" in email and "." in email

# 使用
user = User("张三")
print(User.get_user_count())       # 1（类方法通过类调用）

user_data = {"name": "李四"}
user2 = User.from_dict(user_data)  # 工厂方法
print(User.get_user_count())       # 2

print(User.validate_email("test@example.com"))  # True（静态方法）
```

## 七、数据类 dataclass（Python 3.7+）

自动生成 `__init__`、`__repr__`、`__eq__` 等方法，减少样板代码。

```python
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class Task:
    title: str
    description: str
    assignee: str
    priority: int = 0                                      # 默认值
    tags: list[str] = field(default_factory=list)          # 可变默认值
    created_at: datetime = field(default_factory=datetime.now)
    
    def is_urgent(self) -> bool:
        return self.priority >= 8

# 自动生成了 __init__，不用手写
task = Task(
    title="修复登录Bug",
    description="用户无法通过邮箱登录",
    assignee="张三",
    priority=9,
    tags=["bug", "urgent"],
)

print(task)
# Task(title='修复登录Bug', description='...', assignee='张三', priority=9, ...)

print(task.is_urgent())  # True

# 自动生成了 __eq__
task2 = Task("修复登录Bug", "用户无法通过邮箱登录", "张三", 9, ["bug", "urgent"])
print(task == task2)  # True（比较所有字段）
```

> 💡 **Django 中的 Model、DRF 中的 Serializer 都使用了类似的声明式风格**，理解 `dataclass` 有助于后续学习。
