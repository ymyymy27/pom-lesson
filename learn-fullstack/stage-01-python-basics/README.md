# 第 01 阶段：Python 基础 & 环境搭建

## 学习目标

完成本阶段后，你将能够：
- 搭建 Python 开发环境并管理虚拟环境
- 熟练使用 Python 核心语法（数据类型、控制流、函数、类）
- 理解装饰器、生成器、上下文管理器等进阶特性
- 使用类型提示编写规范代码
- 使用 pip/Poetry 管理依赖

## 阶段实战

编写一个命令行 TODO 应用：
- 增删改查任务
- 任务状态管理（待办/进行中/已完成）
