# 第 02 阶段：数据库基础（SQL + PostgreSQL + Redis）

## 学习目标

完成本阶段后，你将能够：
- 理解关系型数据库核心概念（表、行、列、主键、外键）
- 熟练编写 SQL 增删改查语句
- 安装并使用 PostgreSQL
- 理解索引、事务、范式等进阶概念
- 了解 Redis 基础操作和使用场景

## 课程内容

| 1 | `01-数据库概述与SQL基础.md` | 数据库概念、SQL 语法、CRUD |

## 阶段实战

为 TaskFlow 项目设计数据库：
- 设计用户、项目、任务、评论等表结构
- 编写完整的建表 SQL
- 用 SQL 实现常见业务查询
