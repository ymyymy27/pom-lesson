# 第 03 阶段：Django 核心

## 学习目标

完成本阶段后，你将能够：
- 理解 Django MTV 架构和请求生命周期
- 创建 Django 项目和应用
- 配置 URL 路由系统
- 编写视图函数和类视图
- 使用 Django ORM 进行数据库操作
- 使用 Django Admin 后台管理数据
- 理解中间件和信号机制

## 课程内容

| 节 | 文件 | 内容 |

| 1 | `01-Django入门与项目结构.md` | MTV 架构、创建项目、settings 配置 |
| 2 | `02-URL路由系统.md` | URL 配置、路径参数、命名路由、include |

| 5 | `05-ORM查询API.md` | QuerySet、过滤、聚合、Q/F 对象、优化 |
| 6 | `06-Django-Admin.md` | Admin 配置、自定义显示、过滤、Action |
| 7 | `07-中间件与信号.md` | 中间件原理、自定义中间件、Django 信号 |

## 阶段实战

搭建 TaskFlow 后端项目骨架：
- 创建 Django 项目和 users / projects / tasks 应用
- 定义完整的数据模型
- 配置 Admin 后台
- 通过 Admin 管理数据
