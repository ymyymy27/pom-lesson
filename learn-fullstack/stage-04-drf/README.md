# 第 04 阶段：Django REST Framework（构建 RESTful API）

## 学习目标

完成本阶段后，你将能够：
- 理解 RESTful API 设计原则
- 使用 DRF Serializer 进行数据序列化/反序列化/验证
- 使用 APIView、GenericView、ViewSet 构建 API
- 配置 Router 自动生成 URL
- 实现分页、过滤、搜索、排序
- 使用 drf-spectacular 自动生成 API 文档

## 阶段实战

为 TaskFlow 构建完整的 RESTful API：
- 任务 CRUD API（含嵌套标签、评论）
- 项目 CRUD API（含成员管理）
- 分页、过滤、搜索
- Swagger 文档
