# 第 04 节：权限系统

## 一、DRF 权限体系

DRF 的权限检查发生在 **认证之后、视图逻辑之前**：

```
请求 → 认证（谁？） → 权限（能不能？） → 视图逻辑
```

---

## 二、内置权限类

| 权限类 | 说明 |
|--------|------|
| `AllowAny` | 允许所有人访问（无需认证） |
| `IsAuthenticated` | 必须登录 |
| `IsAdminUser` | 必须是 `is_staff=True` |
| `IsAuthenticatedOrReadOnly` | 已登录可读写，未登录只读 |
| `DjangoModelPermissions` | 基于 Django Model 权限 |
| `DjangoObjectPermissions` | 基于对象级别权限 |

### 2.1 全局配置

```python
# config/settings.py
REST_FRAMEWORK = {
    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticated',  # 全局默认：必须登录
    ],
}
```

### 2.2 视图级配置

```python
from rest_framework.permissions import IsAuthenticated, AllowAny, IsAdminUser

class TaskViewSet(viewsets.ModelViewSet):
    permission_classes = [IsAuthenticated]  # 覆盖全局配置

class RegisterView(generics.CreateAPIView):
    permission_classes = [AllowAny]  # 注册不需要登录

class AdminDashboardView(APIView):
    permission_classes = [IsAdminUser]  # 仅管理员
```

### 2.3 Action 级配置

```python
class TaskViewSet(viewsets.ModelViewSet):
    permission_classes = [IsAuthenticated]
    
    def get_permissions(self):
        """不同 Action 使用不同权限"""
        if self.action == 'list':
            return [AllowAny()]
        if self.action in ['update', 'partial_update', 'destroy']:
            return [IsAuthenticated(), IsTaskOwnerOrAdmin()]
        return [IsAuthenticated()]
    
    # 或者在 @action 中指定
    @action(detail=False, methods=['get'], permission_classes=[AllowAny])
    def public_stats(self, request):
        """公开的统计数据"""
        ...
```

## 三、自定义权限

### 3.1 基础自定义权限

```python
# apps/core/permissions.py
from rest_framework.permissions import BasePermission

class IsOwnerOrReadOnly(BasePermission):
    """
    对象所有者可读写，其他人只读。
    需要模型有 creator 或 owner 字段。
    """
    message = '您没有权限执行此操作，只有创建者可以修改'
    
    def has_object_permission(self, request, view, obj):
        # 安全方法（GET、HEAD、OPTIONS）允许所有人
        if request.method in ('GET', 'HEAD', 'OPTIONS'):
            return True
        
        # 写操作只允许创建者
        if hasattr(obj, 'creator'):
            return obj.creator == request.user
        if hasattr(obj, 'owner'):
            return obj.owner == request.user
        return False
```

### 3.2 项目成员权限

```python
class IsProjectMember(BasePermission):
    """只有项目成员可以访问项目资源"""
    message = '您不是该项目的成员'
    
    def has_object_permission(self, request, view, obj):
        # obj 可能是 Project 或 Task
        project = obj if hasattr(obj, 'members') else getattr(obj, 'project', None)
        if project is None:
            return False
        
        return project.members.filter(id=request.user.id).exists()

class IsProjectAdmin(BasePermission):
    """只有项目管理员可以执行管理操作"""
    message = '需要项目管理员权限'
    
    def has_object_permission(self, request, view, obj):
        from apps.projects.models import ProjectMember
        project = obj if hasattr(obj, 'members') else getattr(obj, 'project', None)
        if project is None:
            return False
        
        return ProjectMember.objects.filter(
            project=project,
            user=request.user,
            role__in=['owner', 'admin'],
        ).exists()
```

### 3.3 任务权限

```python
class IsTaskAssigneeOrCreator(BasePermission):
    """任务负责人或创建者"""
    message = '只有任务负责人或创建者可以修改'
    
    def has_object_permission(self, request, view, obj):
        if request.method in ('GET', 'HEAD', 'OPTIONS'):
            return True
        return obj.assignee == request.user or obj.creator == request.user

class CanAssignTask(BasePermission):
    """只有项目管理员可以分配任务"""
    
    def has_permission(self, request, view):
        if view.action != 'assign_to':
            return True
        return request.user.is_staff  # 简化版，实际应检查项目角色
```

### 3.4 组合权限

```python
from rest_framework.permissions import IsAuthenticated

class TaskViewSet(viewsets.ModelViewSet):
    
    def get_permissions(self):
        if self.action in ['list', 'retrieve']:
            # 已登录 + 项目成员
            return [IsAuthenticated(), IsProjectMember()]
        elif self.action in ['update', 'partial_update']:
            # 已登录 + 任务负责人或创建者
            return [IsAuthenticated(), IsTaskAssigneeOrCreator()]
        elif self.action == 'destroy':
            # 已登录 + 项目管理员
            return [IsAuthenticated(), IsProjectAdmin()]
        return [IsAuthenticated()]
```

## 四、权限检查的两个层级

| 方法 | 检查时机 | 适用场景 |
|------|---------|---------|
| `has_permission(request, view)` | 在视图处理之前 | 列表级权限（能否访问这个端点） |
| `has_object_permission(request, view, obj)` | 获取对象之后 | 对象级权限（能否操作这个对象） |

```python
class IsOwner(BasePermission):
    
    def has_permission(self, request, view):
        """所有请求都需要登录"""
        return request.user and request.user.is_authenticated
    
    def has_object_permission(self, request, view, obj):
        """只有创建者可以操作"""
        return obj.creator == request.user
```

> ⚠️ `has_object_permission` 只在 `.get_object()` 被调用时触发（retrieve / update / destroy），list 不会触发。列表过滤应在 `get_queryset()` 中处理。
