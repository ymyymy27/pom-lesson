# 第 05 阶段：用户系统（注册/登录/JWT/权限）

## 学习目标

完成本阶段后，你将能够：
- 自定义 Django User 模型
- 实现用户注册、登录、登出 API
- 使用 JWT（JSON Web Token）实现无状态认证
- 配置 DRF 权限系统（IsAuthenticated、自定义权限）
- 理解 OAuth2 第三方登录原理

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-自定义User模型.md` | AbstractUser、Profile、信号自动创建 |
| 2 | `02-JWT认证.md` | SimpleJWT 配置、Token 获取/刷新/验证 |
| 3 | `03-注册登录API.md` | 注册、登录、登出、修改密码、当前用户 |
| 4 | `04-权限系统.md` | DRF 权限类、对象级权限、自定义权限 |
| 5 | `05-OAuth2第三方登录.md` | OAuth2 原理、django-allauth 集成 |
