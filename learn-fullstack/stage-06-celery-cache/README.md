# 第 06 阶段：Celery 异步任务 & Redis 缓存

## 学习目标

完成本阶段后，你将能够：
- 理解异步任务的概念和使用场景
- 配置 Celery + Redis 消息队列
- 编写和调度异步任务
- 使用 Celery Beat 实现定时任务
- 使用 Django 缓存框架 + Redis 缓存数据
- 实现缓存策略（缓存失效、缓存穿透防护）

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-Celery入门.md` | 异步任务概念、Celery 架构、安装配置 |
| 2 | `02-任务编写与调度.md` | 任务定义、调用方式、重试、链式任务 |
| 3 | `03-Celery-Beat定时任务.md` | 定时任务、Crontab、django-celery-beat |
| 4 | `04-Django缓存框架.md` | 缓存配置、视图缓存、低级缓存 API |
| 5 | `05-Redis缓存实战.md` | 缓存策略、缓存失效、TaskFlow 缓存方案 |
