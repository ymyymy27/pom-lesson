# 第 07 阶段：前端基础（HTML/CSS/JavaScript/TypeScript）

## 学习目标

完成本阶段后，你将能够：
- 理解 HTML5 语义化标签和页面结构
- 使用 CSS3 进行布局（Flexbox、Grid）和样式设计
- 掌握 JavaScript ES6+ 核心语法
- 理解异步编程（Promise、async/await）
- 掌握 TypeScript 基础（类型系统、接口、泛型）
- 使用现代前端工具链（Node.js、npm、Vite）

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-HTML5基础.md` | 语义化标签、表单、多媒体、可访问性 |
| 2 | `02-CSS3布局与样式.md` | Flexbox、Grid、响应式、动画 |
| 3 | `03-JavaScript-ES6+.md` | 变量、函数、解构、展开、模块、类 |
| 4 | `04-异步编程.md` | 回调、Promise、async/await、Fetch API |
| 5 | `05-TypeScript基础.md` | 类型、接口、泛型、枚举、类型工具 |
| 6 | `06-前端工具链.md` | Node.js、npm、Vite、ESLint、Prettier |

## 预计时长：7 天
