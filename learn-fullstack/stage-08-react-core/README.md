# 第 08 阶段：React 核心（组件/状态/路由/Hooks）

## 学习目标

完成本阶段后，你将能够：
- 理解 React 组件化开发思想和 JSX 语法
- 使用函数组件和 Hooks 管理状态
- 掌握常用 Hooks（useState、useEffect、useRef、useMemo、useCallback）
- 使用 React Router 实现前端路由
- 编写自定义 Hooks 封装逻辑
- 理解组件生命周期和渲染优化

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-React入门与JSX.md` | React 理念、JSX 语法、组件基础 |
| 2 | `02-组件与Props.md` | 函数组件、Props 传递、组件组合、children |
| 3 | `03-状态管理useState.md` | useState、状态更新、表单处理、状态提升 |
| 4 | `04-副作用useEffect.md` | useEffect、生命周期、数据获取、清理 |
| 5 | `05-常用Hooks.md` | useRef、useMemo、useCallback、useReducer |
| 6 | `06-React-Router路由.md` | 路由配置、嵌套路由、路由守卫、导航 |
| 7 | `07-自定义Hooks.md` | 自定义 Hook 编写、常用 Hook 封装 |
