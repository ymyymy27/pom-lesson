# 第 04 节：UI 框架集成

## 一、UI 框架选型

| 框架 | 风格 | 特点 | 适用场景 |
|------|------|------|---------|
| **Ant Design** | 企业级 | 功能全面、中文友好、开箱即用 | 后台管理系统 |
| **shadcn/ui** | 现代简洁 | 基于 Radix UI + Tailwind、可复制源码 | 自定义需求高 |
| **Material UI** | Material Design | Google 风格 | 面向 C 端 |
| **Chakra UI** | 简洁 | 样式系统友好 | 中小型项目 |

本课程以 **shadcn/ui** 为主（搭配 TailwindCSS），同时介绍 Ant Design。

---

## 二、shadcn/ui

shadcn/ui 不是传统组件库（npm 包），而是将组件源码直接复制到你的项目中，完全可定制。

### 2.1 安装

```bash
npx shadcn-ui@latest init

# 选择配置：
# TypeScript: yes
# Style: Default
# Base color: Slate
# CSS variables: yes
```

### 2.2 添加组件

```bash
npx shadcn-ui@latest add button
npx shadcn-ui@latest add input
npx shadcn-ui@latest add card
npx shadcn-ui@latest add dialog
npx shadcn-ui@latest add select
npx shadcn-ui@latest add table
npx shadcn-ui@latest add badge
npx shadcn-ui@latest add toast
npx shadcn-ui@latest add dropdown-menu
npx shadcn-ui@latest add form
```

### 2.3 使用组件

```tsx
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Card, CardHeader, CardTitle, CardContent, CardFooter } from '@/components/ui/card';
import { Badge } from '@/components/ui/badge';
import {
    Dialog, DialogContent, DialogHeader, DialogTitle, DialogTrigger, DialogFooter,
} from '@/components/ui/dialog';
import {
    Select, SelectContent, SelectItem, SelectTrigger, SelectValue,
} from '@/components/ui/select';

function TaskCard({ task }: { task: Task }) {
    const statusVariant: Record<string, 'default' | 'secondary' | 'destructive' | 'outline'> = {
        pending: 'outline',
        in_progress: 'default',
        completed: 'secondary',
        cancelled: 'destructive',
    };
    
    return (
        <Card>
            <CardHeader>
                <div className="flex items-center justify-between">
                    <CardTitle className="text-lg">{task.title}</CardTitle>
                    <Badge variant={statusVariant[task.status]}>
                        {task.status}
                    </Badge>
                </div>
            </CardHeader>
            <CardContent>
                <p className="text-sm text-muted-foreground">{task.description}</p>
            </CardContent>
            <CardFooter className="flex justify-between">
                <span className="text-sm text-muted-foreground">
                    优先级: {task.priority}
                </span>
                <div className="flex gap-2">
                    <Button size="sm" variant="outline">编辑</Button>
                    <Button size="sm" variant="destructive">删除</Button>
                </div>
            </CardFooter>
        </Card>
    );
}
```

### 2.5 数据表格

```tsx
import {
    Table, TableBody, TableCell, TableHead, TableHeader, TableRow,
} from '@/components/ui/table';

function TaskTable({ tasks }: { tasks: Task[] }) {
    return (
        <Table>
            <TableHeader>
                <TableRow>
                    <TableHead>标题</TableHead>
                    <TableHead>状态</TableHead>
                    <TableHead>优先级</TableHead>
                    <TableHead>负责人</TableHead>
                    <TableHead>截止日期</TableHead>
                    <TableHead className="text-right">操作</TableHead>
                </TableRow>
            </TableHeader>
            <TableBody>
                {tasks.map((task) => (
                    <TableRow key={task.id}>
                        <TableCell className="font-medium">{task.title}</TableCell>
                        <TableCell>
                            <Badge variant="outline">{task.status}</Badge>
                        </TableCell>
                        <TableCell>{task.priority}</TableCell>
                        <TableCell>{task.assignee?.username ?? '未分配'}</TableCell>
                        <TableCell>{task.dueDate ?? '-'}</TableCell>
                        <TableCell className="text-right">
                            <Button size="sm" variant="ghost">编辑</Button>
                            <Button size="sm" variant="ghost" className="text-red-500">删除</Button>
                        </TableCell>
                    </TableRow>
                ))}
            </TableBody>
        </Table>
    );
}
```
