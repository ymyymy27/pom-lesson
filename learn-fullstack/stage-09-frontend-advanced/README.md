# 第 09 阶段：前端进阶（状态管理/API 对接/UI 框架）

## 学习目标

完成本阶段后，你将能够：
- 使用 Zustand 进行全局状态管理
- 使用 Axios 封装 API 客户端（拦截器、Token 刷新）
- 使用 TanStack Query (React Query) 管理服务端状态
- 使用 Ant Design / shadcn/ui 构建专业 UI
- 实现表单验证（React Hook Form + Zod）

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-Zustand状态管理.md` | Zustand 核心、Store、中间件、持久化 |
| 2 | `02-Axios与API封装.md` | Axios 配置、拦截器、Token 自动刷新 |
| 3 | `03-TanStack-Query.md` | useQuery、useMutation、缓存、乐观更新 |
| 4 | `04-UI框架集成.md` | Ant Design / shadcn/ui 组件库使用 |
| 5 | `05-表单与验证.md` | React Hook Form + Zod 表单验证 |
