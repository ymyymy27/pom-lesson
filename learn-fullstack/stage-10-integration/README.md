# 第 10 阶段：前后端联调 & 项目实战

## 学习目标

完成本阶段后，你将能够：
- 完成 TaskFlow 前后端完整联调
- 理解 CORS 跨域问题及解决方案
- 实现文件上传（头像/附件）
- 实现 WebSocket 实时通知
- 搭建完整的项目目录结构

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-CORS与联调配置.md` | CORS 原理、代理配置、环境变量 |
| 2 | `02-文件上传.md` | 图片上传、附件管理、前端预览 |
| 3 | `03-WebSocket实时通知.md` | Django Channels、WebSocket、实时推送 |
| 4 | `04-项目实战整合.md` | TaskFlow 完整功能实现与页面搭建 |
