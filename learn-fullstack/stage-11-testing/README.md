# 第 11 阶段：测试（后端 pytest + 前端 Jest/Playwright）

## 学习目标

完成本阶段后，你将能够：
- 使用 pytest + pytest-django 编写后端单元测试和集成测试
- 使用 Factory Boy 生成测试数据
- 测试 DRF API 端点（认证、CRUD、权限）
- 使用 Vitest 编写前端单元测试
- 使用 Playwright 编写端到端测试

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-pytest基础.md` | pytest 入门、fixture、参数化、conftest |
| 2 | `02-Django后端测试.md` | 模型测试、API 测试、Factory Boy |
| 3 | `03-前端单元测试.md` | Vitest、React Testing Library、组件测试 |
| 4 | `04-E2E端到端测试.md` | Playwright 安装配置、页面测试、CI 集成 |

## 预计时长：5 天
