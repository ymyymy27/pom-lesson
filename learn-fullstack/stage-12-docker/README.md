# 第 12 阶段：Docker 容器化

## 学习目标

完成本阶段后，你将能够：
- 理解 Docker 核心概念（镜像、容器、卷、网络）
- 编写 Dockerfile 构建应用镜像
- 使用 Docker Compose 编排多容器应用
- 容器化 TaskFlow 完整技术栈（Django + React + PostgreSQL + Redis + Celery + Nginx）
- 理解开发环境与生产环境的 Docker 配置差异

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-Docker基础.md` | Docker 概念、安装、镜像与容器操作 |
| 2 | `02-Dockerfile编写.md` | 编写后端/前端 Dockerfile、多阶段构建 |
| 3 | `03-Docker-Compose编排.md` | 多容器编排、网络、卷、环境变量 |
| 4 | `04-生产环境Docker部署.md` | Nginx、Gunicorn、生产优化、安全 |
