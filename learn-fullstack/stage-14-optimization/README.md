# 第 14 阶段：性能优化、安全、监控

## 学习目标

完成本阶段后，你将能够：
- 对 Django 后端进行性能分析和优化
- 对 React 前端进行性能优化（代码分割、懒加载、渲染优化）
- 理解 Web 安全常见攻击和防护措施
- 配置应用监控和日志收集
- 掌握全栈性能优化的系统方法

## 课程内容

| 节 | 文件 | 内容 |
|----|------|------|
| 1 | `01-后端性能优化.md` | 数据库优化、查询分析、N+1、连接池、缓存 |
| 2 | `02-前端性能优化.md` | 代码分割、懒加载、渲染优化、资源优化 |
| 3 | `03-Web安全.md` | XSS、CSRF、SQL注入、安全头、HTTPS |
| 4 | `04-监控与日志.md` | 日志配置、Sentry 错误追踪、性能监控 |
| 5 | `05-Prometheus与Grafana实战.md` | Prometheus 指标、Grafana Dashboard、告警规则 |

## 预计时长：5–6 天
