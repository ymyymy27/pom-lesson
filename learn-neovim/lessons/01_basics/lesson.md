# 第 1 课：生存模式 —— 别慌，先活着

> 目标：学会进出 Neovim、保存文件、不丢数据

## 1.1 Neovim 的三种模式（必须理解）

Neovim 有多种"模式"，不同模式下同一个按键含义完全不同。

| 模式 | 说明 | 如何进入 |
|------|------|----------|
| **Normal** (普通模式) | 默认模式，用来导航和操作 | `Esc` |
| **Insert** (插入模式) | 用来输入文字 | `i` |
| **Command** (命令行模式) | 执行命令 | `:` |

> **重要原则**：普通模式下，你的键盘输入**不是**往文件里打字，
> 而是在执行命令。往文件里打字请按 `i` 进入插入模式。

## 1.2 第一个练习：打开文件

在终端中运行：

```bash
nvim lessons/01_basics/practice.txt
```

会打开一个空文件（或新建）。

## 1.3 最最重要的命令

```
i        → 进入插入模式（insert）
Esc      → 退回普通模式
:w       → 保存（write）
:q       → 退出（quit）
:wq      → 保存并退出
:q!      → 不保存强制退出（即使改了内容）
```

> **诀窍**：刚入门时，每次改完后养成 `Esc` → `:w` → 回车的习惯。

## 1.4 练习步骤

请按以下顺序在 Neovim 中完成：

### 步骤 1：打开文件，进入插入模式，写入内容

```
按 i
输入以下文字：
Hello Neovim!
This is my first file.
```

### 步骤 2：保存

```
按 Esc 回到普通模式
输入 :w 并按回车
```

底部应该显示类似 `"practice.txt" 2L, 38B written` 的信息。

### 步骤 3：退出再打开确认

```
输入 :q 回车（退出 Neovim）
重新打开：nvim lessons/01_basics/practice.txt
确认内容还在
```

### 步骤 4：修改内容

```
按 i 进入插入模式
用方向键（或 h j k l）移动光标
修改一行文字
按 Esc 回到普通模式
:w 保存
```

### 步骤 5：强制退出（模拟搞砸的情况）

```
随便在文件中输入一些乱码
按 Esc
输入 :q! 回车
重新打开文件，确认乱码没被保存
```

## 1.5 进入插入模式的多种方式

| 按键 | 含义 |
|------|------|
| `i` | 在**当前光标位置前**插入 (insert) |
| `a` | 在**当前光标位置后**插入 (append) |
| `o` | 在**当前行下方**新建一行并进入插入 |
| `O` | 在**当前行上方**新建一行并进入插入 |
| `I` | 在**行首**进入插入 |
| `A` | 在**行尾**进入插入 |

**建议**：先只用 `i` 和 `Esc`，等熟练了再学其他的。

## 1.6 常见错误

- **在普通模式下打字** → 屏幕可能会显示奇怪的东西（这是正常的），按 `Esc` 回到安全状态
- **忘记按回车** → `:w` 和 `:q` 后必须按回车
- **忘记 `:w`** → 修改后直接 `:q` 会提示未保存，加上 `!` 可以强制退出
