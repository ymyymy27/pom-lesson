# 第 6 课：宏与寄存器

> 目标：学会录制和回放操作序列，以及高效使用寄存器

## 6.1 宏（Macro）

宏 = 录制一系列操作，然后重复执行。

### 基本流程

```vim
qa               " 开始录制到寄存器 a（q = 开始/结束录制）
{一系列操作}      " 执行你想录制的动作
q                " 停止录制（再按一次 q）

@{a}             " 回放寄存器 a 中的宏
@@               " 重复上次执行的宏
10@{a}           " 重复 10 次
```

### 示例：给每行开头加引号

1. `qa` 开始录制到寄存器 a
2. `I` 跳到行首并进入插入模式
3. 输入 `"`
4. `Esc` 退回普通模式
5. `$` 跳到行尾
6. `a` 进入插入模式（光标后）
7. 输入 `"`
8. `Esc` 退回普通模式
9. `q` 停止录制
10. `VG` 选中所有行
11. `:norm @a` 对每行执行宏 a

### 更好的做法：逐行执行宏

1. 先录制宏（同上）
2. 用 `:` 加上 `normal @a` 对范围执行：

```vim
:5,10norm @a      " 对第 5-10 行执行宏 a
```

## 6.2 寄存器（Register）

寄存器 = 存放被删除、复制内容的剪贴板（不止一个！）。

### 查看寄存器

```vim
:reg              " 查看所有寄存器的内容
"ayy              " 复制当前行到寄存器 a
"ap               " 粘贴寄存器 a 的内容
```

### 常用寄存器

| 寄存器 | 内容 |
|--------|------|
| `"` | 默认寄存器（yy/dd/x 等操作的默认目标） |
| `0` | 最近一次 yank 的内容 |
| `1` | 最近一次 delete 的内容 |
| `2-9` | 更早的 delete 历史 |
| `a-z` | 命名寄存器（a 到 z） |
| `A-Z` | 追加到同名小写寄存器 |
| `/` | 上次搜索的 pattern |
| `:` | 上次执行的命令行 |
| `.` | 上次插入的文本 |

### 剪切板寄存器（需要 +clipboard）

```vim
"+yy              " 复制到系统剪切板
"+p               " 从系统剪切板粘贴
```

## 6.3 练习任务

1. 录制一个宏，在行尾添加分号 `;`
2. 对前 5 行执行该宏
3. 用 `:reg` 查看寄存器内容
4. 把某一行复制到寄存器 `c`，然后在别处粘贴
