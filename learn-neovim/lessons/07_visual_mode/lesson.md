# 第 7 课：可视化模式

> 目标：掌握可视化选择和多行批量编辑

## 7.1 三种可视化模式

| 模式 | 按键 | 用途 |
|------|------|------|
| 字符可视化 | `v` | 按字符选择 |
| 行可视化 | `V` | 按整行选择 |
| 块可视化 | `Ctrl+v` | 按列（矩形）选择 |

## 7.2 基本操作

```
v                " 进入字符可视化，选中字符
V                " 进入行可视化，选中整行
Ctrl+v           " 进入块可视化

选中后：
d / x            " 删除选中内容
y                " 复制选中内容
c                " 修改选中内容（删除并进入插入）
~                " 切换大小写
>                " 右缩进
<                " 左缩进
g?               " ROT13 加密
```

## 7.3 块可视化多行编辑（最强大！）

这是 Vim 最令人惊叹的功能之一：

1. `Ctrl+v` 进入块可视化
2. 用 `j k` 选中多行
3. `I` 进入插入模式（在大写 i）
4. 输入内容（比如 `//`）
5. 按 `Esc`
6. 所选行的**每一行**都插入了内容！

### 块可视化常用命令

| 按键 | 含义 |
|------|------|
| `I{text}` | 在选块前插入 |
| `A{text}` | 在选块后追加 |
| `c` | 删除选块并插入 |
| `r` | 把选块所有字符替换成同一个 |
| `~` | 切换大小写 |
| `J` | 合并选中行为一行 |

### 示例：在多行行首加注释

```
Ctrl+v
jjj              " 选中 4 行
I                " 进入块插入
//               " 输入注释符
Esc              " 退出
```

### 示例：在多行行尾加逗号

```
Ctrl+v
jjj
$A
,
Esc
```

## 7.4 可视化模式下的移动

```
o                " 移动选择范围的另一端（对调光标位置）
O                " 在块选择中跳到同列的另一个角
```

## 7.5 与操作符配合

选中内容后按 `:` 会变成 `:'<,'>`，可以直接接命令：

```
:'<,'>norm I//   " 对选中行执行普通模式的 I// 命令
:'<,'>s/old/new/ " 对选中行执行替换
```

## 7.6 练习任务

1. 用 `v` 选中一段文字并删除、复制、粘贴
2. 用 `V` 选中多行并整体右缩进
3. 用 `Ctrl+v I` 在多行行首同时插入内容
4. 用 `Ctrl+v A` 在多行行尾同时插入内容
5. 用 `Ctrl+v r-` 把选中块全部替换成 `-`
