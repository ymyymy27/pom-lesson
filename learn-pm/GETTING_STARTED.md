# 产品经理课程 — 快速开始

## 5 分钟定位

| 你的背景 | 推荐起点 |
|----------|----------|
| 零基础，想了解产品思维 | `learn-product/01_product_thinking.md` |
| 开发者转 PM | `learn-product/01` → 跳过技术基础，重点 02–05 |
| 想转 AI 产品经理 | 先 `learn-ai-pm/01_ai_tech_basics.md`，再 `03_llm_products.md` |
| 已有 PM 经验，补 AI | 直接 `learn-ai-pm/` 全套 |

## 两条学习线

```
learn-product（通用产品）          learn-ai-pm（AI 产品）
  01 产品思维                        01 AI 技术认知
  02 PRD/原型                        02 模型评估
  03 竞品分析                        03 LLM 产品设计
  04 数据分析 ←── 联动 learn-sql     04 AI 伦理
  05 项目管理/敏捷                   05 面试
```

## 与开发者课程的分工

| 主题 | PM 视角（本课程） | 开发者视角 |
|------|------------------|-----------|
| 敏捷/Scrum | PM 在 Sprint 中的角色 | `learn-se/learn-dev-methods` |
| SQL/数据分析 | 指标定义、A/B 测试解读 | `learn-tools/learn-sql` |
| LLM/RAG | 产品形态、用户体验、成本 | `learn-ai/` |
| 安全 | AI 伦理、合规、用户信任 | `learn-se/learn-security` |

## 预计时长

- **learn-product**：约 2 周（5 课）
- **learn-ai-pm**：约 2 周（5 课）
- **完整路线**：约 4 周

## 产出建议

每课完成后尝试产出：

1. 01 产品思维 → 写一份问题陈述（Problem Statement）
2. 02 PRD → 用模板写 TaskFlow 一个功能的 PRD
3. 03 竞品 → 对比 2 个同类产品的功能矩阵
4. 04 数据分析 → 用 SQL 分析一组 mock 数据（参考 learn-sql）
5. 05 敏捷 → 设计一次 Sprint Planning 议程
