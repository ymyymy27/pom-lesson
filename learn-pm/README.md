# 产品经理课程

面向 AI 产品经理的系统学习路径，包含通用产品基本功和 AI PM 专项知识。

👉 **快速开始** → [`GETTING_STARTED.md`](GETTING_STARTED.md)  
👉 **模板库** → [`templates/`](templates/)

## 课程目录

| 课程 | 目录 | 内容 | 课时 |
|------|------|------|------|
| 产品经理基本功 | `learn-product/` | PRD、原型、竞品分析、数据分析、敏捷开发 | 5课 |
| AI 产品经理专项 | `learn-ai-pm/` | AI技术认知、模型评估、大模型产品、AI伦理、面试 | 5课 |

## 学习顺序建议

```
learn-product → learn-ai-pm
  产品基本功     AI专项知识
```

## 学习方式

- 以 **Markdown 文档** 为主，包含概念讲解、案例分析、模板和练习
- 建议边看文档边动手实践（写PRD、画原型、做竞品分析）
- 结合 learn-sql（数据分析）和 learn-ai（技术理解）一起学习
