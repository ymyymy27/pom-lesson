# 第3课：竞品分析

## 1. 什么是竞品分析？

### 一句话定义
**竞品分析就是"研究对手来帮自己做决策"** —— 了解竞争对手做了什么、做得好不好，从而找到自己产品的方向。

### 为什么要做竞品分析？

```
1. 了解市场：这个赛道有哪些玩家？格局如何？
2. 学习借鉴：竞品的优秀设计值得参考
3. 发现机会：竞品没做好的地方就是你的机会
4. 支撑决策：为需求优先级和产品方向提供依据
5. 面试必备：产品经理面试中竞品分析是高频考点
```

---

## 2. 竞品分类

### 三类竞品

```
直接竞品：功能和用户群高度重合
  例：Kimi vs 豆包 vs ChatGPT（都是AI对话助手）

间接竞品：解决同一问题但方式不同
  例：AI翻译 vs 人工翻译 vs 翻译机

潜在竞品：未来可能进入你的市场
  例：微信加入AI功能，可能抢占独立AI助手的市场
```

### 如何找到竞品？

```
1. 应用商店：搜索关键词，看同类APP排名
2. 搜索引擎：搜"XX产品 竞品" / "XX行业 报告"
3. 行业报告：36氪、艾瑞咨询、QuestMobile
4. 投融资信息：IT桔子、企查查（看同赛道融资项目）
5. 社交媒体：知乎、即刻、Twitter 上的用户讨论
6. 产品社区：Product Hunt、少数派、小众软件
```

## 3. 竞品分析框架

### 3.1 五维分析法

```
┌─────────────────────────────────────────────────┐
│                   竞品分析五维度                   │
├──────────┬──────────────────────────────────────┤
│ 产品定位  │ 目标用户是谁？解决什么问题？           │
│          │ 产品slogan、核心价值主张               │
├──────────┼──────────────────────────────────────┤
│ 核心功能  │ 主要功能有哪些？核心体验是什么？        │
│          │ 功能对比表（有/无/做得好不好）          │
├──────────┼──────────────────────────────────────┤
│ 用户体验  │ 界面设计、交互流程、上手难度            │
│          │ 新用户引导、核心路径流畅度              │
├──────────┼──────────────────────────────────────┤
│ 商业模式  │ 怎么赚钱？定价策略？付费转化如何？      │
│          │ 免费 vs 付费功能划分                   │
├──────────┼──────────────────────────────────────┤
│ 运营策略  │ 获客渠道、增长策略、用户运营            │
│          │ 内容生态、社区运营                     │
└──────────┴──────────────────────────────────────┘
```

### 3.2 功能对比表

```
功能对比表示例（AI对话产品）:

| 功能 | Kimi | 豆包 | ChatGPT | 通义千问 |
|------|------|------|---------|---------|
| 多轮对话 | ✅ | ✅ | ✅ | ✅ |
| 长文本处理 | ✅(200万字) | ✅ | ✅(128K) | ✅ |
| 联网搜索 | ✅ | ✅ | ✅ | ✅ |
| 文件上传 | ✅(PDF/Word) | ✅ | ✅ | ✅ |
| 图片理解 | ✅ | ✅ | ✅(GPT-4o) | ✅ |
| 图片生成 | ❌ | ✅ | ✅(DALL-E) | ✅ |
| 语音交互 | ❌ | ✅ | ✅ | ✅ |
| 插件/工具 | ❌ | 有限 | ✅(GPTs) | ✅ |
| 免费额度 | 较多 | 较多 | 有限 | 较多 |
| 中文优化 | 优秀 | 优秀 | 一般 | 优秀 |
```

### 3.3 SWOT 分析

```
针对每个竞品做 SWOT:

        正面              负面
内部  ┌──────────┬──────────────┐
      │ Strengths│ Weaknesses   │
      │ 优势     │ 劣势          │
      ├──────────┼──────────────┤
外部  │Opportuni │ Threats      │
      │ ties     │              │
      │ 机会     │ 威胁          │
      └──────────┴──────────────┘

示例（Kimi）：
  S 优势：长文本处理能力强、中文理解好、免费额度多
  W 劣势：无图片生成、无语音交互、生态较封闭
  O 机会：大模型技术持续进步、办公场景需求增长
  T 威胁：字节豆包资源强、ChatGPT品牌效应、微信可能入局
```

## 5. 竞品分析的常见误区

```
❌ 误区1：只看功能，不看场景
  → 功能再多，不解决用户问题也没用
  → 应该分析：这个功能在什么场景下有价值

❌ 误区2：竞品有什么就做什么
  → 竞品做了不代表做对了
  → 要思考：适合我们的用户吗？有差异化吗？

❌ 误区3：只分析一次，不跟踪
  → 竞品在持续迭代
  → 建议：建立竞品跟踪机制，月度更新

❌ 误区4：分析太表面（只看UI截图）
  → 要深入体验，注册使用，走完核心流程
  → 关注细节：错误提示、空状态、极端情况
```

## 6. 动手练习

### 练习1：AI 对话产品竞品分析

1. 选择 3 个 AI 对话产品（如 Kimi、豆包、ChatGPT）
2. 注册并深度使用每个产品至少 30 分钟
3. 完成功能对比表
4. 对每个产品做 SWOT 分析
5. 写 500 字总结：你认为哪个产品做得最好？为什么？

### 练习2：AI 写作助手竞品分析

1. 找到 3 个 AI 写作/文档工具
2. 用统一的测试用例对比（如"帮我写一封商务邮件"）
3. 从功能、体验、价格三个维度打分（1-5分）
4. 得出结论：如果你要做一个 AI 写作助手，差异化在哪？

## 7. 小结

| 概念 | 核心要点 |
|------|---------|
| 竞品分类 | 直接/间接/潜在三类 |
| 分析维度 | 定位、功能、体验、商业、运营 |
| 功能对比 | 表格化，标明有无和优劣 |
| SWOT | 四象限分析优势劣势机会威胁 |
| 报告输出 | 目的→市场→竞品选择→对比→结论 |
