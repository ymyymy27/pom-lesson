# 产品经理基本功 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_product_thinking.md` | 产品思维、用户需求分析、用户画像、场景分析 |
| 第2课 | `02_prd_and_prototype.md` | PRD 文档撰写、原型设计、需求评审 |
| 第3课 | `03_competitive_analysis.md` | 竞品分析方法论、分析框架、报告模板 |
| 第4课 | `04_data_analysis.md` | 产品数据分析、指标体系、A/B测试、漏斗分析 |
| 第5课 | `05_project_management.md` | 敏捷开发、项目管理、跨部门协作、产品上线 |

## 学习方式

- Markdown 文档 + 实践作业
- 建议边看文档边动手输出（写PRD、画原型、做竞品报告）
- 每课都有模板和练习
