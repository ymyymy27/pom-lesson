## 3. SQL 查询示例

<!-- 联动 learn-tools/learn-sql 练习 -->

```sql
-- 日活跃用户（DAU）
SELECT DATE(created_at) AS day, COUNT(DISTINCT user_id) AS dau
FROM user_events
WHERE event_type = 'login'
GROUP BY day
ORDER BY day DESC
LIMIT 30;
```
