# 软件工程基础

建立软件工程的「底层思维」：生命周期、设计原则、质量保障与重构。

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_software_lifecycle.md` | SDLC、需求分析、可行性、文档与交付物 |
| 第2课 | `02_solid_and_clean_code.md` | SOLID 五大原则、Clean Code 实践 |
| 第3课 | `03_testing_and_quality.md` | 测试金字塔、TDD、代码审查、质量度量 |
| 第4课 | `04_refactoring.md` | 重构时机、常见手法、与测试的配合 |

## 学习目标

- 理解软件从需求到上线的完整生命周期
- 能用 SOLID 原则审视和改进代码结构
- 建立「测试先行、持续重构」的工程习惯

## 学习方式

- 按顺序阅读，每课末尾有自检清单
- 第2、4课建议结合自己项目中的代码对照练习
- 与 `learn-design-patterns/` 衔接：原则 → 模式
