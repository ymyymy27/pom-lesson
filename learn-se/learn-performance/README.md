# 性能工程

性能不是「优化到最快」，而是「在约束下够快」——测量、分析、优化、验证。

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 参考 | `00_performance_overview.md` | 性能思维、延迟分布、优化层次 |
| 第1课 | `01_profiling_and_analysis.md` | 性能分析、Profiling、瓶颈定位 |
| 第2课 | `02_optimization_patterns.md` | 缓存、异步、DB 优化、连接池 |
| 第3课 | `03_load_testing.md` | 负载测试、压测方法、性能基准 |

## 学习目标

- 建立「先测量再优化」的性能思维
- 会用 Profiler 定位 Python 应用瓶颈
- 掌握缓存、异步、DB 索引等常见优化手段
- 能设计负载测试方案
