# 第9课：综合大作业：MultiTask 多租户权限系统

## 1. 项目背景

MultiTask 是一个任务协作 SaaS：多个企业（租户）注册使用，每个企业有自己的成员、部门、项目和任务。你要从零设计并实现一套完整的权限与多租户体系。

## 2. 功能需求

### 租户与组织

- 租户注册、开通、停用
- 租户内邀请成员，同一用户可加入多个租户
- 组织树：多级部门 + 岗位 + 成员

### 权限

- RBAC：内置角色（Owner / Admin / Member）+ 支持客户自定义角色
- 权限点注册：project、task、member 等资源
- 数据权限：成员可配置"仅本人 / 本部门 / 本部门及下属 / 全部"

### 审计与安全

- 登录、权限变更、删除操作可追溯
- 全部接口防越权（水平/垂直/IDOR）

### 非功能

- 默认共享表 + `tenant_id`（MVP），并设计独立库迁移路径
- 缓存 key 隔离租户
- 至少 3 条 ADR：隔离模型、缓存策略、角色设计

## 3. 建议技术栈

```
Python 3.12 + FastAPI + PostgreSQL + Redis
```

与学习工作区其他课程保持一致，便于复用。

## 4. 分阶段实施

| 阶段 | 内容 | 验收 |
|------|------|------|
| 第1阶段 | 数据模型：tenants/users/memberships/departments/roles/permissions 及关联表 + 迁移 | 表结构 + ER 图 |
| 第2阶段 | 注册登录、JWT、租户中间件、基础 CRUD | 两个租户登录互不干扰 |
| 第3阶段 | 权限点注册、RBAC 判断、数据范围解析、审计中间件 | 权限矩阵生效 |
| 第4阶段 | 权限中台：`/check` 批量鉴权、缓存与版本失效 | 权限变更 5 秒内生效 |
| 第5阶段 | 越权测试套件、性能压测、ADR、README | 全部验收清单通过 |

## 5. 验收清单

- [ ] 两个租户互不可见数据，直接改 URL 也无法访问
- [ ] 同一用户可加入多个租户且权限互不影响
- [ ] 数据范围切换后，列表、详情、导出一致生效
- [ ] 权限变更 5 秒内全局生效
- [ ] 审计日志覆盖登录、权限变更、删除操作
- [ ] 单机压测 500+ QPS（鉴权接口）
- [ ] 3 条 ADR 说明关键决策及代价

## 6. 加分项

- PostgreSQL RLS 双重保险
- ABAC 策略（如"仅工作时间可删除任务"）
- SSO 接入（OIDC）
- 租户配额与计费
- 大租户独立 Schema 的路由迁移演示

## 7. 提交形式

项目目录 + README（架构图、API 文档、验收结果）+ 测试报告。

完成后可以串联 `learn-fullstack/`，用 Django + React 把同一套权限体系做成完整应用。
