# Git 版本控制 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_git_basics.md` | Git 是什么、安装配置、基本工作流（add/commit/log） |
| 第2课 | `02_branch_and_merge.md` | 分支管理、合并、冲突解决 |
| 第3课 | `03_remote_collaboration.md` | 远程仓库、GitHub、push/pull、协作流程 |
| 第4课 | `04_advanced_git.md` | rebase、stash、cherry-pick、tag、回退 |
| 第5课 | `05_git_workflow.md` | 工作流实战（Git Flow / GitHub Flow / 提交规范） |

## 学习方式

- Markdown 文档 + 终端动手练习
- 建议创建一个测试仓库反复练习
- 按顺序学习，每课都有动手练习
