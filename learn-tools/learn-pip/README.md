# pip 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_pip_basics.md` | pip 是什么、基本命令（安装/卸载/查看） |
| 第2课 | `02_version_and_requirements.md` | 版本管理 & requirements.txt |
| 第3课 | `03_venv.md` | 虚拟环境（venv）与 pip 配合使用 |
| 第4课 | `04_mirror_and_troubleshoot.md` | 国内镜像源加速 & 常见问题排查 |
| 第5课 | `05_practice.py` | 实战演练脚本（可运行验证你的 pip 环境） |

## 学习方式

- 第1-4课是 **Markdown 文档**，直接阅读即可，里面的命令需要你在终端中手动输入练习
- 第5课是 **Python 脚本**，用来验证你的 pip 环境是否正常工作
- 建议按顺序学习，边读边在终端里动手试

## 为什么用 Markdown 而不是 .py 文件？

因为 pip 是一个**命令行工具**，主要操作是在终端里敲命令，不是写 Python 代码。
所以用文档讲解+终端练习的方式最合适。
