# 第2课：分组、捕获与前后查找

## 1. 分组（Grouping）

### 1.1 基本分组 ( )

用圆括号把正则"打包"成一个整体。

```
正则: (ab)+
匹配: ababab     → [ababab]（ab重复3次）
不匹配: aabb

正则: (red|blue) car
匹配: red car, blue car
```

### 1.2 捕获组

圆括号不仅分组，还会**捕获**匹配的内容，可以后续引用。

```
正则: (\d{4})-(\d{2})-(\d{2})
文本: 2024-01-15

捕获结果:
  组0（整体）: 2024-01-15
  组1:        2024
  组2:        01
  组3:        15
```

**用途：** 从文本中提取信息（日期的年月日、URL 的域名等）。

### 1.3 命名捕获组

给分组起个名字，代码中更好读。

```
正则: (?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})

Python 中:
  match.group('year')   → '2024'
  match.group('month')  → '01'
  match.group('day')    → '15'

JavaScript 中:
  (?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})
  match.groups.year     → '2024'
```

### 1.4 非捕获组 (?: )

只分组不捕获（不需要提取内容时用，性能更好）。

```
正则: (?:red|blue) car
匹配: red car, blue car
但不会捕获 red/blue

对比:
  (red|blue) car     → 捕获组1: red 或 blue
  (?:red|blue) car   → 没有捕获组
```

## 2. 反向引用

引用前面捕获组匹配到的内容。

### 2.1 基本反向引用

```
\1    引用第1个捕获组的内容
\2    引用第2个捕获组的内容

正则: (\w+)\s+\1
文本: hello hello world world foo bar
匹配: [hello hello] [world world]
解释: 匹配重复的单词

正则: <(\w+)>.*?</\1>
文本: <b>bold</b> <i>italic</i>
匹配: [<b>bold</b>] [<i>italic</i>]
解释: 匹配配对的 HTML 标签
```

### 2.2 在替换中使用

```
搜索: (\w+)@(\w+)\.(\w+)
替换: 用户名:\1, 域名:\2, 后缀:\3

文本: alice@gmail.com
结果: 用户名:alice, 域名:gmail, 后缀:com

# 交换两个单词
搜索: (\w+) (\w+)
替换: \2 \1

文本: hello world
结果: world hello
```

## 3. 前后查找（Lookaround）

### 一句话解释
**前后查找 = 在匹配时"看看前面/后面是什么"，但不包含在匹配结果中。**

类比：
```
"找到后面跟着'元'的数字"
  100元 200美元 300元
  [100]元 200美元 [300]元    ← 匹配100和300，不匹配200
  "元"字只是条件，不在结果中
```

### 3.1 四种类型

| 语法 | 名称 | 含义 | 示例 |
|------|------|------|------|
| `(?=...)` | 正向先行 | 后面是... | `\d+(?=元)` → 数字后面跟着"元" |
| `(?!...)` | 负向先行 | 后面不是... | `\d+(?!元)` → 数字后面不是"元" |
| `(?<=...)` | 正向后行 | 前面是... | `(?<=\$)\d+` → 前面是$的数字 |
| `(?<!...)` | 负向后行 | 前面不是... | `(?<!\$)\d+` → 前面不是$的数字 |

**记忆技巧：**
- `=` 是"有"，`!` 是"没有"
- `<` 看左边（后行），没有 `<` 看右边（先行）

### 3.2 正向先行 (?=...)

"匹配的东西，后面必须跟着..."

```
正则: \w+(?=\()
文本: print(hello) len(data) x + y
匹配: [print](hello) [len](data) x + y
解释: 匹配后面跟着 ( 的单词（函数名）

正则: \d+(?=元)
文本: 100元 200美元 300元
匹配: [100]元 200美元 [300]元
```

### 3.3 负向先行 (?!...)

"匹配的东西，后面不能跟着..."

```
正则: \d+(?!元)
文本: 100元 200美元 300元
匹配: 100元 [200]美元 300元
解释: 数字后面不是"元"

正则: \b\w+\b(?!\()
文本: print(hello) foo bar
匹配: print(hello) [foo] [bar]
解释: 不是函数调用的单词
```

### 3.4 正向后行 (?<=...)

"匹配的东西，前面必须是..."

```
正则: (?<=\$)\d+
文本: $100 €200 $300
匹配: $[100] €200 $[300]
解释: 前面是 $ 的数字

正则: (?<=@)\w+
文本: user@gmail.com
匹配: user@[gmail].com
解释: @ 后面的单词
```

### 3.5 负向后行 (?<!...)

"匹配的东西，前面不能是..."

```
正则: (?<!\$)\d+
文本: $100 €200 300
匹配: $100 €[200] [300]
解释: 前面不是 $ 的数字
```

### 3.6 组合使用

```
# 匹配密码强度：至少包含一个大写、一个小写、一个数字
正则: (?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}
解释:
  (?=.*[A-Z])  后面某处有大写字母
  (?=.*[a-z])  后面某处有小写字母
  (?=.*\d)     后面某处有数字
  .{8,}        至少8个字符

匹配: Abc12345 ✓
不匹配: abcdefgh ✗（没大写）
不匹配: ABCD1234 ✗（没小写）
不匹配: Abcdefgh ✗（没数字）
```

## 4. 修饰符（Flags）

| 修饰符 | 含义 | Python |
|--------|------|--------|
| `i` | 忽略大小写 | `re.IGNORECASE` |
| `m` | 多行模式（^$ 匹配每行） | `re.MULTILINE` |
| `s` | 点号匹配换行 | `re.DOTALL` |
| `x` | 忽略空白和注释（可读模式） | `re.VERBOSE` |
| `g` | 全局匹配（JS用，Python默认） | `re.findall()` |

```python
# 在 regex101.com 中：
/pattern/gi    # 全局 + 忽略大小写

# Python 中：
re.findall(r'pattern', text, re.IGNORECASE)
```

## 5. 综合示例

```
# 匹配千分位数字：在数字中每三位加逗号
正则: (?<=\d)(?=(\d{3})+$)
文本: 1234567
替换: ,
结果: 1,234,567

# 提取 Markdown 链接
正则: \[([^\]]+)\]\(([^)]+)\)
文本: [Google](https://google.com)
捕获: 组1=Google, 组2=https://google.com

# 匹配不含某单词的行
正则: ^(?!.*error).*$
文本:
  this is fine          ← ✓
  this has error here   ← ✗
  all good              ← ✓

# 提取 JSON 中的值
正则: "name"\s*:\s*"([^"]+)"
文本: {"name": "Alice", "age": 25}
捕获: 组1=Alice
```

## 7. 小结

| 语法 | 名称 | 用途 |
|------|------|------|
| `(...)` | 捕获组 | 分组+提取 |
| `(?:...)` | 非捕获组 | 只分组不提取 |
| `(?P<name>...)` | 命名捕获 | 按名字提取 |
| `\1` `\2` | 反向引用 | 引用捕获内容 |
| `(?=...)` | 正向先行 | 后面必须是 |
| `(?!...)` | 负向先行 | 后面不能是 |
| `(?<=...)` | 正向后行 | 前面必须是 |
| `(?<!...)` | 负向后行 | 前面不能是 |
