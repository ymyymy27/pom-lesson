# 正则表达式 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_regex_basics.md` | 正则是什么、基础语法（字符/量词/边界） |
| 第2课 | `02_groups_and_lookaround.md` | 分组、捕获、反向引用、前后查找 |
| 第3课 | `03_python_re.md` | Python re 模块（match/search/findall/sub） |
| 第4课 | `04_common_patterns.md` | 常用正则模式（邮箱/手机/URL/IP/日期等） |
| 第5课 | `05_practice.py` | 实战练习脚本（可运行验证） |

## 学习方式

- 第1-4课是 Markdown 文档，配合在线工具练习
- 第5课是 Python 脚本，直接运行测试
- 推荐在线工具：https://regex101.com（实时匹配可视化）
- 按顺序学习，每课都有练习
