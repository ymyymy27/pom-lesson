# Shell 命令行 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_file_and_directory.md` | 文件与目录操作（ls/cd/mkdir/cp/mv/rm） |
| 第2课 | `02_pipe_and_redirect.md` | 管道与重定向（\|/>/>>/<） |
| 第3课 | `03_text_processing.md` | 文本处理（grep/awk/sed/sort/wc） |
| 第4课 | `04_shell_scripting.md` | Shell 脚本编写（变量/条件/循环/函数） |
| 第5课 | `05_practical_commands.md` | 实用命令集锦（进程/网络/压缩/环境变量） |

## 学习方式

- Markdown 文档 + 终端动手练习
- Windows 用户建议用 Git Bash 或 WSL
- 每条命令都动手试一遍，看输出
- 按顺序学习，每课都有动手练习

## 环境说明

- **Windows**: Git Bash（安装 Git 自带）或 WSL
- **Mac/Linux**: 自带终端即可
- PowerShell 命令有差异，本课以 Bash 为主
