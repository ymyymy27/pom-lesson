# SQL 数据分析 从零开始学习教程

## 课程目录

| 课程 | 文件 | 内容 |
|------|------|------|
| 第1课 | `01_sql_basics.md` | SQL 是什么、SELECT/WHERE/ORDER BY/LIMIT |
| 第2课 | `02_aggregation.md` | 聚合函数（COUNT/SUM/AVG）、GROUP BY、HAVING |
| 第3课 | `03_join_and_subquery.md` | 多表连接（JOIN）、子查询、UNION |
| 第4课 | `04_window_functions.md` | 窗口函数（ROW_NUMBER/RANK/LAG/LEAD） |
| 第5课 | `05_practice.md` | 产品经理常用 SQL 实战（留存/漏斗/用户分析） |

## 学习方式

- Markdown 文档 + 实际练习
- 推荐在线练习平台：https://sqliteonline.com
- 也可以用 Python sqlite3 模块本地练习
- 按顺序学习，每课都有练习题

## 环境说明

- 本课以 **标准 SQL** 语法为主（MySQL/PostgreSQL/SQLite 通用）
- 少数语法差异会标注
